# VC2S10I03 — Science Inquiry Skills (Short)

## Snapshot
- **Descriptor:** Select equipment, generate data with appropriate precision and consider sample size for reliable results, using digital tools where appropriate.
- **Year / Area:** Year 10, Science.
- **Big ideas:** Match instrument to claim. Sample size beats single trials. Digital tools speed but need checks.

## What you are learning
- You are learning to **select equipment**, generate data with **appropriate precision**, and consider **sample size** using **digital tools**.
- You should be able to plan data collection that supports the claim.

## Core content

**Precision** is how close repeated measurements are; **accuracy** is how close to the true value; **resolution** is the smallest unit the instrument can show. Match the smallest difference you need to detect with the instrument's resolution. **Sample size (n)** is the number of independent measurements; larger n reduces random error, but design quality matters more than n alone. A pilot study reveals variability and helps decide n.

Digital tools (spreadsheets, loggers, online forms) speed up collection but need version control, clear field names and back-ups. Every record carries label, value, unit, time, instrument, operator and conditions.

**Worked example.** Reaction-time class study. Equipment: identical laptops with a millisecond-resolution online task. n = 30 students, three repeats each. Controlled: same time of day, same room, same task. Pre-register the analysis plan. Record means and standard deviations in a versioned spreadsheet.

**Cultural context.** Aboriginal and Torres Strait Islander rangers across Victoria use a combination of traditional observation and modern instruments, including data loggers and GPS units. Specific cultural knowledge should only be read through published, community-approved material.

## Memorable takeaways
- Match instrument to claim.
- Sample size beats single trials.
- Pilot studies save full studies.
- Label, value, unit, time, instrument, operator.

## Watch out for these traps
- "More decimal places means more accurate." No. Extra zeros beyond resolution are misleading.
- "Bigger n is always better." No. After a point, design matters more.
- "Digital tools are objective." No. They reflect choices in calibration and defaults.

## Model responses

Use these to check your thinking after you have had a go.

- *Precise but inaccurate problem.* The data are repeatable but wrong, which can be more dangerous than obviously bad data.
- *Why are three trials usually a minimum?* Two trials cannot distinguish random variation from a real difference; three lets you compute a mean and a range.
- *What does a pilot study tell you?* Variability, time per trial, equipment quirks and likely sample-size needs.
- *Why is auto-save not version control?* Auto-save overwrites; version control preserves earlier states and supports rollback.
- *Short summary of the reaction-time plan.* Identical laptops, millisecond-resolution timer, n = 30 students with three repeats, controlled conditions, pre-registered analysis, and a versioned data log.
