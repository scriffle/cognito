# VC2M10A14 — Mathematics

## Snapshot
- **Descriptor:** VC2M10A14. Solve simple exponential equations.
- **Year level / Learning area:** Years 9–10, Mathematics (Algebra).
- **Big ideas:**
  - Exponential equations have the variable in the exponent — they require different techniques from linear or quadratic equations.
  - The key strategy is to express both sides with the **same base**, then equate the exponents.
  - Understanding exponent laws is essential for simplifying and solving.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **solve exponential equations** by rewriting expressions with a common base.
- You are learning to recognise when equations are exponential and to apply index laws strategically.

By the end of this you should be able to:
- Identify an equation as exponential (variable in the exponent).
- Express both sides of the equation with the same base.
- Equate exponents and solve the resulting equation.
- Verify solutions by substitution.

## Core content

**1. What makes an equation exponential?** In an exponential equation the unknown is in the **exponent** (power), not the base. Example: 2ˣ = 16 is exponential; x² = 16 is quadratic. Different variable positions require different solving strategies. *Quick check:* Which is exponential — 5ˣ = 125 or x⁵ = 32?

**2. Same-base strategy.** If aˣ = aⁿ, then x = n (because exponential functions are one-to-one). So the goal is to rewrite both sides with the same base. Example: 2ˣ = 16 → 2ˣ = 2⁴ → x = 4. *Quick check:* Solve 3ˣ = 81.

**3. Rewriting numbers as powers.** Key powers to know: 2¹ = 2, 2² = 4, 2³ = 8, 2⁴ = 16, 2⁵ = 32, 2⁶ = 64. 3² = 9, 3³ = 27, 3⁴ = 81. 5² = 25, 5³ = 125. To solve 4ˣ = 64: rewrite as (2²)ˣ = 2⁶ → 2²ˣ = 2⁶ → 2x = 6 → x = 3. *Quick check:* Solve 9ˣ = 27 (Hint: express both as powers of 3).

**4. Equations with negative exponents.** 2ˣ = 1/8. Since 1/8 = 2⁻³, we have 2ˣ = 2⁻³ → x = −3. Remember: a⁻ⁿ = 1/aⁿ. *Quick check:* Solve 5ˣ = 1/25.

**5. Equations requiring index laws.** 8^(x+1) = 32. Rewrite: (2³)^(x+1) = 2⁵ → 2^(3x+3) = 2⁵ → 3x + 3 = 5 → 3x = 2 → x = 2/3. Check: 8^(2/3 + 1) = 8^(5/3) = (2³)^(5/3) = 2⁵ = 32 ✓. *Quick check:* Solve 4^(x−1) = 8.

**6. Worked example — bacterial doubling.**
A colony of bacteria doubles every hour. Starting with 5 bacteria, the population is P = 5 × 2ᵗ. When does the population reach 640?

*Follow the thinking:*
- Set up: 5 × 2ᵗ = 640.
- Divide both sides by 5: 2ᵗ = 128.
- Rewrite 128 as a power of 2: 128 = 2⁷.
- So 2ᵗ = 2⁷ → t = 7.
- Check: 5 × 2⁷ = 5 × 128 = 640 ✓.
- The population reaches 640 after 7 hours.

**7. When same-base doesn't work easily.** Some exponential equations cannot be solved by same-base methods at this level (e.g. 2ˣ = 5). These require logarithms, which are studied later. For now, recognise these as equations that need trial-and-improvement or graphical methods. *Quick check:* Can 3ˣ = 20 be solved by the same-base method? Why or why not?

## Try these scenarios

1. **Everyday.** You invest $1000 and it doubles every 10 years. Write the equation A = 1000 × 2^(t/10). How many years until you have $8000? Set up and solve the exponential equation.
2. **Civic.** A city's waste output grows by a factor of 3 every 20 years. If current output is 50,000 tonnes, solve 50000 × 3^(t/20) = 450000 to find when output reaches 450,000 tonnes.
3. **Vocational.** A radiographer knows a radioactive tracer decays with half-life 6 hours: A = A₀ × (1/2)^(t/6). If the starting amount is 800 mg, solve for when 25 mg remains.
4. **Ethical.** A social media post claims "if you share this with 3 people and they each share with 3, it'll reach everyone in Australia (26 million) in 15 shares." Set up 3¹⁵ and check whether this claim is accurate. What does this tell you about viral claims?
5. **Cross-cultural.** The legend of the chess inventor (from India/Persia) involves placing 1 grain on square 1, 2 on square 2, 4 on square 3, etc. Write the number of grains on square n as 2^(n−1). Solve 2^(n−1) = 1024 to find which square has 1024 grains.

## Memorable takeaways
- Exponential equations have the variable in the exponent.
- Same-base strategy: rewrite both sides with the same base, then equate exponents.
- Know your powers: 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024.
- Negative exponents give fractions: 2⁻³ = 1/8.
- Always verify by substituting back.

## Watch out for these traps
- **Trying to solve exponentials like quadratics.** 2ˣ = 16 is NOT solved by "square rooting" — you need the same-base method.
- **Wrong base identification.** 4ˣ = 8: don't try base 4 — use base 2 (4 = 2², 8 = 2³).
- **Forgetting index laws.** (2³)ˣ = 2³ˣ, not 2^(3+x). Power of a power multiplies exponents.
- **Assuming all exponentials are solvable by same-base.** Equations like 2ˣ = 5 need logarithms (beyond this level).

A note on certainty. The same-base method is logically exact — it relies on the fact that exponential functions are one-to-one (each output corresponds to exactly one input). When both sides can be expressed with the same base, the solution is exact. When they cannot, numerical or logarithmic methods are needed, but the existence and uniqueness of the solution is guaranteed by the one-to-one property.

**Quick checks (Core content)**
1. *Which is exponential?* 5ˣ = 125 is exponential (variable in exponent). x⁵ = 32 is a power equation.
2. *Solve 3ˣ = 81.* 81 = 3⁴, so x = 4.
3. *Solve 9ˣ = 27.* (3²)ˣ = 3³ → 2x = 3 → x = 3/2. Check: 9^(3/2) = (√9)³ = 27 ✓.
4. *Solve 5ˣ = 1/25.* 1/25 = 5⁻², so x = −2.
5. *Solve 4^(x−1) = 8.* (2²)^(x−1) = 2³ → 2(x−1) = 3 → 2x − 2 = 3 → x = 5/2. Check: 4^(3/2) = (√4)³ = 8 ✓.
6. *Bacteria.* t = 7 hours (worked through in example).
7. *Can 3ˣ = 20 be solved by same-base?* No — 20 is not a power of 3. This requires logarithms or graphical methods.

**Try these scenarios**
1. *Investment.* 1000 × 2^(t/10) = 8000 → 2^(t/10) = 8 = 2³ → t/10 = 3 → t = 30 years.
2. *Waste.* 50000 × 3^(t/20) = 450000 → 3^(t/20) = 9 = 3² → t/20 = 2 → t = 40 years.
3. *Radioactive tracer.* 800 × (1/2)^(t/6) = 25 → (1/2)^(t/6) = 25/800 = 1/32 = (1/2)⁵ → t/6 = 5 → t = 30 hours.
4. *Viral sharing.* 3¹⁵ = 14,348,907 ≈ 14.3 million. Not enough to reach 26 million — the claim is inaccurate. Also assumes zero overlap and perfect sharing, which is unrealistic.
5. *Chess grains.* 2^(n−1) = 1024 = 2¹⁰ → n − 1 = 10 → n = 11. Square 11 has 1024 grains.
