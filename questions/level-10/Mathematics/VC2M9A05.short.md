# VC2M9A05 — Mathematics (Short)

## Snapshot
- **Descriptor:** Identify and graph quadratic functions, solve quadratic equations graphically and numerically, and use null factor law to solve monic quadratic equations with integer roots algebraically.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Quadratics produce parabolas. Null factor law: if ab = 0 then a = 0 or b = 0. Factorising gives x-intercepts (roots).

## What you are learning
- You are learning to **identify, graph and solve quadratic functions** using factorisation and the null factor law.
- You should connect algebraic solutions to graphical features of the parabola.

## Core content

**Quadratic functions.** y = ax² + bx + c (a ≠ 0). Graph is a parabola: opens up if a > 0, down if a < 0. Key features: vertex (turning point), axis of symmetry, x-intercepts (roots), y-intercept (= c).

**Graphing from a table.** Choose x-values, calculate y, plot points. The vertex lies midway between the x-intercepts. For y = x² − 4x + 3: roots at x = 1, 3; vertex at (2, −1).

**Factorising monic quadratics.** For x² + bx + c: find two numbers that multiply to c and add to b. Example: x² − 6x + 8 → numbers −2, −4 → (x − 2)(x − 4).

**Null factor law.** If ab = 0 then a = 0 or b = 0. To solve (x − 2)(x − 4) = 0: x = 2 or x = 4. These are the x-intercepts.

**Worked example.** Football height: h = −x² + 8x. Set h = 0: −x(x − 8) = 0 → x = 0 or x = 8 (lands 8 m away). Vertex at x = 4: h = −16 + 32 = 16 m (maximum height).

**Graphing software.** Use Desmos or GeoGebra to verify roots, find vertices, and explore quadratics that don't factorise over integers.

**Victorian and cultural context.** Melbourne's MCG roof, Bolte Bridge cables and fountain jets follow parabolic paths. VicRoads models road crests with quadratic curves. Boomerang flight paths include parabolic segments — the relationship between launch angle and distance is quadratic. Parabolic satellite dishes across Melbourne's suburbs connect families to international broadcasts.

## Memorable takeaways
- Quadratic → parabola. a > 0: opens up. a < 0: opens down.
- Factorise x² + bx + c: two numbers that multiply to c and add to b.
- Null factor law: (x − p)(x − q) = 0 means x = p or x = q.
- Vertex is midway between the roots. y-intercept is c.

## Watch out for these traps
- "I found factors that multiply to c but don't add to b." Both conditions must hold.
- "I only found one solution." Check both factors — null factor law gives two possible solutions.
- "I assumed every quadratic factorises with integers." Some don't — use the discriminant or graphing tools for non-integer roots.

## Model responses

Use these to check your thinking after you have had a go.

- *Which are quadratic: y = 3x² − 2x + 1, y = 5x − 7, y = x² + 4?* First and third (both have x² term).
- *Factorise x² + 5x + 6?* (x + 2)(x + 3). Check: 2 × 3 = 6, 2 + 3 = 5. ✓
- *Solve x² + x − 12 = 0?* (x + 4)(x − 3) = 0 → x = −4 or x = 3.
- *Ball: h = −t² + 6t, when does it land?* −t(t − 6) = 0 → t = 6 seconds. Max height at t = 3: h = 9 m.
- *Arch: y = −0.1x² + 2x, span and max height?* Span: x = 0 to x = 20 → 20 m. Max at x = 10: y = 10 m.
