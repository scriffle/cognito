# VC2M10ASP04 — Mathematics

## Snapshot
- **Descriptor:** VC2M10ASP04. Solve simple trigonometric equations.
- **Year level / Learning area:** Years 9–10 Advanced, Mathematics (Space).
- **Big ideas:**
  - Trigonometric equations can have multiple solutions within a given domain because sin(θ) = sin(180° − θ) and cos(θ) = cos(360° − θ).
  - The unit circle provides a systematic method for identifying all solutions in 0° ≤ x ≤ 360°.
  - Solving trig equations is essential for modelling periodic phenomena such as tides, sound and alternating current.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **solve simple trigonometric equations** and to identify all solutions within a specified domain.
- You are learning to use the unit circle and symmetry properties to find multiple solutions systematically.

By the end of this you should be able to:
- Solve equations of the form sin(x) = k, cos(x) = k and tan(x) = k for 0° ≤ x ≤ 360°.
- Use the ASTC rule to determine which quadrants contain solutions.
- Rearrange equations such as 2sin(x) − 1 = 0 before solving.
- Identify when an equation has 0, 1 or 2 solutions in the given domain.
- Interpret solutions in context (e.g. times when a periodic quantity reaches a given value).

## Core content

**1. Solving sin(x) = k.** For −1 ≤ k ≤ 1, use inverse sine to find the reference angle α = sin⁻¹(k). Solutions in 0° ≤ x ≤ 360°: x = α (Q1) and x = 180° − α (Q2) when k > 0. When k < 0: x = 180° − α and x = 360° + α (noting α is negative). For sin(x) = 0.5: α = 30°, so x = 30° or x = 150°. *Quick check:* Solve sin(x) = √3/2 for 0° ≤ x ≤ 360°.

**2. Solving cos(x) = k.** Reference angle α = cos⁻¹(|k|). When k > 0: x = α (Q1) and x = 360° − α (Q4). When k < 0: x = 180° − α (Q2) and x = 180° + α (Q3). For cos(x) = −√2/2: α = 45°, so x = 135° or x = 225°. *Quick check:* Solve cos(x) = −½ for 0° ≤ x ≤ 360°.

**3. Solving tan(x) = k.** Reference angle α = tan⁻¹(|k|). Tan is positive in Q1 and Q3; negative in Q2 and Q4. Solutions are always 180° apart. For tan(x) = 1: α = 45°, so x = 45° or x = 225°. For tan(x) = −√3: α = 60°, so x = 120° or x = 300°. *Quick check:* Solve tan(x) = −1 for 0° ≤ x ≤ 360°.

**4. Equations requiring rearrangement.** Many equations require algebraic manipulation before the trig equation can be solved. For 2sin(x) − 1 = 0: rearrange to sin(x) = ½, then solve as in Section 1. For √2·cos(x) + 1 = 0: cos(x) = −1/√2 = −√2/2, then solve as in Section 2. *Quick check:* Solve 2cos(x) + √3 = 0 for 0° ≤ x ≤ 360°.

**5. Boundary and special cases.** Some equations have exactly one solution or no solution. sin(x) = 1 has one solution: x = 90°. sin(x) = 0 has three solutions in 0° ≤ x ≤ 360°: x = 0°, 180°, 360°. sin(x) = 2 has no solution (|k| > 1). These cases correspond to extreme or impossible positions on the unit circle. *Quick check:* How many solutions does cos(x) = −1 have for 0° ≤ x ≤ 360°?

**6. Worked example — using the unit circle systematically.**
Solve sin(x) = −0.5 for 0° ≤ x ≤ 360°.

*Follow the thinking:*
- Reference angle: sin⁻¹(0.5) = 30°.
- sin is negative in Q3 and Q4.
- Q3: x = 180° + 30° = 210°.
- Q4: x = 360° − 30° = 330°.
- Solutions: x = 210° or x = 330°.

**7. Interpreting solutions in context.** Trigonometric equations arise in modelling periodic phenomena. If a tide height is modelled by h(t) = 3 + 2sin(30t°), finding when h = 4 requires solving 2sin(30t°) = 1, so sin(30t°) = 0.5. The solutions for 30t give the times at which the tide reaches that height. Multiple solutions correspond to the tide reaching the same height at different times in the cycle. *Quick check:* A temperature model gives T = 20 + 5sin(15t°). Find the values of t (0 ≤ t ≤ 24) when T = 22.5.

## Victorian and cultural context

- **Victorian anchor.** Trigonometric equations are central to electrical engineering (AC circuit analysis), acoustics and telecommunications — industries with strong Victorian presence. VCE Mathematical Methods develops these skills extensively.
- **Aboriginal and Torres Strait Islander perspective.** Periodic natural cycles — tidal patterns, seasonal changes, lunar phases — have been observed and predicted by First Nations peoples for millennia. The mathematical formalisation of "when does this periodic quantity reach a given value?" connects to this deep predictive tradition.
- **Multicultural Australian perspective.** Indian mathematicians including Madhava of Sangamagrama (14th century) developed series expansions for trigonometric functions, laying groundwork for solving trig equations analytically. Islamic astronomers routinely solved trig equations for celestial calculations.

## Try these scenarios

1. **Everyday.** A Ferris wheel's height is h = 15 + 10sin(θ°). Find the angles θ (0° ≤ θ ≤ 360°) when the height is 20 m.
2. **Civic.** Daylight hours in Melbourne are modelled by D = 12 + 2.5sin(30(t − 3)°). In which months does Melbourne receive exactly 12 hours of daylight?
3. **Vocational.** An electrician solves 340sin(x°) = 170 to find when AC voltage reaches 170 V. Find all solutions for 0° ≤ x ≤ 360°.
4. **Ethical.** A student solves sin(x) = 0.6 and gets only x = 36.9°. Explain the error and find the missing solution.
5. **Cross-cultural.** Research Madhava's trigonometric series. Then solve: 2sin(x) − √3 = 0 and √2·cos(x) = −1 for 0° ≤ x ≤ 360°.

## Memorable takeaways
- sin(x) = k and cos(x) = k typically have two solutions in 0°–360° (when |k| < 1).
- tan(x) = k always has two solutions in 0°–360°, separated by 180°.
- Use ASTC to determine which quadrants contain solutions.
- Always find the reference angle first, then place it in the correct quadrant(s).
- Rearrange before solving: isolate the trig function first.

## Watch out for these traps
- **Finding only one solution.** sin(x) = k and cos(x) = k usually have two solutions — check both relevant quadrants.
- **Wrong quadrant placement.** Use ASTC carefully: sin positive in Q1 and Q2, cos positive in Q1 and Q4.
- **Forgetting to rearrange first.** Isolate the trig function before finding the reference angle.
- **Calculator in radians.** Ensure degree mode for problems stated in degrees.
