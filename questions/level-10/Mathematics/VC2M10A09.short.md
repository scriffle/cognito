# VC2M10A09 — Mathematics (Short)

## Snapshot
- **Descriptor:** Solve simultaneous linear equations, using algebraic and graphical techniques including using digital tools.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Two linear equations with two unknowns have a solution that satisfies both at once. Graphically it is the intersection point. Algebraically, substitution and elimination are systematic methods.

## What you are learning
- You are learning to **solve simultaneous linear equations** using **substitution, elimination and graphical methods**.
- You should interpret the solution as the intersection of two lines and verify by substituting back.

## Core content

**Simultaneous equations** must be true at the same time. The solution (x, y) satisfies both.

**Substitution:** Isolate one variable, substitute into the other. y = 2x + 1 and 3x + y = 11 → 3x + 2x + 1 = 11 → x = 2, y = 5.

**Elimination:** Make coefficients match, add/subtract to eliminate one variable. 2x + 3y = 12 and 4x − 3y = 6 → add: 6x = 18 → x = 3, y = 2.

**Graphical:** Plot both lines; the intersection is the solution. Limitation: precision depends on scale.

**Worked example.** Concert tickets: 2x + 3y = 36, 4x + y = 44. Multiply first by 2: 4x + 6y = 72. Subtract second: 5y = 28 → y = $5.60, x = $9.60. Check in both equations ✓.

**Special cases:** Parallel lines → no solution (contradiction like 0 = 7). Identical lines → infinitely many solutions.

**Victorian context.** VicRoads models intersecting traffic flows; Melbourne Metro Tunnel used constraint equations for alignment. Chinese mathematicians solved systems over 2,000 years ago in the "Nine Chapters."

## Memorable takeaways
- Simultaneous = satisfies both equations at the same time.
- Graphically: intersection point. Algebraically: substitution or elimination.
- Always check by substituting into both original equations.
- Parallel lines → no solution. Identical lines → infinite solutions.

## Watch out for these traps
- Arithmetic errors in elimination — multiply every term including the constant.
- Adding when you should subtract (same-sign coefficients → subtract).
- Misreading graphical intersections — use algebra for precision.
