# VC2M9A07 — Mathematics (Short)

## Snapshot
- **Descriptor:** Experiment with the effects of the variation of parameters on graphs of related functions, using digital tools, making connections between graphical and algebraic representations, and generalising emerging patterns.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Parameters (a, h, k) in function equations control transformations. a stretches/reflects, h shifts horizontally (opposite sign), k shifts vertically. Digital tools with sliders make these effects visible. The same rules apply to all function families.

## What you are learning
- You are learning to **experiment with parameters** and observe their effects on graphs using digital tools.
- You should generalise the algebra-graph connection across function types.

## Core content

**Parameters.** In y = a(x−h)² + k: a = stretch/reflection, h = horizontal shift, k = vertical shift. Vertex at (h, k).

**Parameter a.** |a| > 1: narrower (stretched). 0 < |a| < 1: wider (compressed). a < 0: reflected in x-axis. y = 2x² narrower than y = x²; y = −x² flipped.

**Parameter h.** y = f(x−h): shifts RIGHT h units. (x−3) shifts right 3. (x+2) shifts left 2. Sign is OPPOSITE.

**Parameter k.** y = f(x) + k: shifts UP k units. Negative k shifts down.

**Combined.** y = −2(x+1)² + 5: vertex (−1, 5), opens down, narrower than standard.

**Worked example (Desmos).** Sliders for a, h, k on y = a(x−h)² + k. Slide a: shape changes. Slide h: horizontal position. Slide k: vertical position. Same patterns for exponentials, hyperbolas, square roots.

**Generalisation.** For ANY function y = af(x−h) + k: a controls shape/direction, h controls horizontal position (opposite sign), k controls vertical position (same sign). Universal across all function families.

**Victorian context.** Melbourne animation studios transform curves for motion paths. VCE Methods built on transformed functions. Desmos/GeoGebra standard in Victorian classrooms. Systematic parameter variation mirrors experimental approaches in land management — adjusting one factor, observing outcomes.

## Memorable takeaways
- a: stretch (|a|>1), compress (|a|<1), reflect (a<0).
- h: shift horizontally (opposite sign — (x−3) goes RIGHT).
- k: shift vertically (same sign — +5 goes UP).
- Rules are UNIVERSAL across all function families.
- Explore with sliders → generalise the pattern.

## Watch out for these traps
- (x−3) shifts RIGHT, not left. Sign is opposite to direction.
- a stretches/reflects; h and k shift position — don't confuse.
- 0 < a < 1 compresses (flatter), not stretches.
- Same rules apply to all functions — don't learn separate rules for each.

## Model responses

- *y = 2(x−3)² + 1: parameters.* a=2, h=3, k=1. Vertex (3,1), opens up, narrower.
- *a changes 1→3→−1 on y = ax².* Narrower → narrower still → reflected (opens down).
- *y = (x−4)².* Shifted 4 units right.
- *y = 2ˣ − 3 vs y = 2ˣ.* Down 3. Asymptote at y = −3.
- *Vertex of y = −2(x+1)² + 5.* (−1, 5). Opens down.
