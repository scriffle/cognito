## Core content

**1. What is a data structure?** A **data structure** is a way of organising data so it can be accessed and modified efficiently. A shopping list is a structure (ordered items). A phone book is a structure (names mapped to numbers). In programming: **lists** (ordered sequences), **dictionaries** (key–value pairs), and **2D arrays** (tables/grids). *Quick check:* Which data structure would you use to store student names paired with their scores?

**2. Lists (arrays).** A **list** stores items in order, accessed by index (position). In pseudocode: `scores ← [85, 72, 91, 68, 77]`. Access: `scores[0]` gives 85 (first item). Operations: append, remove, sort, search. *Quick check:* What does `scores[3]` return from the list above?

**3. Dictionaries (key–value pairs).** A **dictionary** maps keys to values. In pseudocode: `temps ← {"Mon": 22, "Tue": 19, "Wed": 24}`. Access: `temps["Tue"]` gives 19. Useful when you need to look up data by name rather than position. *Quick check:* How would you add "Thu": 21 to the dictionary above?

**4. Algorithms that process lists.** Common patterns: traverse (visit every item), search (find a specific item), accumulate (sum, average, count), filter (select items meeting a condition), sort (arrange in order). *Quick check:* Write pseudocode to find the maximum value in a list.

**5. Algorithms that process dictionaries.** Traverse all keys, look up values by key, update values, filter by condition on values. Example: find all days with temperature above 20.

```
FOR each day IN temps:
    IF temps[day] > 20 THEN
        OUTPUT day, temps[day]
```

*Quick check:* Modify this to find the coldest day.

**6. Worked example: calculating class statistics.**

A teacher stores 10 test scores in a list and wants the mean, highest and lowest.

*Follow the thinking (pseudocode):*
```
scores ← [78, 85, 62, 91, 74, 88, 56, 93, 70, 81]
total ← 0
highest ← scores[0]
lowest ← scores[0]

FOR each score IN scores:
    total ← total + score
    IF score > highest THEN highest ← score
    IF score < lowest THEN lowest ← score

mean ← total / LENGTH(scores)
OUTPUT "Mean:", mean, "Highest:", highest, "Lowest:", lowest
```

*In Python:*
```python
scores = [78, 85, 62, 91, 74, 88, 56, 93, 70, 81]
mean = sum(scores) / len(scores)
print(f"Mean: {mean}, Highest: {max(scores)}, Lowest: {min(scores)}")
```

**7. Choosing the right structure.** Lists when order matters or you process items sequentially. Dictionaries when you need fast lookup by name/key. 2D arrays (list of lists) for grid-based data (timetables, spreadsheets, game boards). *Quick check:* Which structure suits a timetable with rows for days and columns for periods?

## Memorable takeaways
- Data structures organise information for efficient processing.
- Lists: ordered, accessed by index. Dictionaries: key–value lookup.
- Common patterns: traverse, search, accumulate, filter, sort.
- Pseudocode first, then translate to code — this catches logic errors early.
- Choose the structure that matches how you need to access the data.

## Watch out for these traps
- "I started the index at 1." Most languages (Python, JavaScript) use zero-based indexing. `scores[0]` is the first item.
- "I used a list when a dictionary was better." If you need to look up data by name (not position), a dictionary is more appropriate and faster.
- "My algorithm works for my test data so it must be correct." Test with edge cases: empty list, all same values, one item, very large inputs.
- "I wrote code without pseudocode first." Pseudocode helps you think about logic without getting tangled in syntax errors.
