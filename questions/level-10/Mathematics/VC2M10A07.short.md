# VC2M10A07 — Mathematics (Short)

## Snapshot
- **Descriptor:** Solve problems involving linear equations, including those derived from formulas.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** A linear equation has the unknown to the first power. Solving means isolating the unknown with inverse operations. Many formulas become linear equations once you substitute known values.

## What you are learning
- You are learning to **solve linear equations** including those arising from real-world formulas and word problems.
- You should handle unknowns on both sides, brackets and fractions.

## Core content

**Linear equation:** unknown to the first power only. 3x + 7 = 22 is linear; x² + 1 = 10 is not.

**One/two-step:** 2x + 5 = 17 → 2x = 12 → x = 6. Use inverse operations on both sides.

**Unknown on both sides:** 5x + 3 = 2x + 18 → 3x = 15 → x = 5.

**Brackets:** expand first. 3(2x − 1) = 4(x + 5) → 6x − 3 = 4x + 20 → 2x = 23 → x = 11.5.

**Fractions:** multiply by LCD. (x+3)/4 = (2x−1)/6 → LCD 12: 3(x+3) = 2(2x−1) → 3x+9 = 4x−2 → x = 11.

**Worked example — plumber's bill.** C = 90 + 65h. Bill = $350. Equation: 350 = 90 + 65h → 260 = 65h → h = 4 hours. Check: 90 + 65(4) = 350 ✓.

**Setting up from words.** Define x, translate to algebra, solve, interpret in context, check.

**Victorian and cultural context.** Energy companies bill Victorians using C = supply charge + rate × kWh — a linear formula. VicRoads uses linear cost models for road pricing. Small-business owners across Melbourne's multicultural communities solve linear equations daily for break-even, pricing and wages.

## Memorable takeaways
- Linear = first power only.
- Inverse operations on both sides — keep balanced.
- Brackets: expand. Fractions: multiply by LCD.
- Always interpret and check your answer in context.

## Watch out for these traps
- "Subtracted from one side only." Both sides must get the same operation.
- "Expanded brackets wrong." 3(2x−1) = 6x−3, not 6x−1. Multiply every term.
- "Negative answer can't be right." Depends on context — hours can't be negative but temperatures can.
