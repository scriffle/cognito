# VC2M10A13 — Mathematics (Short)

## Snapshot
- **Descriptor:** Solve simple quadratic equations using a range of strategies, including null factor law.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** A quadratic (ax² + bx + c = 0) can have two, one or zero real solutions. The null factor law (if AB = 0, then A = 0 or B = 0) is the primary solving strategy. Other strategies include completing the square and the quadratic formula.

## What you are learning
- You are learning to **solve quadratic equations** using factorisation, the null factor law, and other strategies.
- You should rearrange to standard form, factorise, and apply the null factor law to find solutions.

## Core content

**Null factor law.** If (A)(B) = 0, then A = 0 or B = 0. Factorise first, then set each bracket to zero. Example: (x − 3)(x + 2) = 0 → x = 3 or x = −2.

**Factorising to solve.** x² + 5x − 14 = 0. Find two numbers multiplying to −14, adding to +5: +7, −2. So (x + 7)(x − 2) = 0 → x = −7 or x = 2.

**Special cases.** Difference of squares: x² − 16 = (x−4)(x+4) = 0 → x = ±4. Common factor: 3x² − 12x = 3x(x−4) = 0 → x = 0 or x = 4. Perfect square: x² − 6x + 9 = (x−3)² = 0 → x = 3 (repeated).

**Completing the square.** x² + 8x + 3 = 0 → (x+4)² − 13 = 0 → x = −4 ± √13.

**Quadratic formula.** x = (−b ± √(b²−4ac)) / 2a. Discriminant Δ = b²−4ac: positive → 2 solutions; zero → 1 solution; negative → no real solutions.

**Worked example — projectile.** h = −t² + 6t. When h = 0: −t(t−6) = 0 → t = 0 (launch) or t = 6 (landing). Ball airborne for 6 seconds.

**Victorian context.** Engineers modelling the Bolte Bridge cables use quadratic equations. AFL kick trajectories follow parabolic paths. The spatial reasoning about projectile paths connects to First Nations knowledge of throwing implements. Al-Khwarizmi (9th century Baghdad) invented "completing the square" geometrically.

## Memorable takeaways
- Standard form first: ax² + bx + c = 0.
- Null factor law: if (A)(B) = 0, then A = 0 or B = 0.
- Never divide by x — factor it out instead (or lose x = 0).
- Discriminant tells you how many solutions exist.
- Always check by substituting back.

## Watch out for these traps
- Forgetting to set the equation to zero before factorising.
- Dividing both sides by x (loses x = 0 as a solution).
- Giving only one solution when two exist.
- Not checking answers by substitution.

## Model responses

Use these to check your thinking after you have had a go.

- *Solve (x−7)(x+1) = 0.* x = 7 or x = −1.
- *Solve x² − 9x + 20 = 0.* (x−4)(x−5) = 0 → x = 4 or x = 5.
- *Solve x² − 25 = 0.* (x−5)(x+5) = 0 → x = ±5.
- *Complete the square: x² + 6x + 2 = 0.* (x+3)² = 7 → x = −3 ± √7.
- *Discriminant of 2x² + 3x − 5 = 0.* Δ = 9 + 40 = 49 > 0. Two solutions.
