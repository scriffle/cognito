## Core content

**1. What is a quadratic function?** A quadratic function has the form y = ax² + bx + c, where a ≠ 0. The highest power of x is 2. The graph is always a **parabola** — a U-shape (opens up if a > 0) or an inverted U (opens down if a < 0). *Quick check:* Which of these are quadratic? (i) y = 3x² − 2x + 1. (ii) y = 5x − 7. (iii) y = x² + 4.

**2. Key features of a parabola.** The **vertex** (turning point) is the highest or lowest point. The **axis of symmetry** is the vertical line through the vertex. The **x-intercepts** (roots/zeros) are where the parabola crosses the x-axis (y = 0). The **y-intercept** is where x = 0 (which is just c in y = ax² + bx + c). *Quick check:* For y = x² − 6x + 8, find the y-intercept.

**3. Graphing from a table.** Choose x-values either side of the vertex, calculate y, and plot. For y = x² − 4x + 3: try x = 0, 1, 2, 3, 4. Values: y = 3, 0, −1, 0, 3. The vertex is at x = 2 (axis of symmetry midway between roots x = 1 and x = 3), y = −1. *Quick check:* For y = x² − 2x − 3, find y when x = −1, 0, 1, 2, 3.

**4. Factorising monic quadratics.** A monic quadratic has the form x² + bx + c. To factorise, find two numbers that multiply to c and add to b. x² − 6x + 8: numbers that multiply to 8 and add to −6 are −2 and −4. So x² − 6x + 8 = (x − 2)(x − 4). *Quick check:* Factorise x² + 5x + 6.

**5. The null factor law.** If the product of two factors equals zero, then at least one factor must be zero: if ab = 0, then a = 0 or b = 0. To solve x² − 6x + 8 = 0: factorise to (x − 2)(x − 4) = 0. Then x − 2 = 0 → x = 2 or x − 4 = 0 → x = 4. The solutions are x = 2 and x = 4. These are the x-intercepts of the parabola. *Quick check:* Solve x² + x − 12 = 0 by factorising.

**6. Worked example: modelling a kicked football.**

A football's height is modelled by h = −x² + 8x, where x is horizontal distance in metres and h is height in metres.

*Follow the thinking:*
- Find x-intercepts: set h = 0. −x² + 8x = 0 → −x(x − 8) = 0 → x = 0 or x = 8. Ball lands 8 m away.
- Axis of symmetry: midway between roots = (0 + 8)/2 = 4.
- Vertex: at x = 4, h = −16 + 32 = 16. Maximum height is 16 m.
- y-intercept: h(0) = 0. Ball starts at ground level. ✓
- The parabola opens downward (a = −1 < 0) — makes sense for a ball that goes up then comes down.

**7. Using graphing software.** Desmos, GeoGebra and other tools let you enter a quadratic and instantly see the parabola, vertex, and intercepts. Use them to check your algebraic work, explore how changing a, b and c affects the graph, and solve equations graphically (find where the curve crosses the x-axis). Graphical solutions can find approximate roots even when algebraic factorisation is not possible. *Quick check:* Use Desmos to graph y = x² − 3x − 2. How many x-intercepts does it have? Can you factorise this with integers?

## Victorian and cultural context

- **Victorian anchor.** The parabolic arch appears throughout Melbourne's architecture — the MCG's roof structure, the Bolte Bridge cable profiles, and fountain water jets at Southbank all follow quadratic paths. Engineers model projectile motion with quadratics: VicRoads uses parabolic curves for road crests and dips to ensure driver sightlines.
- **Aboriginal and Torres Strait Islander perspective.** The flight path of a thrown boomerang includes parabolic segments — the relationship between launch angle, distance and height can be modelled using quadratic functions. Spear trajectories, the arc of thrown stones for hunting, and the curved profiles of coolamon vessels all demonstrate parabolic forms in First Nations design and practice. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Parabolic satellite dishes for international broadcasting are ubiquitous across Melbourne's suburbs. The physics of cricket and soccer — ball trajectories — follow quadratic models familiar to communities from every cricketing and footballing nation.

## Try these scenarios

1. **Everyday.** A ball is thrown upward with height h = −t² + 6t (h in metres, t in seconds). When does it hit the ground? What is the maximum height and when does it occur?
2. **Civic.** A council designs a parabolic arch for a pedestrian bridge. The arch is modelled by y = −0.1x² + 2x where x and y are in metres. Find the span of the arch (distance between x-intercepts) and the maximum height.
3. **Vocational.** A landscaper is designing a rectangular garden bed against a wall. She has 20 m of edging for the three open sides. If the width is x metres, the area is A = x(20 − 2x) = −2x² + 20x. Find the dimensions that maximise the area.
4. **Ethical.** A company models profit as P = −x² + 40x − 300 where x is the price in dollars. Find the break-even prices (where P = 0) and the price that maximises profit. Discuss whether maximising profit should always be the goal.
5. **Cross-cultural.** A cricket ball is hit at an angle, following the path y = −0.02x² + x where x is horizontal distance and y is height (both in metres). Find how far the ball travels before landing and its maximum height. Compare this to a soccer ball following y = −0.05x² + x.

## Memorable takeaways
- Quadratic = parabola. a > 0 opens up; a < 0 opens down.
- To factorise x² + bx + c: find two numbers that multiply to c and add to b.
- Null factor law: if (x − p)(x − q) = 0, then x = p or x = q.
- The x-intercepts (roots) are where y = 0. The vertex is midway between them.
- y-intercept is c (the constant term).

## Watch out for these traps
- "I forgot that a quadratic can have 0, 1 or 2 x-intercepts." Not every parabola crosses the x-axis. If the discriminant is negative or the quadratic doesn't factorise over integers, there may be no integer roots.
- "I found factors that multiply to c but didn't check they add to b." You need both conditions: multiply to c AND add to b.
- "I only found one solution." The null factor law gives a = 0 OR b = 0 — check both factors.
- "I confused the vertex with the y-intercept." The vertex is at x = −b/(2a) or midway between roots. The y-intercept is at x = 0.

A note on certainty. Quadratic functions and the null factor law are established algebra. Real-world phenomena (projectile motion, areas) are modelled by quadratics under simplifying assumptions (no air resistance, flat ground). The model is useful within its domain of validity.

**Quick checks (Core content)**

1. *Which are quadratic?* (i) Yes — x² term, a = 3. (ii) No — highest power is 1 (linear). (iii) Yes — x² term, a = 1.
