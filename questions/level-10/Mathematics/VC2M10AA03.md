# VC2M10AA03 — Mathematics

## Snapshot
- **Descriptor:** VC2M10AA03. Simplify combinations of linear expressions with rational coefficients and solve equations with algebraic fractions.
- **Year level / Learning area:** Years 9–10 Advanced, Mathematics (Algebra).
- **Big ideas:**
  - Rational coefficients (fractions) follow the same algebraic rules as integers — common denominators, distribution and cancellation still apply.
  - Solving equations with algebraic fractions requires clearing denominators by multiplying through by the lowest common denominator (LCD).
  - Solutions must be checked to ensure no denominator equals zero.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **simplify linear expressions involving rational (fractional) coefficients** and to **solve equations that contain algebraic fractions**.
- You are learning to work fluently with fractions in algebraic contexts, applying LCD techniques and verifying that solutions are valid.

By the end of this you should be able to:
- Simplify expressions such as ⅔(6x − 9) + ¾(8x + 4).
- Find the lowest common denominator of algebraic fractions.
- Solve equations involving one or more algebraic fractions.
- Check that solutions do not make any denominator zero.
- Rearrange complex formulas that contain fractions.

## Core content

**1. Simplifying with rational coefficients.** To simplify ⅔(6x − 9) + ¾(8x + 4), distribute each fraction: ⅔ × 6x = 4x, ⅔ × (−9) = −6, ¾ × 8x = 6x, ¾ × 4 = 3. Combining: 4x − 6 + 6x + 3 = 10x − 3. The key is careful distribution and collection of like terms. *Quick check:* Simplify ½(4x + 6) − ⅓(9x − 3).

**2. Finding the LCD of algebraic fractions.** The lowest common denominator of algebraic fractions is the smallest expression divisible by each denominator. For (2x − 1)/3 and (x + 2)/4, the LCD is 12. For x/a and 1/(a + 1), the LCD is a(a + 1). Finding the LCD allows fractions to be combined or equations to be cleared. *Quick check:* What is the LCD of (x + 1)/6 and (2x − 3)/4?

**3. Adding and subtracting algebraic fractions.** Convert each fraction to the common denominator, then combine numerators. For (2x − 1)/3 − (x + 2)/4: LCD = 12. Rewrite as [4(2x − 1) − 3(x + 2)]/12 = (8x − 4 − 3x − 6)/12 = (5x − 10)/12. This may simplify further: 5(x − 2)/12. *Quick check:* Simplify (3x + 1)/5 + (x − 4)/3.

**4. Solving equations with algebraic fractions.** Multiply every term by the LCD to clear all denominators. For (2x − 1)/3 − (x + 2)/4 = 1: multiply by 12. 4(2x − 1) − 3(x + 2) = 12. Expand: 8x − 4 − 3x − 6 = 12. Simplify: 5x − 10 = 12, so 5x = 22, x = 22/5 = 4.4. *Quick check:* Solve (x + 3)/2 − (x − 1)/5 = 4.

**5. Checking for excluded values.** When a variable appears in a denominator, certain values make the denominator zero and are excluded from the domain. For 3/(x − 2) = 5, solving gives x = 2.6, which is valid since x ≠ 2. If solving produces x = 2, that value must be rejected — the equation has no solution. *Quick check:* For the equation 4/(x + 1) = 2/(x − 3), what values of x are excluded?

**6. Worked example — solving a multi-fraction equation.**
Solve: x/2 + (x + 1)/3 = (2x − 1)/4.

*Follow the thinking:*
- LCD of 2, 3, 4 is 12.
- Multiply every term by 12: 6x + 4(x + 1) = 3(2x − 1).
- Expand: 6x + 4x + 4 = 6x − 3.
- Simplify: 10x + 4 = 6x − 3.
- Rearrange: 4x = −7, so x = −7/4 = −1.75.
- Check: (−7/4)/2 + (−3/4)/3 = (−7/8) + (−1/4) = −7/8 − 2/8 = −9/8. And (2(−7/4) − 1)/4 = (−7/2 − 1)/4 = (−9/2)/4 = −9/8 ✓.

**7. Rearranging formulas with fractions.** Many formulas in physics and engineering contain fractions. For 1/f = 1/u + 1/v (lens equation), solving for f requires combining the right side over a common denominator uv: 1/f = (v + u)/(uv), so f = uv/(u + v). *Quick check:* Rearrange 1/R = 1/R₁ + 1/R₂ to make R the subject.

## Victorian and cultural context

- **Victorian anchor.** Physics and engineering courses at Victorian universities use algebraic fraction manipulation extensively in optics, circuit analysis and fluid dynamics. The lens formula 1/f = 1/u + 1/v is a standard VCE Physics application.
- **Aboriginal and Torres Strait Islander perspective.** Proportional reasoning — the conceptual foundation for working with fractions — is embedded in the resource-sharing practices and trade systems of First Nations peoples across Australia.
- **Multicultural Australian perspective.** The systematic treatment of equations involving fractions has roots in the work of Indian mathematician Brahmagupta (7th century CE) and the algebraic traditions of the Islamic Golden Age.

## Try these scenarios

1. **Everyday.** A recipe requires ⅔ cup of flour per serve and ¾ cup of sugar per serve. Write and simplify an expression for the total dry ingredients for x serves.
2. **Civic.** A council divides funding between two projects: (x + 500)/3 thousand dollars to project A and (2x − 100)/5 thousand to project B. Write a simplified expression for the total funding.
3. **Vocational.** Two resistors in parallel have combined resistance given by 1/R = 1/R₁ + 1/R₂. If R₁ = x and R₂ = x + 4, express R as a single fraction.
4. **Ethical.** A student solves 5/(x − 3) = 5/(x − 3) and claims x can be any number. Identify the error.
5. **Cross-cultural.** Research Brahmagupta's contributions to algebra. Then solve: (3x + 2)/4 − (x − 5)/6 = 3.

## Memorable takeaways
- Distribute fractional coefficients carefully — treat each term inside the brackets.
- The LCD clears all denominators at once — multiply every term, not just some.
- Always check that solutions do not make any denominator zero.
- Algebraic fractions follow the same rules as numerical fractions.
- Rearranging formulas with fractions is a core skill for physics and engineering.

Show all working and verify by substitution. 250–300 words.

## Watch out for these traps
- **Multiplying only some terms by the LCD.** Every term in the equation — including any that are not fractions — must be multiplied.
- **Sign errors when distributing negatives.** In (2x − 1)/3 − (x + 2)/4, the subtraction applies to the entire second fraction: −3(x + 2), not −3x + 6.
- **Forgetting excluded values.** If x appears in a denominator, state the restriction before solving.
- **Cancelling incorrectly.** Only factors (not terms) can be cancelled: (x + 3)/x ≠ 1 + 3 = 4.

## Model responses

Use these to check your own thinking after you have had a go.

**Quick checks (Core content)**
1. *Simplify ½(4x + 6) − ⅓(9x − 3).* = 2x + 3 − 3x + 1 = −x + 4.
2. *LCD of (x + 1)/6 and (2x − 3)/4.* LCD = 12.
3. *Simplify (3x + 1)/5 + (x − 4)/3.* LCD = 15. [3(3x + 1) + 5(x − 4)]/15 = (9x + 3 + 5x − 20)/15 = (14x − 17)/15.
4. *Solve (x + 3)/2 − (x − 1)/5 = 4.* LCD = 10. 5(x + 3) − 2(x − 1) = 40. 5x + 15 − 2x + 2 = 40. 3x + 17 = 40. 3x = 23. x = 23/3.
5. *Excluded values for 4/(x + 1) = 2/(x − 3).* x ≠ −1 and x ≠ 3.
6. *Worked example.* x = −7/4. Verified by substitution.
7. *Rearrange 1/R = 1/R₁ + 1/R₂.* 1/R = (R₂ + R₁)/(R₁R₂). R = R₁R₂/(R₁ + R₂).

**Try these scenarios**
1. *Recipe.* Total per serve = ⅔x + ¾x = (8x + 9x)/12 = 17x/12 cups. (Or: ⅔ + ¾ = 17/12 per serve, so 17x/12 total.)
2. *Council funding.* (x + 500)/3 + (2x − 100)/5. LCD = 15. [5(x + 500) + 3(2x − 100)]/15 = (5x + 2500 + 6x − 300)/15 = (11x + 2200)/15.
3. *Parallel resistance.* 1/R = 1/x + 1/(x + 4) = (x + 4 + x)/[x(x + 4)] = (2x + 4)/[x(x + 4)]. R = x(x + 4)/(2x + 4) = x(x + 4)/[2(x + 2)].
4. *Student error.* The equation 5/(x − 3) = 5/(x − 3) is true for all x except x = 3 (excluded value). The student forgot to exclude x = 3.
5. *Solve (3x + 2)/4 − (x − 5)/6 = 3.* LCD = 12. 3(3x + 2) − 2(x − 5) = 36. 9x + 6 − 2x + 10 = 36. 7x + 16 = 36. 7x = 20. x = 20/7.

**Stretch task — example shape of a strong answer.** (a) 1/f = (v + u)/(uv), so f = uv/(u + v). (b) f = (x + 2)(2x − 1)/[(x + 2) + (2x − 1)] = (x + 2)(2x − 1)/(3x + 1). (c) 3 = (x + 2)(2x − 1)/(3x + 1). 3(3x + 1) = (x + 2)(2x − 1). 9x + 3 = 2x² + 3x − 2. 2x² − 6x − 5 = 0. x = (6 ± √76)/4 = (3 ± √19)/2. (d) Excluded: x = −2 (u = 0), x = ½ (v = 0), x = −⅓ (u + v = 0).
