# VC2M10AA08 — Mathematics (Short)

## Snapshot
- **Descriptor:** Use function notation like f(x) to describe relationships between dependent and independent variables.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** f(x) names the function and specifies the input variable. f(a) means substitute x = a. Function notation enables precise communication about evaluating, comparing and transforming functions.

## What you are learning
- You are learning to **use function notation** to define, evaluate and communicate mathematical relationships.
- You should be able to evaluate f(a), interpret f(x) = 0, and describe transformations using function notation.

## Core content

**Function notation:** f(x) = 3x² − 2x + 1 names the function f with input x. This is not f times x.

**Evaluating:** f(4) = 3(16) − 8 + 1 = 41. Substitute x = 4 into the rule.

**Algebraic inputs:** f(x + h) replaces every x with (x + h). For f(x) = x²: f(x + h) = (x + h)² = x² + 2xh + h².

**Solving f(x) = 0:** Finds x-intercepts. For f(x) = x² − 5x + 6: x = 2 or x = 3.

**Real-world notation:** C(d) = 3.50 + 2.10d models taxi cost. C(12) = $28.70.

**Transformations:** g(x) = f(x − 3) + 2 shifts right 3, up 2. −f(x) reflects in x-axis; f(−x) reflects in y-axis.

**Victorian context.** Function notation is standard from VCE onward. Euler (18th century) formalised the f(x) convention used universally in mathematics, science and engineering.

## Memorable takeaways
- f(x) is not multiplication — it means "function f evaluated at x."
- f(a) means substitute x = a into the rule.
- f(a + b) ≠ f(a) + f(b) in general.
- Solving f(x) = 0 finds x-intercepts; f(a) = k finds inputs giving output k.

## Watch out for these traps
- Treating f(x) as f × x.
- Assuming f(a + b) = f(a) + f(b) — this is generally false.
- Forgetting parentheses when substituting negatives: f(−2) requires (−2)², not −2².
