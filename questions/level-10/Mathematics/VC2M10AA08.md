## Core content

**1. What is function notation?** Function notation replaces "y = …" with "f(x) = …" to name the function and its input explicitly. In f(x) = 3x² − 2x + 1, f is the name of the function and x is the independent variable. The notation f(x) represents the output (dependent variable) when x is the input. Other letters may be used: g(t), h(n), C(x). *Quick check:* Write the rule "y equals five x minus three" in function notation.

**2. Evaluating f(a).** To find f(a), substitute x = a into the rule. For f(x) = 3x² − 2x + 1: f(4) = 3(16) − 2(4) + 1 = 48 − 8 + 1 = 41. Similarly, f(−2) = 3(4) − 2(−2) + 1 = 12 + 4 + 1 = 17. Evaluation is substitution. *Quick check:* Given f(x) = x² − 3x + 2, find f(5) and f(−1).

**3. Function notation with algebraic inputs.** f(x + h) means "replace every x in the rule with (x + h)." For f(x) = x²: f(x + h) = (x + h)² = x² + 2xh + h². This is used extensively in calculus to compute rates of change. *Quick check:* Given f(x) = 2x + 1, find f(x + 3) and simplify.

**4. Solving f(x) = 0.** Setting f(x) = 0 finds the x-values where the function's output is zero — the x-intercepts of the graph. For f(x) = x² − 5x + 6: f(x) = 0 gives x² − 5x + 6 = 0, so (x − 2)(x − 3) = 0, giving x = 2 or x = 3. *Quick check:* Solve f(x) = 0 for f(x) = x² − 9.

**5. Real-world function notation.** A taxi fare is modelled by C(d) = 3.50 + 2.10d, where d is distance in kilometres and C is cost in dollars. C(12) = 3.50 + 25.20 = 28.70: a 12 km trip costs $28.70. The notation clarifies what varies (d) and what the function produces (cost). *Quick check:* Given C(n) = 50 + 8n (cost in dollars for n items), interpret C(20) and find n when C(n) = 130.

**6. Worked example — interpreting function behaviour.**
f(3) = 10 and f(5) = 18.

*Follow the thinking:*
- The function produces output 10 when the input is 3, and output 18 when the input is 5.
- The average rate of change between x = 3 and x = 5 is (18 − 10)/(5 − 3) = 8/2 = 4.
- This means the function increases by an average of 4 units per unit increase in x over this interval.
- No conclusion can be drawn about the function's behaviour outside this interval without more information.

**7. Function notation and transformations.** If f(x) = x², then g(x) = f(x − 3) + 2 means g(x) = (x − 3)² + 2 — a horizontal shift 3 right and vertical shift 2 up. Function notation makes transformations precise: f(−x) reflects in the y-axis; −f(x) reflects in the x-axis; af(x) stretches vertically by factor a. *Quick check:* If f(x) = x², write the rule for g(x) = −f(x + 1) − 4 in expanded form.

## Victorian and cultural context

- **Victorian anchor.** Function notation is the standard language of mathematics from VCE onward, used in every branch of applied mathematics, physics and engineering at Victorian universities and in STEM industries.
- **Aboriginal and Torres Strait Islander perspective.** The concept of input-output relationships — where a process transforms one quantity into another — is reflected in First Nations technologies such as fire-management, where controlled inputs (timing, wind direction) produce predictable ecological outcomes.
- **Multicultural Australian perspective.** The function concept was formalised by Leonhard Euler (18th century Switzerland) and Peter Lejeune Dirichlet (19th century Germany), though the idea of systematic input-output relationships has roots in mathematical traditions worldwide.

2. **Civic.** A council models park visitors as V(t) = −2t² + 24t (hundreds), where t is hours after 8 am. Find when the park has no visitors and when visitor numbers peak.

4. **Ethical.** A student writes f(2 + 3) = f(2) + f(3) = 41 + 17 = 58. Given f(x) = 3x² − 2x + 1, verify whether this is correct and explain any error.

## Memorable takeaways
- f(x) names both the function and its input — it is not "f times x."
- f(a) means substitute x = a; f(x + h) means substitute x = x + h.
- Solving f(x) = 0 finds the x-intercepts.
- Function notation makes transformations precise and unambiguous.
- Real-world contexts benefit from named functions: C(d), V(t), R(T).

## Stretch yourself
A company models its revenue as R(x) = −2x² + 100x (in thousands of dollars), where x is the price per unit. The cost function is C(x) = 20x + 200. (a) Define the profit function P(x) = R(x) − C(x). (b) Find P(0), P(20) and P(40) and interpret each. (c) Solve P(x) = 0 to find the break-even prices. (d) Complete the square to find the price that maximises profit and state the maximum profit. (e) Find and interpret P(x + 1) − P(x). 250–300 words.

## Watch out for these traps
- **Treating f(x) as multiplication.** f(x) is not f × x; it is the function f evaluated at x.
- **Assuming f(a + b) = f(a) + f(b).** This is generally false. For f(x) = x²: f(2 + 3) = f(5) = 25, but f(2) + f(3) = 4 + 9 = 13.
- **Confusing the function name with the variable.** In C(n) = 50 + 8n, C is the function name and n is the input. C is not a variable being multiplied.
- **Forgetting parentheses when substituting negatives.** f(−2) requires (−2)² = 4, not −2² = −4.

## Try drawing this
Draw a mapping diagram: list inputs (1, 2, 3, 4, 5) in a column on the left. Apply the rule f(x) = 2x − 1 to get outputs (1, 3, 5, 7, 9) in a column on the right. Draw arrows connecting each input to its output. This visualises the function as a mapping.

**Try these scenarios**
1. *Streaming.* M(1) = 15, M(4) = 24. For M(s) ≤ 30: 12 + 3s ≤ 30 → s ≤ 6.
2. *Park visitors.* V(t) = 0: −2t(t − 12) = 0, t = 0 or t = 12 (8 am and 8 pm). Peak at t = 6 (2 pm): V(6) = 72 hundred = 7200 visitors.
3. *Resistance.* R(25) = 100(1 + 0.1) = 110 Ω. R = 120: 120 = 100(1 + 0.004T) → 1.2 = 1 + 0.004T → T = 50°C.
4. *Student error.* f(5) = 3(25) − 10 + 1 = 66. But f(2) + f(3) = (12 − 4 + 1) + (27 − 6 + 1) = 9 + 22 = 31. f(2 + 3) ≠ f(2) + f(3). The function is not additive.
5. *Composition.* g(2) = 2(2) − 3 = 1. f(g(2)) = f(1) = 1 + 1 = 2. f(2) = 4 + 1 = 5. g(f(2)) = g(5) = 10 − 3 = 7.
