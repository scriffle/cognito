# VC2M10AA05 — Mathematics (Short)

## Snapshot
- **Descriptor:** Describe, interpret and sketch parabolas, hyperbolas, circles and exponential functions from their equations.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** Each function type has a characteristic equation and distinctive features. Key features (vertices, asymptotes, centres, intercepts) are identifiable directly from the equation. Transformations modify standard forms systematically.

## What you are learning
- You are learning to **recognise function types from equations** and to **sketch graphs** by identifying key features.
- You should be able to sketch parabolas, hyperbolas, circles and exponentials, and describe transformations.

## Core content

**Parabolas:** y = a(x − h)² + k has vertex (h, k), axis x = h. a > 0 opens up; a < 0 opens down. For y = (x − 2)² − 4: vertex (2, −4), opens upward.

**Hyperbolas:** y = a/x has asymptotes x = 0 and y = 0. a > 0 → quadrants 1, 3; a < 0 → quadrants 2, 4. Translated: y = a/(x − h) + k has asymptotes x = h, y = k.

**Circles:** (x − h)² + (y − k)² = r² has centre (h, k) and radius r. A circle is not a function (fails vertical line test).

**Exponentials:** y = aˣ has y-intercept (0, 1), asymptote y = 0. a > 1 → growth; 0 < a < 1 → decay.

**Transformations:** Inside the bracket affects x (opposite direction); outside affects y (same direction). y = −2(x − 1)² + 8: vertex (1, 8), reflected, narrower.

**Victorian context.** Parabolic arcs appear in Melbourne bridge design; circular geometry in the MCG; exponential models in Victorian urban planning. Apollonius of Perga (3rd century BCE) systematically studied conic sections.

## Memorable takeaways
- Squared terms → parabola or circle; reciprocal → hyperbola; base raised to x → exponential.
- Vertex form gives the vertex directly; circle form gives centre and radius directly.
- Inside-bracket shifts are opposite in direction to the sign.
- Asymptotes are lines the curve approaches but never touches.

## Watch out for these traps
- (x + 1)² means shift LEFT, not right — the sign inside is opposite.
- A circle is not a function — do not apply the vertical line test expectation.
- y = a/x is undefined at x = 0; the curve never passes through the origin.

## Model responses

Use these to check your thinking after you have had a go.

- *Vertex and direction of y = −(x + 1)² + 3.* Vertex (−1, 3), opens downward.
- *Asymptotes of y = 3/x.* x = 0 and y = 0; curve in quadrants 1 and 3.
- *Centre and radius of (x − 3)² + (y + 2)² = 16.* Centre (3, −2), radius 4.
- *y = (½)ˣ features.* y-intercept (0, 1), asymptote y = 0, decay.
- *Transformations y = x² → y = 2(x − 4)² − 1.* Stretch ×2, right 4, down 1.
- *Curve through (0,1), always positive, approaches x-axis.* Exponential function.
