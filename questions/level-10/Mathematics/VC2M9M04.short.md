# VC2M9M04 — Mathematics (Short)

## Snapshot
- **Descriptor:** Calculate and interpret absolute, relative and percentage errors in measurements.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Every measurement has uncertainty. Absolute error = |measured − true| or ± half smallest unit. Relative error = absolute/measured. Percentage error = relative × 100%.

## What you are learning
- You are learning to **calculate and interpret** absolute, relative and percentage errors in measurements.
- You should compare measurement reliability using percentage error rather than absolute error alone.

## Core content

**Absolute error.** The magnitude of difference between measured and true value. When true value is unknown: ± half the smallest instrument graduation. A mm ruler has ± 0.5 mm error.

**Relative error.** Absolute error divided by the measured value. No units. Example: 0.5 mm error on 200 mm measurement → relative error = 0.0025.

**Percentage error.** Relative error × 100%. The 0.0025 becomes 0.25%. Most intuitive for communicating measurement quality.

**Precision vs accuracy.** Precision = how repeatable (small random variation). Accuracy = how close to true value. You can be precise but inaccurate, or imprecise but accurate on average.

**Error in calculations.** For multiplied quantities (area, volume): percentage errors add approximately. Length 1.25% + width 1.67% → area ≈ 2.92% error. Report results to matching precision.

**Worked example.** Block 24.5 m × 18.3 m, instrument ± 0.05 m. Relative errors: 0.204%, 0.273%. Area = 448.35 m². Area %error ≈ 0.48%. Absolute area error ≈ 2.1 m². At $1 200/m², that's $2 500 uncertainty.

**Victorian and cultural context.** Victorian surveyors must meet precision standards for land titles. Melbourne Metro Tunnel required mm tolerances over km. VicRoads speed cameras include ± 2 km/h error margins. First Nations fish trap construction at Budj Bim requires proportional accuracy — gaps must be consistent relative to fish size, an intuitive relative-error concept.

## Memorable takeaways
- Absolute error has units. Relative/percentage error is dimensionless.
- Same absolute error on a small measurement = larger percentage error.
- For multiplied quantities: percentage errors add.
- Report results to precision matching your measurement accuracy.

## Watch out for these traps
- "Small absolute error always means precise." 1 mm error is great for 10 m (0.01%) but terrible for 2 mm (50%). Use percentage error to compare.
- "I reported 8 decimal places." If measurements have 1% error, extra decimals are false precision.
- "I used the full division, not half." Maximum error from a graduated instrument is ± half the smallest interval.

## Model responses

Use these to check your thinking after you have had a go.

- *Table measured to nearest cm — max absolute error?* ± 0.5 cm.
- *5.0 m ± 0.05 m — relative error?* 0.05/5.0 = 0.01.
- *Field measured 98 m, actual 100 m — % error?* 2/100 × 100 = 2%.
- *Lengths 8.0 ± 0.1 and 6.0 ± 0.1 multiplied — area % error?* 1.25% + 1.67% ≈ 2.92%.
- *Volume 2 348 cm³ with 3% error — how to report?* 2 350 ± 70 cm³ (3 sig fig).
