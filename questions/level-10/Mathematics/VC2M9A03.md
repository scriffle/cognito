# VC2M9A03 — Mathematics

## Snapshot
- **Descriptor:** VC2M9A03. Sketch linear graphs of equations in various algebraic forms, using the coordinates of 2 points, and solve linear equations.
- **Year level / Learning area:** Years 9–10, Mathematics (Algebra).
- **Big ideas:**
  - A linear equation produces a straight-line graph.
  - Two points are enough to define and sketch any line.
  - Solving a linear equation means finding the value of the variable that makes it true.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking; Aboriginal and Torres Strait Islander Histories and Cultures.

## What you are learning
- You are learning to **sketch linear graphs** from equations in different forms (slope-intercept, general, intercept form) and to **solve linear equations** algebraically.
- You are learning that all linear equations produce straight-line graphs, and that two points are sufficient to draw any line.

By the end of this you should be able to:
- Recognise a linear equation in various forms.
- Find two points on a line from its equation.
- Sketch the line accurately using those points.
- Identify the x-intercept and y-intercept from an equation.
- Solve linear equations including those with brackets and fractions.
- Connect the algebraic solution to the graph (the x-intercept of y = expression).

## Core content

**1. Forms of linear equations.** Linear equations can be written in several forms:
- **Slope-intercept form:** y = mx + c (gradient m, y-intercept c).
- **General form:** ax + by + c = 0 (or ax + by = c).
- **Intercept form:** x/a + y/b = 1 (x-intercept a, y-intercept b).

All produce straight-line graphs. *Quick check:* Rewrite 2x + 3y = 6 in slope-intercept form.

**2. Sketching using two points.** To sketch any line, find two points and draw a straight line through them. The easiest two points are usually the intercepts. For y = 2x − 4: when x = 0, y = −4 (y-intercept); when y = 0, 0 = 2x − 4 → x = 2 (x-intercept). Plot (0, −4) and (2, 0), draw the line. *Quick check:* Find the x-intercept and y-intercept of y = −3x + 9.

**3. Sketching from slope-intercept form.** From y = mx + c: start at the y-intercept (0, c), then use the gradient m = rise/run to find a second point. For y = ²⁄₃x + 1: start at (0, 1), then rise 2, run 3 to reach (3, 3). Draw the line. *Quick check:* Sketch y = −½x + 4 by starting at the y-intercept and using the gradient.

**4. Solving linear equations.** To solve, isolate the variable using inverse operations. Keep the equation balanced — do the same to both sides.
- 3x + 7 = 22 → 3x = 15 → x = 5.
- 2(x − 4) = 3x + 1 → 2x − 8 = 3x + 1 → −9 = x.
- (x + 3)/4 = 5 → x + 3 = 20 → x = 17.

*Quick check:* Solve 5(x − 2) = 3(x + 4).

**5. Equations with fractions.** Multiply both sides by the lowest common denominator (LCD) to clear fractions. For x/3 + x/4 = 7: LCD = 12. Multiply: 4x + 3x = 84 → 7x = 84 → x = 12. *Quick check:* Solve (2x − 1)/5 = (x + 3)/3.

**6. Worked example: sketch and solve.**

Sketch 3x + 2y = 12 and find where it crosses the x-axis.

*Follow the thinking:*
- Find y-intercept: set x = 0 → 2y = 12 → y = 6. Point: (0, 6).
- Find x-intercept: set y = 0 → 3x = 12 → x = 4. Point: (4, 0).
- Sketch the line through (0, 6) and (4, 0).
- The line crosses the x-axis at (4, 0), confirming the solution to 3x + 2(0) = 12 is x = 4.
- Check: 3(4) + 2(0) = 12 ✓.

**7. Connecting graphs to solutions.** Solving a linear equation like 2x − 4 = 0 is the same as finding where the graph y = 2x − 4 crosses the x-axis (the x-intercept). The solution x = 2 is the x-coordinate of that crossing point. This connects algebra (solving) to geometry (reading a graph). *Quick check:* The line y = 4x − 12 crosses the x-axis at what point? What equation does this solve?

## Victorian and cultural context

- **Victorian anchor.** Linear models are used constantly across Victoria: VicRoads models fuel cost as a linear function of distance; Melbourne's Myki fare system uses a linear relationship between zones travelled and cost; utility bills model usage charges as a linear equation (fixed charge + cost per unit). Urban planners use linear graphs to visualise growth projections for Melbourne's outer suburbs.
- **Aboriginal and Torres Strait Islander perspective.** Straight-line paths between significant sites — walking tracks, songlines — can be modelled as linear relationships on a coordinate plane. The alignment of stones at Wurdi Youang (Wadawurrung Country) with solstice positions demonstrates precise linear geometry in cultural practice. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Small business owners across Melbourne's diverse communities use linear equations daily — pricing models (cost = fixed + variable × quantity), break-even analysis, and currency conversion are all linear relationships graphed and solved the same way.

## Try these scenarios

1. **Everyday.** A phone plan charges $30 per month plus $0.10 per text message. Write the cost equation. Sketch the graph and find how many texts give a total cost of $45.
2. **Civic.** A council swimming pool charges adults $6 and children $3.50. Total revenue for a session is $840. Write and graph the equation. Find how many adults attended if there were 80 children.
3. **Vocational.** An electrician charges $90 call-out fee plus $75 per hour. Write the linear equation for total cost. Sketch the graph and solve for the number of hours if the bill is $352.50.
4. **Ethical.** Two internet plans: Plan A costs $50/month + $10/GB over the cap. Plan B costs $80/month with unlimited data. Set up and solve the equation to find the data usage where both plans cost the same. Discuss which plan is better value for different users.
5. **Cross-cultural.** A community garden allocates plots linearly: each household gets a 3 m frontage plus 1.5 m per family member. Write the equation for plot width. A family of 5 has a plot next to a couple. Sketch both plot widths on a number line and find the total frontage they use together.

## Memorable takeaways
- Linear equation → straight-line graph. Always.
- Two points define a line. Intercepts are usually the easiest two points.
- y = mx + c: m is gradient (steepness), c is y-intercept (starting value).
- Solve by isolating the variable — same operation to both sides.
- The solution to a linear equation is the x-intercept of its graph.

## Stretch yourself

(a) Write a linear equation for annual earnings under each package. (b) Sketch both lines on the same axes, labelling intercepts and the point of intersection. (c) Solve algebraically to find the number of units where both packages pay the same. (d) For what range of sales is each package better? (e) A third package offers $60 000 flat (no commission). Add this to your graph and find the sales levels where it beats each of the other packages. Show all working. 250–300 words.

## Watch out for these traps
- "I only plotted one point and guessed the line." Two points are the minimum for accuracy. Always find and plot two distinct points.
- "I forgot the negative sign on the gradient." If m is negative, the line slopes downward left to right. Check your direction.
- "I solved for x but didn't check." Substitute your answer back into the original equation to verify. Especially important with fractions and brackets.
- "I confused the y-intercept with the x-intercept." The y-intercept is where x = 0 (the line crosses the vertical axis). The x-intercept is where y = 0 (crosses the horizontal axis).

**Quick checks (Core content)**

1. *Rewrite 2x + 3y = 6.* 3y = −2x + 6 → y = −⅔x + 2.

6. *y = 4x − 12 crosses x-axis.* Set y = 0: 4x − 12 = 0 → x = 3. Point: (3, 0). Solves 4x − 12 = 0.

**Try these scenarios**

1. *Phone plan.* C = 30 + 0.10t. For C = 45: 0.10t = 15 → t = 150 texts.
2. *Swimming pool.* 6a + 3.5c = 840. With c = 80: 6a + 280 = 840 → 6a = 560 → a = 93.3. Since we need whole people, approximately 93 adults (the model gives a non-integer, suggesting the scenario has a slight rounding issue — in practice, 93 adults and 80 children gives $838).

B starts lower but is steeper. (c) 45 000 + 500n = 30 000 + 800n → 15 000 = 300n → n = 50 units. At 50 units both earn $70 000. (d) Below 50 units: A is better. Above 50 units: B is better.
