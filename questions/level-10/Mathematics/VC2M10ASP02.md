# VC2M10ASP02 — Mathematics

## Snapshot
- **Descriptor:** VC2M10ASP02. The sine rule, cosine rule and area rule for any triangle and applying them to problems.
- **Year level / Learning area:** Years 9–10 Advanced, Mathematics (Space).
- **Big ideas:**
  - The sine rule a/sin(A) = b/sin(B) = c/sin(C) relates sides and opposite angles in any triangle.
  - The cosine rule c² = a² + b² − 2ab·cos(C) generalises Pythagoras to non-right triangles.
  - The area rule Area = ½ab·sin(C) computes area without requiring the perpendicular height.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **apply the sine rule, cosine rule and area rule** to solve problems involving any triangle.
- You are learning to determine which rule to apply based on the given information.

By the end of this you should be able to:
- Apply the sine rule to find missing sides and angles.
- Apply the cosine rule to find a side (given two sides and included angle) or an angle (given three sides).
- Apply the area rule Area = ½ab·sin(C) to find the area of a triangle.
- Determine which rule is appropriate for a given problem.
- Recognise and handle the ambiguous case of the sine rule.

## Core content

**1. The sine rule.** For any triangle with sides a, b, c opposite angles A, B, C: a/sin(A) = b/sin(B) = c/sin(C). Use when given: two angles and one side, or two sides and a non-included angle. For a triangle with A = 40°, B = 70°, a = 10: b = 10·sin(70°)/sin(40°) ≈ 14.62. *Quick check:* In a triangle, A = 30°, B = 80°, a = 8. Find b.

**2. The cosine rule — finding a side.** c² = a² + b² − 2ab·cos(C). Use when given two sides and the included angle. For a = 7, b = 10, C = 60°: c² = 49 + 100 − 140·cos(60°) = 149 − 70 = 79. c = √79 ≈ 8.89. When C = 90°, this reduces to Pythagoras. *Quick check:* Find side c when a = 5, b = 8, C = 45°.

**3. The cosine rule — finding an angle.** Rearranging: cos(C) = (a² + b² − c²)/(2ab). For a = 6, b = 8, c = 10: cos(C) = (36 + 64 − 100)/96 = 0. C = 90°. This confirms the triangle is right-angled. *Quick check:* Find angle C when a = 4, b = 5, c = 7.

**4. The area rule.** Area = ½ab·sin(C). This gives the area using two sides and their included angle — no height measurement needed. For a = 12, b = 9, C = 50°: Area = ½ × 12 × 9 × sin(50°) ≈ 41.4 square units. *Quick check:* Find the area of a triangle with sides 10 and 14, included angle 30°.

**5. Choosing the right rule.** Given two angles and one side → sine rule. Given two sides and included angle → cosine rule (for side) or area rule (for area). Given three sides → cosine rule (for angle). Given two sides and non-included angle → sine rule (watch for ambiguous case). *Quick check:* State which rule to use: three sides known, find the largest angle.

**6. Worked example — navigation problem.**
Two ships leave a port. Ship A travels 15 km on a bearing of 040°. Ship B travels 20 km on a bearing of 120°. Find the distance between the ships.

*Follow the thinking:*
- The angle at the port between the two paths = 120° − 40° = 80°.
- Two sides (15, 20) and included angle (80°) → cosine rule.
- d² = 15² + 20² − 2(15)(20)·cos(80°) = 225 + 400 − 600·cos(80°) ≈ 625 − 104.2 = 520.8.
- d ≈ 22.82 km.

**7. The ambiguous case.** When using the sine rule with two sides and a non-included angle (SSA), there may be 0, 1 or 2 solutions. This occurs because sin(θ) = sin(180° − θ), so two angles may satisfy the equation. Always check whether the second angle produces a valid triangle (angles summing to 180°). *Quick check:* If sin(B) = 0.8 and the triangle has A = 40° and a = 10, how many solutions for B are possible?

## Victorian and cultural context

- **Victorian anchor.** Surveyors across Victoria use the sine and cosine rules for land measurement. Marine navigation in Port Phillip Bay and coastal Victoria relies on these trigonometric techniques.
- **Aboriginal and Torres Strait Islander perspective.** Navigation across vast distances — using star positions, landmarks and wind patterns — was practised by First Nations peoples for millennia. The trigonometric calculations formalise the spatial reasoning these navigators employed intuitively.
- **Multicultural Australian perspective.** The sine rule was known to medieval Islamic mathematicians, including Nasir al-Din al-Tusi (13th century Persia). The cosine rule generalises Euclid's propositions on obtuse and acute triangles.

2. **Civic.** A council measures a triangular park with sides 120 m, 85 m and 95 m. Find the largest angle and the area.
3. **Vocational.** A surveyor needs to find the width of a river. Standing at A, the surveyor measures angle BAC = 65° to a tree at C directly opposite, then walks 50 m to B and measures angle ABC = 80°. Find AC.
4. **Ethical.** A student uses the sine rule for a problem with two sides and an included angle. Explain why the cosine rule is the correct choice.
5. **Cross-cultural.** Research al-Tusi's contributions to trigonometry. Then find the area of a triangle with a = 15, b = 20, C = 110°.

## Memorable takeaways
- Sine rule: a/sin A = b/sin B = c/sin C — for angle-side pairs.
- Cosine rule: c² = a² + b² − 2ab·cos C — generalises Pythagoras.
- Area rule: ½ab·sin C — no height needed.
- Choose the rule based on what is given: angles + side → sine; sides + included angle → cosine.
- Watch for the ambiguous case with SSA (sine rule).

## Watch out for these traps
- **Using the sine rule when the cosine rule is needed.** Two sides and an included angle require the cosine rule, not the sine rule.
- **Calculator in wrong mode.** Ensure the calculator is in degree mode, not radians.
- **Ignoring the ambiguous case.** With SSA, always check whether a second valid triangle exists.
- **Misidentifying the included angle.** The included angle is between the two given sides.

**Try these scenarios**
1. *Hikers.* Angle = 60°. d² = 9 + 16 − 24·cos(60°) = 25 − 12 = 13. d = √13 ≈ 3.61 km.
