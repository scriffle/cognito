# VC2M10A12 — Mathematics (Short)

## Snapshot
- **Descriptor:** Solve linear equations involving simple algebraic fractions.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Clear fractions by multiplying every term by the LCD. Once fractions are removed, solve as a standard linear equation. Always check solutions and state restrictions (denominators cannot equal zero).

## What you are learning
- You are learning to **solve linear equations that contain algebraic fractions** with numerical or variable denominators.
- You should clear fractions systematically, solve the resulting equation, and check for excluded values.

## Core content

**Numerical denominators.** x/3 + x/5 = 8. LCD = 15. Multiply every term: 5x + 3x = 120 → 8x = 120 → x = 15. Check: 15/3 + 15/5 = 5 + 3 = 8 ✓.

**Multi-term numerators.** (2x + 1)/4 = 3. Multiply both sides by 4: 2x + 1 = 12 → x = 5.5. Use brackets — the denominator multiplies the entire numerator.

**Fractions on both sides.** (x + 3)/2 = (2x − 1)/3. LCD = 6. Multiply: 3(x + 3) = 2(2x − 1) → 3x + 9 = 4x − 2 → x = 11. Check: 14/2 = 7; 21/3 = 7 ✓.

**Variable denominators.** 5/x = 2. Multiply by x: 5 = 2x → x = 2.5. Restriction: x ≠ 0.

**Worked example — work-rate problem.** Painter A: 6 hours (rate 1/6). Painter B: 10 hours (rate 1/10). Together: 1/6 + 1/10 = 1/t. LCD = 30t. Multiply: 5t + 3t = 30 → 8t = 30 → t = 3.75 hours. Check: 1/6 + 1/10 = 8/30 = 4/15; 1/3.75 = 4/15 ✓.

**Checking and restrictions.** Always substitute back. State excluded values (any x that makes a denominator zero). If your solution equals an excluded value, the equation has no valid solution.

**Victorian context.** Engineers at CSIRO and Engineers Australia solve fractional equations for flow rates and circuit problems. Aboriginal corporations managing shared budgets encounter proportional reasoning with fractions in financial planning. Proportional sharing — splitting costs, calculating ingredient ratios — is universal in family and business contexts.

## Memorable takeaways
- Clear fractions: multiply every term by the LCD.
- Use brackets for multi-term numerators.
- After clearing, solve as a standard linear equation.
- Always check by substituting back.
- State restrictions: variable denominators ≠ 0.

## Watch out for these traps
- Multiplying only one side — you must multiply every term on both sides.
- Forgetting brackets: 3 × (2x + 1) = 6x + 3, not 6x + 1.
- Not checking — especially with variable denominators, your solution might make a denominator zero.

## Model responses

Use these to check your thinking after you have had a go.

- *Solve x/2 − x/6 = 4.* LCD = 6. 3x − x = 24 → 2x = 24 → x = 12. Check: 6 − 2 = 4 ✓.
- *Solve (3x − 2)/5 = 4.* 3x − 2 = 20 → 3x = 22 → x = 22/3. Check: 20/5 = 4 ✓.
- *Solve (x+1)/4 = (x−2)/3.* LCD = 12. 3(x+1) = 4(x−2) → 3x + 3 = 4x − 8 → x = 11. Check: 12/4 = 3; 9/3 = 3 ✓.
- *Solve 12/x = 4.* x = 3. Restriction: x ≠ 0.
- *Egyptian aha problem: x + x/7 = 19.* LCD = 7. 7x + x = 133 → 8x = 133 → x = 133/8 = 16.625. Check: 16.625 + 2.375 = 19 ✓.
