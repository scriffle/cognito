# VC2M10SP01 — Mathematics (Short)

## Snapshot
- **Descriptor:** Apply deductive reasoning to formulate proofs involving shapes in the plane and use theorems to solve spatial problems.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Deductive reasoning builds logical chains from known facts to new conclusions. A proof shows WHY something must be true for all cases. Congruence and similarity criteria (SSS, SAS, AAS, RHS, AAA) are the key tools. Once proven, theorems become tools for solving problems.

## What you are learning
- You are learning to **construct deductive proofs** about plane shapes and to **apply geometric theorems** to solve problems.
- You should structure proofs with Given → To prove → Proof (with reasons) → Conclusion.

## Core content

**Deductive vs inductive.** Measuring 10 triangles is inductive (suggests but doesn't prove). Deduction uses logic from known truths — conclusion must follow for ALL cases.

**Proof structure.** Given → To prove → Statements with reasons → QED.

**Key theorems.** Angles on a line = 180°. Triangle angle sum = 180°. Alternate angles equal (parallel lines). Exterior angle = sum of non-adjacent interior angles.

**Congruence criteria.** SSS, SAS, AAS, RHS. NOT SSA (ambiguous case). Congruent = same shape and size.

**Similarity criteria.** AAA (equiangular), SSS (ratio), SAS (ratio). Similar = same shape, different size.

**Worked example — parallelogram diagonals bisect.** Given ABCD parallelogram, diagonals meet at M. In triangles ABM and CDM: AB = CD (opposite sides), angle ABM = angle CDM (alternate), angle BAM = angle DCM (alternate). By AAS: triangles congruent. Therefore AM = CM, BM = DM. Diagonals bisect. ✓

**Applying theorems.** Parallelogram angle (3x+10)° adjacent to (2x+20)°: sum = 180° → 5x + 30 = 180 → x = 30.

**Victorian context.** Melbourne's Parliament House symmetry, West Gate Bridge triangular trusses, State Library dome — all rely on geometric proof. Land surveyors use triangle congruence to verify boundaries. Wurdi Youang stone arrangement demonstrates geometric precision. Deductive proof spans civilisations: Greek (Euclid), Indian (Baudhayana), Islamic patterns, Chinese geometry (Liu Hui).

## Memorable takeaways
- Proof = logical chain where every step has a cited reason.
- Congruence: SSS, SAS, AAS, RHS (not SSA).
- Similarity: AAA, SSS ratio, SAS ratio.
- Examples suggest; proofs establish certainty for all cases.
- Once proven, a theorem becomes a problem-solving tool.

## Watch out for these traps
- Assuming what you're trying to prove (circular reasoning).
- Using SSA — it's not a valid congruence criterion.
- Forgetting to cite reasons for each step.
- Confusing congruence (same size) with similarity (same shape).

## Model responses

Use these to check your thinking after you have had a go.

- *Triangle angles 2x, 3x, 4x.* 9x = 180 → x = 20. Angles: 40°, 60°, 80°.
- *SAS congruence check.* Two sides and included angle match → congruent by SAS.
- *Parallelogram: one angle 85°.* Adjacent = 95°, opposite = 85°. All four: 85°, 95°, 85°, 95°.
- *Proof that equal diagonals → rectangle.* SSS gives congruent triangles → adjacent angles equal → each = 90°.
- *n² + n + 41 prime for n = 0 to 39.* Fails at n = 40 (= 41²). Pattern ≠ proof.
