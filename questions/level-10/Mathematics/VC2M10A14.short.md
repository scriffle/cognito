# VC2M10A14 — Mathematics (Short)

## Snapshot
- **Descriptor:** Solve simple exponential equations.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Exponential equations have the variable in the exponent. The key strategy is to express both sides with the same base, then equate exponents. Index laws are essential for rewriting powers.

## What you are learning
- You are learning to **solve exponential equations** by rewriting both sides with a common base.
- You should recognise exponential equations and apply index laws to equate exponents.

## Core content

**Same-base strategy.** If aˣ = aⁿ, then x = n. Rewrite both sides with the same base. Example: 2ˣ = 16 → 2ˣ = 2⁴ → x = 4.

**Rewriting numbers as powers.** 4ˣ = 64: rewrite as (2²)ˣ = 2⁶ → 2²ˣ = 2⁶ → 2x = 6 → x = 3. Know your powers: 2⁴ = 16, 2⁷ = 128, 3⁴ = 81, 5³ = 125.

**Negative exponents.** 2ˣ = 1/8. Since 1/8 = 2⁻³, then x = −3.

**Index laws in action.** 8^(x+1) = 32 → (2³)^(x+1) = 2⁵ → 3(x+1) = 5 → 3x + 3 = 5 → x = 2/3.

**Worked example — bacterial doubling.** P = 5 × 2ᵗ. When P = 640: 2ᵗ = 128 = 2⁷ → t = 7 hours. Check: 5 × 128 = 640 ✓.

**Limitations.** Equations like 2ˣ = 5 cannot be solved by same-base (20 is not a power of 2). These need logarithms (studied later) or graphical/trial methods.

**Victorian context.** ABS uses exponential models for Victoria's population projections. CSIRO models radioactive decay at the Australian Synchrotron. Carbon-14 dating (exponential decay) confirms the 65,000+ year presence of First Nations people. Compound interest — encountered by every Australian family — is fundamentally exponential.

## Memorable takeaways
- Variable in the exponent = exponential equation.
- Same-base method: rewrite, then equate exponents.
- Know key powers of 2, 3, and 5.
- Negative exponents give fractions: a⁻ⁿ = 1/aⁿ.
- Power of a power: (aᵐ)ⁿ = aᵐⁿ (multiply exponents).

## Watch out for these traps
- Trying to "square root" an exponential — use same-base, not quadratic methods.
- Wrong base choice: for 4ˣ = 8, use base 2, not base 4.
- Forgetting (2³)ˣ = 2³ˣ, not 2^(3+x).
- Not all exponentials are solvable by same-base at this level.

## Model responses

Use these to check your thinking after you have had a go.

- *Solve 3ˣ = 81.* 81 = 3⁴ → x = 4.
- *Solve 9ˣ = 27.* (3²)ˣ = 3³ → 2x = 3 → x = 3/2.
- *Solve 5ˣ = 1/25.* 1/25 = 5⁻² → x = −2.
- *Solve 4^(x−1) = 8.* 2^(2x−2) = 2³ → 2x−2 = 3 → x = 5/2.
- *Investment doubling.* 1000 × 2^(t/10) = 8000 → 2^(t/10) = 2³ → t = 30 years.
