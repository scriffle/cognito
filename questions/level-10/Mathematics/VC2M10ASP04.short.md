# VC2M10ASP04 — Mathematics (Short)

## Snapshot
- **Descriptor:** Solve simple trigonometric equations.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** Trig equations have multiple solutions due to symmetry. Unit circle and ASTC rule identify all solutions in a domain. Essential for modelling periodic phenomena.

## What you are learning
- You are learning to **solve simple trigonometric equations** and identify all solutions within a specified domain.
- You should be able to use the unit circle and ASTC rule to find multiple solutions systematically.

## Core content

**Solving sin(x) = k:** Find reference angle α = sin⁻¹(|k|). k > 0: x = α (Q1), x = 180° − α (Q2). k < 0: x = 180° + α (Q3), x = 360° − α (Q4).

**Solving cos(x) = k:** Reference angle α = cos⁻¹(|k|). k > 0: Q1 and Q4. k < 0: Q2 and Q3.

**Solving tan(x) = k:** Reference angle α = tan⁻¹(|k|). Solutions 180° apart. k > 0: Q1 and Q3. k < 0: Q2 and Q4.

**Rearranging first:** 2sin(x) − 1 = 0 → sin(x) = ½ → x = 30° or 150°.

**Special cases:** sin(x) = 1 → one solution (90°). sin(x) = 0 → x = 0°, 180°, 360°. sin(x) = 2 → no solution.

**Victorian context.** Trig equations model AC circuits, tidal patterns and acoustics. Madhava of Sangamagrama (14th century India) developed trigonometric series.

## Memorable takeaways
- sin(x) = k and cos(x) = k typically have two solutions in 0°–360°.
- tan(x) = k always has two solutions, 180° apart.
- Find the reference angle first, then place in correct quadrants using ASTC.
- Rearrange to isolate the trig function before solving.

## Watch out for these traps
- Finding only one solution — always check both relevant quadrants.
- Wrong quadrant placement — use ASTC carefully.
- Forgetting to rearrange before finding the reference angle.
