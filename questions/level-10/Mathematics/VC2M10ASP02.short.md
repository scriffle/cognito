# VC2M10ASP02 — Mathematics (Short)

## Snapshot
- **Descriptor:** The sine rule, cosine rule and area rule for any triangle and applying them to problems.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** Sine rule relates sides to opposite angles. Cosine rule generalises Pythagoras. Area rule uses two sides and included angle.

## What you are learning
- You are learning to **apply the sine, cosine and area rules** to solve triangle problems.
- You should be able to select the correct rule and handle the ambiguous case.

## Core content

**Sine rule:** a/sin A = b/sin B = c/sin C. Use with angle-side pairs.

**Cosine rule (side):** c² = a² + b² − 2ab·cos C. Two sides + included angle → find side.

**Cosine rule (angle):** cos C = (a² + b² − c²)/(2ab). Three sides → find angle.

**Area rule:** Area = ½ab·sin C. Two sides + included angle.

**Choosing:** Angles+side → sine. Sides+included angle → cosine. Three sides → cosine for angle.

**Ambiguous case (SSA):** sin B = sin(180°−B), so two angles may be valid.

**Victorian context.** Surveyors use these rules for land measurement. Al-Tusi (13th century Persia) contributed significantly to trigonometric theory.

## Memorable takeaways
- Sine rule for angle-side pairs; cosine rule for SAS or SSS configurations.
- Area = ½ab·sin C — no height needed.
- Cosine rule reduces to Pythagoras when C = 90°.
- Check for the ambiguous case with SSA.

## Watch out for these traps
- Using sine rule when cosine is needed (two sides + included angle).
- Calculator in radians instead of degrees.
- Ignoring the second possible angle in the ambiguous case.
