# VC2M9ST04 — Mathematics (Short)

## Snapshot
- **Descriptor:** Choose appropriate forms of display or visualisation for a given type of data; justify selections and interpret displays for a given context.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Data type determines display. Categorical → bar/pie. Numerical → histogram/box plot/scatter. Justify by naming data type and purpose. Display choice can reveal or hide patterns.

## What you are learning
- You are learning to **choose, justify and interpret** appropriate data displays for different data types and contexts.
- You should match display to data type, explain why, and critically evaluate graphs.

## Core content

**Data types.** Categorical: nominal (colours, names) or ordinal (ratings, ranks). Numerical: discrete (countable) or continuous (measurable). Data type determines valid display choices.

**Categorical displays.** Bar chart: compares category frequencies (separated bars). Pie chart: shows proportions (best for 3–7 categories). Stacked bar: composition across groups.

**Numerical displays.** Histogram: distribution shape (touching bars, continuous). Box plot: median, quartiles, range, outliers — ideal for comparing groups. Dot plot/stem-and-leaf: small datasets.

**Bivariate displays.** Scatter plot: relationship between two numerical variables. Line graph: change over time (time series).

**Justifying.** State: (1) data type, (2) what you want to show, (3) why this display suits. "Box plots because I have numerical data from multiple groups and want to compare spreads."

**Interpreting and misleading graphs.** Describe shape, centre, spread, outliers. Watch for: truncated y-axis, 3D distortion, too many pie slices, wrong chart type for data.

**Victorian and cultural context.** ABS and Victorian government choose visualisations carefully for census and health data. Bureau of Meteorology uses colour-mapped displays. Data sovereignty matters for First Nations communities — how data is displayed affects interpretation. Organisations like Mayi Kuwayu centre Indigenous data governance. Multicultural community organisations need culturally accessible visualisations.

## Memorable takeaways
- Categorical → bar/pie. Numerical → histogram/box plot/scatter.
- Match display to data type + purpose.
- Justify: data type, purpose, why this display works best.
- Interpret: shape, centre, spread, outliers.
- Watch for misleading tricks (truncated axes, too many categories).

## Watch out for these traps
- "Pie chart for 15 categories." Unreadable. Use a bar chart.
- "Bar chart for continuous data." Use a histogram (touching bars for ranges).
- "Line graph for categorical data." Lines imply continuous connection — only for ordered/time data.

## Model responses

Use these to check your thinking after you have had a go.

- *Classify: shoe size, favourite sport, temperature, satisfaction 1–5?* Discrete numerical, nominal categorical, continuous numerical, ordinal categorical.
- *Transport mode (5 categories) — which display?* Bar chart (categorical, comparing frequencies). Pie chart also acceptable.
- *Comparing test scores across 3 classes?* Parallel box plots — compare medians, spreads.
- *Study hours vs test scores?* Scatter plot — two numerical variables, investigating relationship.
- *Truncated y-axis — how misleading?* Small differences look large; fills visual space disproportionately.
