# VC2M10SP02 — Mathematics (Short)

## Snapshot
- **Descriptor:** Interpret networks and network diagrams used to represent relationships in practical situations and describe connectedness.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** A network has vertices (nodes) connected by edges. Networks model relationships: transport, social, communication. A network is connected if every vertex can be reached from every other. Sum of degrees = 2 × edges. A tree is a connected network with no circuits (n−1 edges).

## What you are learning
- You are learning to **interpret and construct network diagrams** and describe **connectedness** in practical contexts.
- You should identify vertices, edges, degrees, and determine whether networks are connected.

## Core content

**Network basics.** Vertices (nodes) connected by edges (lines). Only connections matter — not the drawing's appearance. Degree = number of edges at a vertex.

**Degree sum.** Sum of all degrees = 2 × number of edges (each edge touches two vertices). Degrees 2, 3, 3, 4 → sum 12 → 6 edges.

**Connectedness.** Connected = path exists between every pair of vertices. Disconnected = some vertices unreachable. A bridge is an edge whose removal disconnects the network.

**Trees.** Connected + no circuits. Exactly n−1 edges for n vertices. Most efficient connected network (minimum edges).

**Worked example.** 6 suburbs, 7 roads. Degrees: A=2, B=3, C=3, D=3, E=2, F=1. Sum = 14 = 2×7 ✓. Connected (A→B→D→F). F is a leaf (degree 1) — vulnerable to disconnection.

**Weighted and directed.** Weights = distances/costs. Directions = one-way connections. Allows shortest-path and flow questions.

**Victorian context.** Melbourne's PTV train network modelled as a graph. NBN rollout planned via network optimisation. Songlines form networks connecting communities across Country — vertices are significant places, edges are paths between them. Social media networks demonstrate degree, connectedness and influence.

## Memorable takeaways
- Network = vertices + edges.
- Degree = number of edges at a vertex.
- Sum of degrees = 2 × number of edges.
- Connected = every vertex reachable from every other.
- Tree = connected, no circuits, n−1 edges.

## Watch out for these traps
- Two different-looking diagrams can be the same network (only connections matter).
- Not all networks are connected — always check.
- A tree has NO redundancy — every edge is critical.
- A loop adds 2 to a vertex's degree, not 1.
