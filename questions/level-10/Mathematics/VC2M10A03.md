# VC2M10A03 — Mathematics

## Snapshot
- **Descriptor:** VC2M10A03. Apply the four operations to simple algebraic fractions with numerical or single variable denominators.
- **Year level / Learning area:** Years 9–10, Mathematics (Algebra).
- **Big ideas:**
  - Algebraic fractions follow the same rules as numerical fractions — find common denominators for addition and subtraction, multiply across for multiplication, flip and multiply for division.
  - The denominator can be a number or a single variable (e.g. 3, x, 2a).
  - Simplifying algebraic fractions uses factorising and cancelling common factors.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **add, subtract, multiply and divide simple algebraic fractions** with numerical or single-variable denominators.
- You are learning to find common denominators, simplify results, and work confidently with algebra in fraction form.

By the end of this you should be able to:
- Add and subtract algebraic fractions by finding the lowest common denominator (LCD).
- Multiply algebraic fractions by multiplying numerators and denominators.
- Divide algebraic fractions by multiplying by the reciprocal.
- Simplify results by cancelling common factors.

## Core content

**1. What is an algebraic fraction?** An algebraic fraction has a variable expression in the numerator, the denominator, or both. Examples: x/3, (2a + 1)/5, 4/x, 3/(2m). The rules for operating on them are the same as for ordinary fractions. *Quick check:* Is 5/(x + 1) an algebraic fraction? Why?

**2. Adding and subtracting — same denominator.** If the denominators are already the same, add or subtract the numerators: x/4 + 3x/4 = (x + 3x)/4 = 4x/4 = x. *Quick check:* Simplify 5a/7 − 2a/7.

**3. Adding and subtracting — different numerical denominators.** Find the **lowest common denominator (LCD)** and convert each fraction. x/3 + x/5: LCD = 15. Convert: 5x/15 + 3x/15 = 8x/15. *Quick check:* Simplify x/4 + x/6.

**4. Adding and subtracting — variable denominators.** When denominators are single variables: 3/x + 5/x = 8/x (same denominator). For different variable denominators: 2/a + 3/b: LCD = ab. Convert: 2b/(ab) + 3a/(ab) = (2b + 3a)/(ab). *Quick check:* Simplify 4/m − 1/n.

**5. Multiplying algebraic fractions.** Multiply numerators together and denominators together, then simplify. (2x/3) × (5/x) = 10x/(3x) = 10/3. Cancel common factors before or after multiplying. *Quick check:* Simplify (3a/4) × (8/a²).

**6. Worked example — adding fractions in a rates problem.**
Two pipes fill a tank. Pipe A fills 1/x of the tank per hour. Pipe B fills 1/(2x) per hour. Together per hour they fill:

*Follow the thinking:*
- 1/x + 1/(2x). LCD = 2x.
- Convert: 2/(2x) + 1/(2x) = 3/(2x).
- Together, the pipes fill 3/(2x) of the tank per hour.
- Check: if x = 4, Pipe A fills 1/4 per hour, Pipe B fills 1/8. Together: 1/4 + 1/8 = 2/8 + 1/8 = 3/8. Formula: 3/(2×4) = 3/8 ✓.

**7. Dividing algebraic fractions.** To divide, multiply by the **reciprocal** (flip the second fraction). (4x/5) ÷ (2x/3) = (4x/5) × (3/(2x)) = 12x/(10x) = 6/5. *Quick check:* Simplify (6/a) ÷ (3/a²).

## Victorian and cultural context

- **Victorian anchor.** Algebraic fractions appear in physics formulas used at CSIRO and the Australian Synchrotron (e.g. combined resistance: 1/R_total = 1/R₁ + 1/R₂). Engineers at Engineers Australia use these operations when combining rates in parallel systems. Financial analysts apply algebraic fractions in compound-rate calculations.
- **Aboriginal and Torres Strait Islander perspective.** Rate-sharing problems — dividing resources proportionally across groups — are relevant to community resource management. Aboriginal corporations managing shared water, land or funding allocations use proportional reasoning that algebraic fractions formalise. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Fraction arithmetic was highly developed in ancient Egyptian (unit fractions), Indian (decimal fractions) and Islamic (sexagesimal fractions) mathematics. Students can explore how these traditions contributed to the modern symbolic notation used today.

## Try these scenarios

1. **Everyday.** You spend x/3 hours on homework and x/4 hours on sport each day. Write and simplify an expression for the total time.
2. **Civic.** A council splits a budget: 2/x of the total goes to roads and 3/(2x) goes to parks. Write a single fraction for the combined allocation.
3. **Vocational.** An electrician calculates total resistance for two parallel resistors: 1/R_total = 1/R₁ + 1/R₂. If R₁ = 2a and R₂ = 3a, find 1/R_total as a single fraction and then find R_total.
4. **Ethical.** A student simplifies (x + 2)/3 + (x − 1)/3 as (2x + 1)/6. Identify the error, explain what went wrong, and give the correct answer.
5. **Cross-cultural.** Ancient Egyptians only used unit fractions (numerator of 1). Express 5/6 as a sum of distinct unit fractions (Egyptian style). Then add 1/x + 1/(2x) + 1/(3x) using algebra.

## Memorable takeaways
- Same denominator: add/subtract the numerators directly.
- Different denominators: find the LCD, convert, then combine.
- Multiply: numerator × numerator, denominator × denominator, then simplify.
- Divide: flip the second fraction and multiply.
- Cancel common factors to simplify — but only factors, never terms.

## Watch out for these traps
- **Cancelling terms instead of factors.** In (x + 3)/x, you cannot cancel the x — it is a term in the numerator sum, not a factor. You can only cancel factors that multiply the entire numerator and denominator.
- **Forgetting to multiply both numerator and denominator when converting.** x/3 with LCD 15: multiply both by 5 to get 5x/15, not x/15.
- **Adding denominators.** x/3 + x/5 ≠ x/8 or 2x/8. You must find a common denominator.
- **Forgetting to flip when dividing.** (a/b) ÷ (c/d) = (a/b) × (d/c), not (a/b) × (c/d).

A note on certainty. The rules for operating on algebraic fractions are exact — they follow from the properties of equality and the definition of division. The only restriction: the denominator cannot equal zero (division by zero is undefined). When working with variable denominators, always note this restriction.

## Model responses

Use these to check your own thinking after you have had a go.

**Quick checks (Core content)**
1. *Is 5/(x+1) an algebraic fraction?* Yes — it has a variable expression in the denominator.
2. *5a/7 − 2a/7.* 3a/7.
3. *x/4 + x/6.* LCD = 12. 3x/12 + 2x/12 = 5x/12.
4. *4/m − 1/n.* LCD = mn. (4n − m)/(mn).
5. *(3a/4) × (8/a²).* 24a/(4a²) = 6/a.
6. *Pipe problem.* 3/(2x) (worked through in example).
7. *(6/a) ÷ (3/a²).* (6/a) × (a²/3) = 6a²/(3a) = 2a.

**Try these scenarios**
1. *Total time.* x/3 + x/4. LCD = 12. 4x/12 + 3x/12 = 7x/12 hours.
2. *Council budget.* 2/x + 3/(2x). LCD = 2x. 4/(2x) + 3/(2x) = 7/(2x).
3. *Parallel resistance.* 1/(2a) + 1/(3a). LCD = 6a. 3/(6a) + 2/(6a) = 5/(6a). So R_total = 6a/5.
4. *Student error.* The denominators are the same (both 3), so add numerators directly: (x + 2 + x − 1)/3 = (2x + 1)/3. The student incorrectly doubled the denominator.
5. *Egyptian fractions and algebra.* 5/6 = 1/2 + 1/3. Algebraic: 1/x + 1/(2x) + 1/(3x). LCD = 6x. 6/(6x) + 3/(6x) + 2/(6x) = 11/(6x).

**Stretch task — example shape of a strong answer.** Worker A rate = 1/x per hour. Worker B rate = 1/(x + 4) per hour. Combined: 1/x + 1/(x + 4). LCD = x(x + 4). Combined = (x + 4 + x)/(x(x + 4)) = (2x + 4)/(x(x + 4)) = 2(x + 2)/(x(x + 4)). When x = 6: rate = 2(8)/(6 × 10) = 16/60 = 4/15 of the building per hour. Time = 15/4 = 3.75 hours. Verify: A does 1/6 per hour, B does 1/10 per hour. Together: 1/6 + 1/10 = 5/30 + 3/30 = 8/30 = 4/15 ✓. Assumptions: constant work rate, no breaks, no interference between workers.
