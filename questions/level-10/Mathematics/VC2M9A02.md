# VC2M9A02 — Mathematics

## Snapshot
- **Descriptor:** VC2M9A02. Simplify algebraic expressions, apply the distributive law to expand algebraic expressions including binomial products, and factorise monic quadratic expressions.
- **Year level / Learning area:** Years 9–10, Mathematics (Algebra).
- **Big ideas:**
  - Simplifying means collecting like terms and reducing expressions to their simplest form.
  - The **distributive law** expands brackets: a(b + c) = ab + ac. **Binomial products** expand two brackets: (a + b)(c + d).
  - **Factorising** is the reverse — writing an expression as a product of factors. For monic quadratics (x² + bx + c), find two numbers that multiply to c and add to b.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **simplify, expand and factorise** algebraic expressions including binomial products and monic quadratics.
- You are learning that expanding and factorising are reverse operations.

By the end of this you should be able to:
- Simplify expressions by collecting like terms.
- Expand using the distributive law: a(b + c) = ab + ac.
- Expand binomial products: (x + a)(x + b) = x² + (a+b)x + ab.
- Recognise and use special products: perfect squares and difference of squares.
- Factorise monic quadratics x² + bx + c by finding factor pairs of c that sum to b.

## Core content

**1. Simplifying expressions.** Collect **like terms** — terms with the same variable and power. 3x + 5x = 8x. 2x² + 3x − x² + 5x = x² + 8x. Unlike terms cannot be combined: 3x + 2y stays as 3x + 2y. *Quick check:* Simplify 4a + 3b − 2a + 5b.

**2. The distributive law.** a(b + c) = ab + ac. The factor outside multiplies every term inside. Examples: 3(x + 4) = 3x + 12. −2(3x − 5) = −6x + 10 (negative multiplies both terms). x(x + 3) = x² + 3x. *Quick check:* Expand 5(2x − 3).

**3. Expanding binomial products.** (x + a)(x + b): multiply each term in the first bracket by each term in the second. Use FOIL: First, Outer, Inner, Last. (x + 3)(x + 5) = x² + 5x + 3x + 15 = x² + 8x + 15. General result: (x + a)(x + b) = x² + (a + b)x + ab. *Quick check:* Expand (x + 4)(x − 2).

**4. Special products.** **Perfect square:** (x + a)² = x² + 2ax + a². (x + 3)² = x² + 6x + 9. **Difference of squares:** (x + a)(x − a) = x² − a². (x + 5)(x − 5) = x² − 25. These shortcuts save time and reduce errors. *Quick check:* Expand (x − 4)².

**5. Factorising — common factors.** Find the highest common factor (HCF) of all terms and take it out. 6x² + 9x = 3x(2x + 3). Check: 3x × 2x + 3x × 3 = 6x² + 9x ✓. Always look for common factors first. *Quick check:* Factorise 12xy − 8x.

**6. Worked example — factorising a monic quadratic.**
Factorise x² + 7x + 12.

*Follow the thinking:*
- This is monic (coefficient of x² is 1). Form: x² + bx + c.
- Need two numbers that multiply to c = 12 AND add to b = 7.
- Factor pairs of 12: (1, 12), (2, 6), (3, 4).
- Which pair adds to 7? 3 + 4 = 7. ✓
- Therefore: x² + 7x + 12 = (x + 3)(x + 4).
- Check by expanding: (x + 3)(x + 4) = x² + 4x + 3x + 12 = x² + 7x + 12. ✓

**7. Factorising with negatives.** When c is negative, one number is positive and one negative. x² + 2x − 15: need numbers multiplying to −15, adding to +2. That's +5 and −3. So (x + 5)(x − 3). When b is negative and c is positive, both numbers are negative. x² − 7x + 10: need −5 and −2 (multiply to +10, add to −7). So (x − 5)(x − 2). *Quick check:* Factorise x² − x − 6.

## Try these scenarios

1. **Everyday.** A rectangular room has dimensions (x + 2) and (x + 5) metres. Expand to find the area expression. If x = 3, calculate the actual area. Verify by substituting into both the factored and expanded forms.
2. **Civic.** A council extends a square park (side x metres) by 3 metres in one direction and 4 metres in the other. Write the new area as a binomial product and expand. How much extra area was added compared to the original x²?
3. **Vocational.** A tiler needs (x² + 5x + 6) tiles for a job. Factorise this expression. If x = 10, how many tiles? Verify using both the factored and expanded forms.
4. **Ethical.** A student claims (x + 3)² = x² + 9. Prove this wrong by expanding correctly. Then substitute x = 2 into both the incorrect and correct versions to show the numerical error.
5. **Cross-cultural.** Al-Khwarizmi (9th century Baghdad) described "a square and ten of its roots equals 39" — which we write as x² + 10x = 39 or x² + 10x − 39 = 0. Factorise x² + 10x − 39 and solve.

## Memorable takeaways
- Distributive law: a(b + c) = ab + ac.
- Binomial product: (x + a)(x + b) = x² + (a+b)x + ab.
- Special: (x + a)² = x² + 2ax + a². (x+a)(x−a) = x² − a².
- Factorise monic quadratic: find two numbers that multiply to c and add to b.
- Expanding and factorising are reverse operations — always check by expanding back.

## Stretch yourself
Expand and simplify (2x + 3)(3x − 1) − (x + 2)². Then factorise the result. Note: (2x + 3)(3x − 1) is a non-monic binomial product. Develop the expansion systematically. After simplifying, you should get a quadratic that may or may not factorise neatly. Verify your factorisation by expanding. Then investigate: can every quadratic be factorised with integer coefficients? Try to factorise x² + x + 1 — what goes wrong? Explain why some quadratics are "irreducible" over the integers and how you can tell (link to the discriminant). 250–300 words.

## Watch out for these traps
- **Forgetting to multiply all terms.** 3(x + 4) = 3x + 12, NOT 3x + 4.
- **(x + 3)² ≠ x² + 9.** It equals x² + 6x + 9. Never forget the middle term.
- **Sign errors with negatives.** −2(x − 3) = −2x + 6, NOT −2x − 6. Negative × negative = positive.
- **Stopping at common factors.** Always check if the remaining bracket can be factorised further.
- **Not checking by expanding.** After factorising, always expand to verify you get the original expression.

## Try drawing this
Draw the area model for (x + 5)(x + 3): a rectangle split into four parts. Label each part with its area (x², 3x, 5x, 15). Show that the total area = x² + 8x + 15. Then reverse the process: given x² + 8x + 15, show how finding 3 and 5 (multiply to 15, add to 8) reconstructs the rectangle.

A note on certainty. Algebraic expansion is deterministic — there is exactly one correct expanded form for any product. Factorisation of monic quadratics with integer coefficients is also unique (up to order of factors). The methods taught here always work for monic quadratics that have integer factor pairs. When integer factors don't exist, the quadratic formula provides exact solutions, and the expression is irreducible over the integers.

**Try these scenarios**
1. *Room area.* (x + 2)(x + 5) = x² + 7x + 10. At x = 3: factored = 5 × 8 = 40 m². Expanded: 9 + 21 + 10 = 40 ✓.
2. *Park extension.* New area = (x + 3)(x + 4) = x² + 7x + 12. Extra area = 7x + 12 (compared to original x²). This represents the two rectangular strips and corner square added.
3. *Tiler.* x² + 5x + 6 = (x + 2)(x + 3). At x = 10: factored = 12 × 13 = 156 tiles. Expanded: 100 + 50 + 6 = 156 ✓.
4. *Expansion error.* (x + 3)² = x² + 6x + 9, NOT x² + 9. At x = 2: correct = 25 (since 5² = 25). Incorrect gives 4 + 9 = 13. The middle term (6x = 12) is missing, causing an error of 12.
5. *Al-Khwarizmi.* x² + 10x − 39 = 0. Need numbers multiplying to −39, adding to 10. That's +13 and −3. (x + 13)(x − 3) = 0. Solutions: x = −13 or x = 3. Since al-Khwarizmi only accepted positive roots: x = 3. Check: 9 + 30 = 39 ✓.

**Stretch task — example shape of a strong answer.** (2x+3)(3x−1) = 6x² − 2x + 9x − 3 = 6x² + 7x − 3. (x+2)² = x² + 4x + 4. Subtraction: 6x² + 7x − 3 − x² − 4x − 4 = 5x² + 3x − 7. Factorise 5x² + 3x − 7: need ac = −35 and factors adding to 3. Factors of −35: (7, −5). 7 + (−5) = 2 ≠ 3. Try (−7, 5): −2 ≠ 3. No integer pairs work — this quadratic is irreducible over integers. Check discriminant: b² − 4ac = 9 + 140 = 149. Since √149 is irrational, the quadratic has no rational factors. Not every quadratic factorises with integers — you can tell by checking whether the discriminant is a perfect square. If Δ is a perfect square, integer factorisation exists; if not, the expression is irreducible over ℚ.
