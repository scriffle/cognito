# VC2M10A06 — Mathematics (Short)

## Snapshot
- **Descriptor:** Implement algorithms that use data structures using pseudocode or a general purpose programming language.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** Data structures organise information for efficient processing. Lists store ordered data; dictionaries map keys to values. Pseudocode bridges mathematical thinking and executable code.

## What you are learning
- You are learning to **implement algorithms that use data structures** in pseudocode or a programming language like Python.
- You should choose appropriate structures and write clear procedures that process stored data.

## Core content

A **data structure** organises data for access and modification. Common types: **lists** (ordered, by index), **dictionaries** (key–value lookup), **2D arrays** (tables/grids).

**Lists.** `scores ← [85, 72, 91, 68, 77]`. Access by index: `scores[0]` = 85. Operations: append, remove, sort, search.

**Dictionaries.** `temps ← {"Mon": 22, "Tue": 19, "Wed": 24}`. Access by key: `temps["Tue"]` = 19. Useful for lookup by name.

**Common algorithm patterns:** traverse (visit all), search, accumulate (sum/average), filter (select by condition), sort.

**Worked example — class statistics:**
```
scores ← [78, 85, 62, 91, 74, 88, 56, 93, 70, 81]
total ← 0; highest ← scores[0]; lowest ← scores[0]
FOR each score IN scores:
    total ← total + score
    IF score > highest THEN highest ← score
    IF score < lowest THEN lowest ← score
mean ← total / LENGTH(scores)
```
Output: Mean 77.8, Highest 93, Lowest 56.

**Choosing structures.** Lists when order matters. Dictionaries for lookup by name. 2D arrays for grids (timetables, spreadsheets).

**Victorian and cultural context.** Metro Trains processes arrival-time lists to calculate delays. Bureau of Meteorology stores daily temperatures in arrays and computes monthly statistics. Aboriginal ranger programs use databases to record cultural-burn outcomes and species counts — structured data supporting land-management decisions.

## Memorable takeaways
- Lists: ordered, by index. Dictionaries: key–value pairs.
- Common patterns: traverse, search, accumulate, filter, sort.
- Pseudocode first, then code — catches logic errors early.
- Choose the structure that matches how you access the data.

## Watch out for these traps
- "Started index at 1." Most languages use zero-based indexing.
- "Used a list when a dictionary was better." If lookup is by name, use a dictionary.
- "Works for my data = correct." Test with edge cases: empty, one item, all same values.
