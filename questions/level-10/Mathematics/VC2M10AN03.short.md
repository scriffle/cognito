# VC2M10AN03 — Mathematics (Short)

## Snapshot
- **Descriptor:** Define logarithms, apply log laws and investigate logarithmic scales.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** logₐ(b) = c means aᶜ = b. Log laws mirror exponent laws: product, quotient, power. Logarithmic scales (pH, Richter, dB) compress vast ranges.

## What you are learning
- You are learning to **define logarithms**, **apply log laws**, and **interpret logarithmic scales**.
- You should be able to convert forms, simplify using log laws, and solve exponential equations.

## Core content

**Definition:** logₐ(b) = c means aᶜ = b. log₁₀(1000) = 3. logₐ(1) = 0. logₐ(a) = 1.

**Product law:** log(mn) = log(m) + log(n).

**Quotient law:** log(m/n) = log(m) − log(n).

**Power law:** log(mⁿ) = n·log(m). Brings exponents down as multipliers.

**Solving:** 2ˣ = 100 → x = log(100)/log(2) ≈ 6.644.

**Combining laws:** 2·log(3) + log(4) − log(6) = log(9) + log(4) − log(6) = log(36/6) = log(6).

**Logarithmic scales:** pH = −log₁₀[H⁺]. Richter: +1 magnitude = 10× amplitude. Decibels: +10 dB = 10× intensity.

**Victorian context.** John Napier (1614) invented logarithms. Victorian research institutions use log scales for environmental monitoring and seismology.

## Memorable takeaways
- logₐ(b) = c means aᶜ = b — the log is the exponent.
- Product: log(ab) = log a + log b. Quotient: log(a/b) = log a − log b. Power: log(aⁿ) = n log a.
- log(a + b) ≠ log a + log b — there is NO log law for sums.
- To solve aˣ = b: x = log b / log a.

## Watch out for these traps
- log(a + b) ≠ log(a) + log(b). The product law is for multiplication, not addition.
- log(a) − log(b) = log(a/b), not log(a − b).
- log(x) is undefined for x ≤ 0.
