# VC2M10AA04 — Mathematics (Short)

## Snapshot
- **Descriptor:** The inverse relationship between exponential and logarithmic functions.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** logₐ(b) = c means aᶜ = b — the logarithm is the exponent. Exponential and logarithmic functions are inverses, with graphs reflected in y = x. Logarithmic scales compress vast ranges into manageable numbers.

## What you are learning
- You are learning to **convert between exponential and logarithmic form**, evaluate logarithms, and sketch both function types.
- You should be able to solve exponential equations using logarithms and interpret logarithmic scales.

## Core content

**Exponential functions** y = aˣ have y-intercept (0, 1), asymptote y = 0, and are always positive.

**Logarithms:** logₐ(b) = c means aᶜ = b. Example: log₂(8) = 3 because 2³ = 8. Special values: logₐ(1) = 0, logₐ(a) = 1.

**Converting:** 5² = 25 ↔ log₅(25) = 2. Every exponential statement has an equivalent logarithmic form.

**Graphical relationship:** y = logₐ(x) is the reflection of y = aˣ in y = x. Features of y = logₐ(x): x-intercept (1, 0), vertical asymptote x = 0, domain x > 0.

**Solving:** 10ˣ = 500 → x = log₁₀(500) ≈ 2.699. For growth problems: 1.05ⁿ = 2 → n = log(2)/log(1.05) ≈ 14.21.

**Logarithmic scales:** Richter (magnitude +1 = 10× amplitude), pH (= −log₁₀[H⁺]), decibels (+10 dB = 10× intensity).

**Victorian context.** Victorian environmental researchers use pH to monitor waterway health. John Napier invented logarithms in 1614; Indian mathematician Jyeṣṭhadeva independently explored related series.

## Memorable takeaways
- logₐ(b) = c means aᶜ = b — always convert to check understanding.
- logₐ(1) = 0 and logₐ(a) = 1 for any valid base.
- Exponential and logarithmic graphs are reflections in y = x.
- Each unit on a logarithmic scale represents a constant multiplicative change, not additive.

## Watch out for these traps
- Confusing base and argument: in log₂(8) = 3, the base is 2, not 8.
- Falsely assuming log(a + b) = log(a) + log(b).
- Forgetting that logₐ(x) is undefined for x ≤ 0.
