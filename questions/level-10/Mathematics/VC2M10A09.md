# VC2M10A09 — Mathematics

## Snapshot
- **Descriptor:** VC2M10A09. Solve simultaneous linear equations, using algebraic and graphical techniques including using digital tools.
- **Year level / Learning area:** Years 9–10, Mathematics (Algebra).
- **Big ideas:**
  - Two linear equations with two unknowns can be solved simultaneously — the solution satisfies both equations at once.
  - Graphically, the solution is the point where two lines intersect.
  - Algebraically, substitution and elimination are systematic methods that always work.

## What you are learning
- You are learning to **solve simultaneous linear equations** using **substitution, elimination and graphical methods**.
- You are learning to interpret the solution as the intersection point of two lines.

By the end of this you should be able to:
- Solve a pair of simultaneous equations by substitution.
- Solve a pair of simultaneous equations by elimination.

## Core content

**1. What are simultaneous equations?** Two (or more) equations that must be true **at the same time** for the same values of the unknowns. For example: x + y = 10 and 2x − y = 5. The solution is the pair (x, y) that satisfies both. *Quick check:* Does the pair (5, 5) satisfy both x + y = 10 and 2x − y = 5?

**2. The graphical method.** Each linear equation represents a straight line. The solution is the **intersection point** — where the two lines cross. Plot both lines (by finding intercepts or using gradient-intercept form) and read off the coordinates. Limitation: reading from a graph gives approximate answers unless the intersection falls on grid points. *Quick check:* Two lines intersect at (3, 4). What does this tell you about the simultaneous equations?

**3. Substitution method.** (1) Rearrange one equation to make one variable the subject. (2) Substitute into the other equation. (3) Solve for the remaining variable. (4) Back-substitute to find the other. Example: y = 2x + 1 and 3x + y = 11. Substitute: 3x + (2x + 1) = 11 → 5x + 1 = 11 → 5x = 10 → x = 2. Then y = 2(2) + 1 = 5. Solution: (2, 5). *Quick check:* For x + y = 7 and y = x + 3, substitute the second into the first and solve.

**4. Elimination method.** (1) Multiply one or both equations so that a variable has the same (or opposite) coefficient. (2) Add or subtract the equations to eliminate that variable. (3) Solve, then back-substitute. Example: 2x + 3y = 12 and 4x − 3y = 6. Add the equations: 6x = 18 → x = 3. Substitute: 2(3) + 3y = 12 → 3y = 6 → y = 2. Solution: (3, 2). *Quick check:* For 3x + 2y = 16 and x + 2y = 10, subtract the second from the first to find x.

**5. Choosing a method.** Use **substitution** when one equation already has a variable isolated (e.g. y = ...). Use **elimination** when coefficients are easy to match. Use **graphical** for a visual check or when a digital tool is available. All three methods give the same answer. *Quick check:* Which method would you choose for y = 4x − 1 and 2x + 3y = 15? Why?

**6. Worked example — solving a ticket-pricing problem.**
A school sells adult tickets at $x and child tickets at $y for a concert. Two families buy tickets:
- Family A: 2 adults + 3 children = $36 → 2x + 3y = 36
- Family B: 4 adults + 1 child = $44 → 4x + y = 44

*Follow the thinking:*
- Elimination: multiply the first equation by 2 → 4x + 6y = 72.
- Subtract the second: (4x + 6y) − (4x + y) = 72 − 44 → 5y = 28 → y = 5.60.
- Substitute: 4x + 5.60 = 44 → 4x = 38.40 → x = 9.60.
- Solution: adult ticket = $9.60, child ticket = $5.60.
- Check: Family A: 2(9.60) + 3(5.60) = 19.20 + 16.80 = 36 ✓. Family B: 4(9.60) + 5.60 = 38.40 + 5.60 = 44 ✓.

**7. Special cases.** If the two lines are **parallel** (same gradient, different intercept), there is **no solution** — the system is inconsistent. If the two lines are **identical** (same equation written differently), there are **infinitely many solutions**. When solving algebraically, parallel lines give a contradiction (e.g. 0 = 5); identical lines give a tautology (e.g. 0 = 0). *Quick check:* You solve a system and get 0 = 7. What does this mean?

## Victorian and cultural context

- **Victorian anchor.** Simultaneous equations model real situations across Victoria: economists at the Reserve Bank use systems of equations for market equilibrium; traffic engineers at VicRoads model intersecting flow rates; the Melbourne Metro Tunnel project required solving multiple constraint equations simultaneously for tunnel alignment.
- **Aboriginal and Torres Strait Islander perspective.** Resource-sharing problems — such as dividing harvest between family groups where multiple constraints must be satisfied — embody the logic of simultaneous equations. Aboriginal corporations managing land, funding and community services apply this reasoning when balancing multiple budget lines simultaneously. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Systems of equations appear in everyday multicultural contexts: comparing phone plans with different rates, working out exchange rates for sending money to two different countries, or splitting shared household costs. Students can model family budgeting scenarios as simultaneous equations.

## Try these scenarios

1. **Everyday.** Two streaming services cost different monthly rates. Service A costs $x/month; Service B costs $y/month. You know that 3 months of A plus 2 months of B costs $52, and 1 month of A plus 4 months of B costs $46. Set up and solve the simultaneous equations.
2. **Civic.** A council buys benches at $x each and bins at $y each. Order 1: 5 benches + 3 bins = $2 100. Order 2: 2 benches + 7 bins = $1 900. Solve for the price of each item.
3. **Vocational.** An electrician charges $x per hour plus a $y call-out fee. Job 1 takes 3 hours and costs $255. Job 2 takes 5 hours and costs $375. Set up simultaneous equations and find x and y.
4. **Ethical.** A student solves graphically and reads the intersection as (2.5, 3.5). The algebraic solution is (2.4, 3.6). Discuss why the graphical answer might differ and which is more reliable.
5. **Cross-cultural.** Chinese mathematicians solved systems of linear equations over 2,000 years ago (the "Nine Chapters on the Mathematical Art"). Research this text and describe how its method compares to elimination.

## Memorable takeaways
- Simultaneous means "at the same time" — find values satisfying both equations.
- Graphically: the solution is the intersection point.
- Substitution: isolate one variable, substitute into the other equation.
- Elimination: make coefficients match, add or subtract to eliminate a variable.
- Always check by substituting back into both original equations.

## Stretch yourself
A café sells two drink sizes. A regular costs $x and a large costs $y. On Monday, the café sells 40 regulars and 25 larges for $292.50 total. On Tuesday, it sells 30 regulars and 35 larges for $295. Set up simultaneous equations. Solve using elimination. Then solve graphically (sketch or use digital tools) and confirm the same answer. If the café wants to make $500 in large-drink revenue on Wednesday, how many larges must it sell? Finally, discuss what would happen to the system if Tuesday's sales were exactly 0.75 times Monday's (every item scaled proportionally) — would you get a unique solution? Explain using the concept of parallel/identical lines. 250–300 words.

## Watch out for these traps
- **Arithmetic errors in elimination.** When multiplying an equation, multiply every term — including the constant on the right side.
- **Forgetting to check.** Always substitute your solution into both original equations. If it fails either, you made an error.
- **Adding when you should subtract (or vice versa).** If the coefficients you matched have the same sign, subtract. If opposite signs, add.
- **Misreading the graph.** Graphical solutions are only exact if the intersection falls on grid lines. Use algebra for precision.

A note on certainty. When two distinct non-parallel lines exist in a plane, they intersect at exactly one point — this is a theorem of Euclidean geometry. The algebraic methods (substitution, elimination) find that point exactly. Graphical methods give an approximation limited by drawing precision.

**Quick checks (Core content)**
1. *Does (5, 5) work?* x + y = 10 ✓. 2(5) − 5 = 5 ✓. Yes, it satisfies both.
2. *Intersection at (3, 4).* x = 3 and y = 4 is the solution to the system.
3. *Substitution.* x + (x + 3) = 7 → 2x + 3 = 7 → 2x = 4 → x = 2, y = 5.
4. *Elimination.* (3x + 2y) − (x + 2y) = 16 − 10 → 2x = 6 → x = 3. Then y = 3.5.
5. *Which method?* Substitution — y is already isolated in y = 4x − 1.
6. *Ticket prices.* x = $9.60, y = $5.60 (worked through in example).
7. *0 = 7.* No solution — the lines are parallel (inconsistent system).

**Try these scenarios**
1. *Streaming.* 3x + 2y = 52 and x + 4y = 46. From the second: x = 46 − 4y. Substitute: 3(46 − 4y) + 2y = 52 → 138 − 12y + 2y = 52 → −10y = −86 → y = 8.60. x = 46 − 34.40 = 11.60. Service A: $11.60/month, Service B: $8.60/month.
2. *Benches and bins.* 5x + 3y = 2100 and 2x + 7y = 1900. Multiply first by 7, second by 3: 35x + 21y = 14700, 6x + 21y = 5700. Subtract: 29x = 9000 → x = $310.34... (non-integer — recheck). Alternative: multiply first by 2, second by 5: 10x + 6y = 4200, 10x + 35y = 9500. Subtract: 29y = 5300 → y = $182.76... Note: this problem gives non-integer answers — acceptable in real pricing contexts. Bench ≈ $310, bin ≈ $183.
3. *Electrician.* 3x + y = 255 and 5x + y = 375. Subtract: 2x = 120 → x = 60. y = 255 − 180 = 75. Rate: $60/hour, call-out: $75.
4. *Graphical vs algebraic.* Graphical reading is limited by drawing precision and scale. Algebraic is exact. For precise answers, use algebra; for visual understanding, use graphs.
5. *Nine Chapters.* The Chinese method (Gaussian elimination avant la lettre) uses a coefficient matrix and systematic row operations — essentially the same logical steps as modern elimination.

**Stretch task — example shape of a strong answer.** 40x + 25y = 292.50 and 30x + 35y = 295. Multiply first by 7, second by 5: 280x + 175y = 2047.50, 150x + 175y = 1475. Subtract: 130x = 572.50 → x = 4.40. Substitute: 30(4.40) + 35y = 295 → 132 + 35y = 295 → y = 4.66 (approx). Regular: $4.40, large: ~$4.66. For $500 in large revenue: 500 ÷ 4.66 ≈ 107 larges. If Tuesday is exactly 0.75 × Monday, the two equations are scalar multiples (same line) — infinitely many solutions, no unique answer. The system becomes dependent.
