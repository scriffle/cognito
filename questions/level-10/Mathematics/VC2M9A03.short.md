# VC2M9A03 — Mathematics (Short)

## Snapshot
- **Descriptor:** Sketch linear graphs of equations in various algebraic forms, using the coordinates of 2 points, and solve linear equations.
- **Year / Area:** Years 9–10, Mathematics.
- **Big ideas:** A linear equation produces a straight-line graph. Two points define a line. Solving means finding the variable value that makes the equation true.

## What you are learning
- You are learning to **sketch linear graphs** from equations in different forms and to **solve linear equations** algebraically.
- You should connect solutions to graphs: the solution is the x-intercept.

## Core content

**Forms of linear equations.** Slope-intercept: y = mx + c. General: ax + by + c = 0. Intercept: x/a + y/b = 1. All produce straight lines.

**Sketching using two points.** Find two points (usually the intercepts) and draw a straight line through them. For y = 2x − 4: y-intercept (0, −4), x-intercept (2, 0). Plot and connect.

**Sketching from slope-intercept.** From y = mx + c: start at (0, c), use gradient m = rise/run to find a second point. For y = ²⁄₃x + 1: start at (0, 1), rise 2, run 3 → (3, 3).

**Solving linear equations.** Isolate the variable using inverse operations. Keep it balanced. 3x + 7 = 22 → 3x = 15 → x = 5. With brackets: 2(x − 4) = 3x + 1 → 2x − 8 = 3x + 1 → x = −9.

**Equations with fractions.** Multiply by the LCD to clear fractions. x/3 + x/4 = 7: LCD = 12. 4x + 3x = 84 → x = 12.

**Worked example.** Sketch 3x + 2y = 12. y-intercept: x = 0 → y = 6. x-intercept: y = 0 → x = 4. Plot (0, 6) and (4, 0), draw line. Check: 3(4) + 2(0) = 12 ✓.

**Victorian and cultural context.** Melbourne's Myki fare system, utility bills, and VicRoads fuel-cost models all use linear relationships. Small businesses across Melbourne's diverse communities use linear equations for pricing and break-even analysis. First Nations walking track alignments between significant sites model as linear paths on a coordinate plane.

## Memorable takeaways
- Linear equation → straight line. Two points define it.
- y = mx + c: m is gradient, c is y-intercept.
- Solve by isolating the variable — same operation to both sides.
- The x-intercept of the graph is the solution to the equation.

## Watch out for these traps
- "I only plotted one point." You need at least two distinct points for an accurate line.
- "I forgot the negative gradient." Negative m means the line slopes downward left to right.
- "I solved but didn't check." Substitute back to verify, especially with fractions and brackets.

- *Intercepts of y = −3x + 9?* y-int: (0, 9). x-int: (3, 0).
