# VC2M10AA07 — Mathematics (Short)

## Snapshot
- **Descriptor:** Factorise both monic and non-monic quadratic expressions and solve a wide range of quadratic equations.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** Monic quadratics have leading coefficient 1; non-monic have a ≠ 1. Three methods — factorisation, completing the square, quadratic formula — suit different situations. The discriminant Δ = b² − 4ac classifies solution types.

## What you are learning
- You are learning to **factorise monic and non-monic quadratics** and to **solve quadratic equations** using multiple methods.
- You should be able to select the most efficient method and use the discriminant to predict solution types.

## Core content

**Monic factorisation:** x² + bx + c: find factors of c that sum to b. x² + 7x + 12 = (x + 3)(x + 4).

**Non-monic factorisation:** For ax² + bx + c: find factors of ac that sum to b, split middle term, group. 6x² + 11x − 10 = (2x + 5)(3x − 2).

**Completing the square:** x² + bx + c = (x + b/2)² − (b/2)² + c. For x² + 6x + 1 = (x + 3)² − 8.

**Quadratic formula:** x = (−b ± √(b² − 4ac))/(2a). Universal method. For 2x² − 3x − 7 = 0: x = (3 ± √65)/4.

**Discriminant:** Δ > 0 → two real; Δ = 0 → one repeated; Δ < 0 → no real solutions.

**Worked example.** Rectangle: (x + 5)(x − 2) = 60 → x² + 3x − 70 = 0 → (x + 10)(x − 7) = 0. x = 7, dimensions 12 × 5.

**Victorian context.** Brahmagupta (7th century) developed the first general quadratic formula. Al-Khwārizmī's geometric completing-the-square method gave algebra its name.

## Memorable takeaways
- Monic: factors of c that sum to b. Non-monic: factors of ac that sum to b, then group.
- Completing the square reveals the vertex: (−b/2, c − b²/4).
- The quadratic formula works for every quadratic equation.
- Δ classifies solutions before solving.

## Watch out for these traps
- Sign errors in the quadratic formula — when b is negative, −b is positive.
- Forgetting to set the equation to zero before applying the formula.
- Rejecting negative solutions without checking whether the context demands it.

## Model responses

Use these to check your thinking after you have had a go.

- *Factorise x² − 5x + 6.* (x − 2)(x − 3).
- *Factorise 2x² + 7x + 3.* (x + 3)(2x + 1).
- *Complete the square: x² − 4x + 7.* (x − 2)² + 3.
- *Solve x² + 2x − 5 = 0.* x = −1 ± √6.
- *Discriminant of x² − 6x + 9 = 0.* Δ = 0. One repeated solution: x = 3.
- *Most efficient for x² − 100 = 0.* Difference of squares: (x − 10)(x + 10) = 0.
