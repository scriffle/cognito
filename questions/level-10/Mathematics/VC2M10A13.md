# VC2M10A13 — Mathematics

## Snapshot
- **Descriptor:** VC2M10A13. Solve simple quadratic equations using a range of strategies, including null factor law.
- **Year level / Learning area:** Years 9–10, Mathematics (Algebra).
- **Big ideas:**
  - A quadratic equation has the form ax² + bx + c = 0 and can have two, one or zero real solutions.
  - The **null factor law** (if ab = 0, then a = 0 or b = 0) is the key tool for solving factorised quadratics.
  - Strategies include factorising, completing the square, and using the quadratic formula.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **solve quadratic equations** using factorisation, the null factor law, and other strategies.
- You are learning to recognise when a quadratic has two solutions, one repeated solution, or no real solutions.

By the end of this you should be able to:
- Rearrange equations into standard form ax² + bx + c = 0.
- Factorise and apply the null factor law to find solutions.
- Use completing the square or the quadratic formula when factorisation is not straightforward.
- Interpret the number of solutions and check by substitution.

## Core content

**1. Standard form.** A quadratic equation must be written in the form ax² + bx + c = 0 before solving. Move all terms to one side so the other side equals zero. Example: x² + 5x = 14 becomes x² + 5x − 14 = 0. *Quick check:* Rearrange 3x² = 12 into standard form.

**2. The null factor law.** If the product of two factors equals zero, at least one factor must be zero: if A × B = 0 then A = 0 or B = 0. This means once you factorise a quadratic into two brackets, you can set each bracket to zero and solve. Example: (x − 3)(x + 2) = 0 → x = 3 or x = −2. *Quick check:* Solve (x − 7)(x + 1) = 0.

**3. Factorising then solving.** x² + 5x − 14 = 0. Find two numbers that multiply to −14 and add to +5: that's +7 and −2. So (x + 7)(x − 2) = 0 → x = −7 or x = 2. Always check: (−7)² + 5(−7) − 14 = 49 − 35 − 14 = 0 ✓. *Quick check:* Solve x² − 9x + 20 = 0 by factorising.

**4. Special cases.** Perfect square: x² − 6x + 9 = (x − 3)² = 0 → x = 3 (one repeated solution). Difference of squares: x² − 16 = (x − 4)(x + 4) = 0 → x = ±4. Common factor first: 3x² − 12x = 3x(x − 4) = 0 → x = 0 or x = 4. *Quick check:* Solve x² − 25 = 0.

**5. Completing the square.** When factorisation is not obvious, complete the square. x² + 8x + 3 = 0 → (x + 4)² − 16 + 3 = 0 → (x + 4)² = 13 → x + 4 = ±√13 → x = −4 ± √13. This always works for any quadratic. *Quick check:* Complete the square for x² + 6x + 2 = 0.

**6. Worked example — projectile height.**
A ball is kicked so its height is h = −t² + 6t (metres, t in seconds). When does it hit the ground?

*Follow the thinking:*
- Set h = 0: −t² + 6t = 0.
- Factor out −t: −t(t − 6) = 0.
- Null factor law: t = 0 or t = 6.
- t = 0 is the launch; t = 6 is when it lands.
- Check: h(6) = −36 + 36 = 0 ✓.
- The ball is in the air for 6 seconds.

**7. The quadratic formula.** For ax² + bx + c = 0: x = (−b ± √(b² − 4ac)) / 2a. The **discriminant** Δ = b² − 4ac tells you how many solutions: Δ > 0 → two solutions; Δ = 0 → one repeated solution; Δ < 0 → no real solutions. *Quick check:* For 2x² + 3x − 5 = 0, calculate the discriminant. How many solutions are there?

## Victorian and cultural context

- **Victorian anchor.** Engineers designing the Bolte Bridge calculated parabolic cable tensions using quadratic equations. The MCG's playing surface dimensions involve quadratic relationships in area calculations. Australian Rules football — modelling the arc of a kick — naturally produces quadratic equations for height vs time. AMSI resources connect quadratic solving to physics and engineering applications.
- **Aboriginal and Torres Strait Islander perspective.** Projectile problems connect to traditional knowledge of throwing implements — the trajectory of a spear or boomerang follows a parabolic path. While traditional calculations were not algebraic, the spatial reasoning about launch angles, distances and return points embodies the same physical relationships. - **Multicultural Australian perspective.** Quadratic equations appear in diverse practical contexts worldwide: architectural arches, satellite dish design, sports analytics, and business profit modelling. ## Try these scenarios

1. **Everyday.** A rectangular garden has length (x + 3) metres and width (x − 1) metres. Its area is 45 m². Set up the quadratic equation and solve for x. What are the garden's dimensions?
2. **Civic.** A council launches a firework vertically. Its height is h = −5t² + 40t + 2 (metres). When does it reach the ground (h = 0)? Use the quadratic formula. Interpret both solutions.
3. **Vocational.** A carpenter cuts a square from each corner of a 20 cm × 30 cm sheet of metal, then folds up the sides to make a tray. If the squares have side x cm and the base area of the tray is 416 cm², set up and solve the equation for x.
4. **Ethical.** A student solves x² = 9 and writes x = 3 only. What have they missed? Why does the ± matter in real contexts?
5. **Cross-cultural.** Al-Khwarizmi (9th century, Baghdad) solved quadratic equations by "completing the square" geometrically — literally completing a square shape with tiles. Draw a diagram showing how x² + 6x can be completed to (x + 3)² by adding 9 unit squares.

## Memorable takeaways
- Standard form first: ax² + bx + c = 0.
- Null factor law: if (A)(B) = 0, then A = 0 or B = 0.
- Factorise → apply null factor law → two solutions.
- Special cases: perfect squares (one solution), difference of squares.
- Quadratic formula works for all quadratics; discriminant tells you how many solutions.

## Stretch yourself
A farmer has 100 m of fencing and wants to enclose a rectangular paddock against an existing wall (so only 3 sides need fencing). Let x be the length of the sides perpendicular to the wall. Write the area as A = x(100 − 2x). Find the dimensions that give an area of exactly 1000 m² (solve the quadratic). Then find the maximum possible area by completing the square (or otherwise). Explain why there are two solutions for the 1000 m² problem but the maximum has only one. Discuss what happens if you try to solve for A = 1500 m² (check the discriminant). 250–300 words.

## Watch out for these traps
- **Forgetting to set the equation to zero.** The null factor law only works when one side is zero. x² + 5x = 14 cannot be factorised as is — rearrange first.
- **Losing a solution.** Never divide both sides by x (you lose x = 0 as a solution). Factor out x instead.
- **Only giving one answer.** Quadratics typically have two solutions — always check for both.
- **Not checking.** Substitute solutions back into the original equation to verify.

A note on certainty. The null factor law is a logical certainty — it follows directly from the properties of zero in multiplication. Every factorised quadratic yields exact solutions. The quadratic formula provides exact solutions for all quadratics with real coefficients; when the discriminant is negative, no real solutions exist, and this is a proven impossibility, not a limitation of method.

7. *Discriminant of 2x² + 3x − 5 = 0.* Δ = 9 − 4(2)(−5) = 9 + 40 = 49 > 0 → two real solutions.

**Try these scenarios**
1. *Garden.* (x+3)(x−1) = 45 → x² + 2x − 3 = 45 → x² + 2x − 48 = 0 → (x+8)(x−6) = 0 → x = 6 (reject x = −8). Dimensions: 9 m × 5 m. Check: 45 ✓.
2. *Firework.* −5t² + 40t + 2 = 0. Formula: t = (−40 ± √(1600 + 40))/−10 = (−40 ± √1640)/−10. t ≈ 8.05 s (positive solution). Negative solution represents time before launch — reject.
3. *Carpenter.* Base: (20−2x)(30−2x) = 416. 600 − 100x + 4x² = 416 → 4x² − 100x + 184 = 0 → x² − 25x + 46 = 0 → (x−2)(x−23) = 0. x = 2 (x = 23 exceeds sheet size). Squares are 2 cm × 2 cm.
4. *Missing solution.* x² = 9 gives x = ±3. Missing x = −3. In context: a square room with area 9 m² has sides 3 m (positive only), but in pure algebra both solutions exist.
5. *Al-Khwarizmi.* x² + 6x: draw a square (x²) and two rectangles (3x each side). Complete by adding a 3×3 square = 9. Total = (x+3)². Geometric diagram confirms algebraic method.

**Stretch task — example shape of a strong answer.** A = x(100−2x) = 100x − 2x². For A = 1000: 2x² − 100x + 1000 = 0 → x² − 50x + 500 = 0. Discriminant: 2500 − 2000 = 500 > 0. x = (50 ± √500)/2 = 25 ± 5√5. x ≈ 13.8 or x ≈ 36.2. Both valid (paddock is 72.4 × 13.8 or 27.6 × 36.2). Maximum: A = −2(x² − 50x) = −2(x−25)² + 1250. Maximum is 1250 m² when x = 25 (one solution — vertex). For A = 1500: x² − 50x + 750 = 0. Δ = 2500 − 3000 = −500 < 0. No real solutions — 1500 exceeds the maximum possible area.
