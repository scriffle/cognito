# VC2M10ASP05 — Mathematics (Short)

## Snapshot
- **Descriptor:** Apply Pythagoras' theorem and trigonometry to solve three-dimensional problems.
- **Year / Area:** Years 9–10 Advanced, Mathematics.
- **Big ideas:** 3D problems reduce to right-angled triangles within solids. Space diagonal: d = √(l² + w² + h²). Trig ratios apply to extracted 2D triangles.

## What you are learning
- You are learning to **apply Pythagoras' theorem and trigonometry to 3D problems** involving prisms, pyramids and cones.
- You should be able to identify right-angled triangles within 3D shapes and solve for unknown lengths and angles.

## Core content

**Space diagonal:** d = √(l² + w² + h²). For 3 × 4 × 12: d = √169 = 13.

**Angles in prisms:** Angle between space diagonal and base: tan(θ) = height / face diagonal.

**Pyramids:** Slant height uses half the base edge. Square pyramid base 10, height 12: slant height = √(5² + 12²) = 13.

**Cones:** l = √(r² + h²). Semi-vertical angle: tan(α) = r/h.

**3D elevation:** Find horizontal distance first (Pythagoras in ground plane), then apply trig vertically.

**Victorian context.** 3D calculations are fundamental to Victorian construction, mining and engineering. Ancient Egyptian builders used practical 3D geometry for pyramid construction.

## Memorable takeaways
- Space diagonal: d = √(l² + w² + h²).
- Identify and sketch right-angled triangles from the 3D shape.
- Slant height of a pyramid uses half the base edge, not the full edge.
- Find horizontal distance first, then apply trigonometry for elevation angles.

## Watch out for these traps
- Using full base edge instead of half for slant height.
- Forgetting to find horizontal distance in the ground plane first.
- Confusing slant height (to edge midpoint) with slant edge (to vertex).
