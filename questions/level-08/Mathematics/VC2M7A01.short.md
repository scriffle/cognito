# VC2M7A01 — Mathematics (Short)

## Snapshot
- **Descriptor:** Recognise and use variables to represent everyday formulas algebraically and substitute values into formulas to determine an unknown.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** A variable stands for a changeable quantity. Everyday formulas compress real-world rules into algebra. Substitution replaces a variable with a number to find an answer.

## What you are learning
- You are learning to **recognise variables** in everyday formulas and **substitute values** to find unknowns.
- You should be able to translate a word rule into an algebraic formula and evaluate it.

## Core content

A **variable** is a letter (such as *n*, *t*, *d*) representing a quantity that can change. A **constant** is a fixed number. In *C = 12n + 5*, the variables are *C* and *n*; the constants are 12 and 5.

**Everyday formulas** turn real-life rules into shorthand. Cost of entry: *C = 12n*. Perimeter of a rectangle: *P = 2(l + w)*. Average speed: *s = d / t*. Key translation words: "sum" → +, "product" → ×, "triple" → × 3.

**Substitution** means replacing a variable with a known number and evaluating. If *A = lw*, *l = 8*, *w = 3*, then *A = 24*. Always follow **BODMAS** — brackets first, then orders, multiplication and division left to right, addition and subtraction left to right.

**Finding an unknown:** if *C = 12n + 5* and *C = 41*, then *12n = 36*, so *n = 3*.

**Worked example — MCG perimeter fence.** Fencing costs $18 per metre around a rectangular section *l* m by *w* m. Formula: *Cost = 18 × 2(l + w)*. If *l = 45*, *w = 30*: Cost = 18 × 2(75) = 18 × 150 = $2 700. *Follow the thinking:* brackets → multiply → done.

**Checking.** Substitute your answer back into the original formula. If it produces the correct output, your solution is right.

**Cultural context.** Gunditjmara fish-trap engineering at Budj Bim required precise water-flow calculations — quantitative relationships embedded in Country. Melbourne tram fares, VicRoads speed-distance signs and Melbourne Water bills all use everyday formulas students encounter in daily life.

## Memorable takeaways
- A variable is a letter for a changeable quantity.
- Formulas compress real-world rules into algebra.
- Substitute means replace and evaluate.
- BODMAS governs the order of operations.

## Watch out for these traps
- "A variable can only be *x*." Any letter works — *n*, *t*, *d*, *C*.
- "Multiply before brackets." BODMAS says brackets come first.
- "Substitution is guessing." It is precise replacement followed by evaluation.
