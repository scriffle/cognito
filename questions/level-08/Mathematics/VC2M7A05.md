# VC2M7A05 — Mathematics

## Snapshot
- **Descriptor:** VC2M7A05. Generate tables of values from visually changing patterns or the rule of a function; describe and plot these relationships on the Cartesian plane.
- **Year level / Learning area:** Years 7–8, Mathematics (Algebra).
- **Big ideas:**
  - Patterns become rules; rules become tables; tables become graphs.
  - The Cartesian plane turns number relationships into pictures you can read.
  - Functions link every input to exactly one output.
- **Curriculum hooks:** Critical and Creative Thinking; Numeracy; Aboriginal and Torres Strait Islander Histories and Cultures.

## What you are learning
- You are learning to **spot a pattern, write its rule, build a table of values and plot the result on the Cartesian plane**.
- You are learning that a function is a reliable machine: put a number in, get exactly one number out.

By the end of this you should be able to:
- Identify a visual or numerical pattern and express it as a rule using a variable.
- Generate a table of values from that rule.
- Plot ordered pairs on the Cartesian plane and describe the shape of the graph.
- Predict values beyond the table by extending the pattern.

## Core content

**1. Patterns to rules.** A pattern is anything that repeats or grows in a predictable way. A matchstick triangle needs 3 matches; two triangles sharing a side need 5; three need 7. The rule is: number of matches = 2n + 1, where n is the number of triangles. *Quick check:* How many matches for 10 triangles?

**2. What is a function?** A **function** is a rule that assigns exactly one output to each input. If you put 4 into the rule y = 2x + 1, you always get 9. We call x the **independent variable** and y the **dependent variable**. *Quick check:* Why does the word "exactly one" matter in the definition?

**3. Building a table of values.** Choose several input values for x (often 0, 1, 2, 3, 4 …). Apply the rule to each. Record x and y side by side. The table for y = 2x + 1 starts: (0, 1), (1, 3), (2, 5), (3, 7), (4, 9). *Quick check:* Complete the table row for x = 6.

**4. The Cartesian plane.** Two perpendicular number lines cross at the **origin** (0, 0). The horizontal axis is x; the vertical axis is y. Every point is an **ordered pair** (x, y). The plane has four **quadrants**, but at Level 7 you mostly work in the first quadrant (both values positive). *Quick check:* Which quadrant contains the point (−3, 2)?

**5. Plotting ordered pairs.** Start at the origin. Move right by the x-value, then up by the y-value. Mark the dot. For (2, 5): move 2 right and 5 up. When you plot all the pairs from a table, the dots often line up. *Quick check:* If the dots from your table form a straight line, what does that tell you about the rule?

**6. Worked example — growing tile pattern.**
A square tile pattern grows: 1, 4, 9, 16 … The rule is y = n², where n is the position number.

| n | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| y | 1 | 4 | 9 | 16 | 25 |

*Follow the thinking:* Plot these on the Cartesian plane. The dots curve upward — this is not a straight line but a **parabola** shape. The rule is **non-linear** because the variable is squared.

**7. Reading the graph.** Once plotted, a graph tells a story. A straight line means the pattern grows by the same amount each step (**linear**). A curve means the growth rate changes (**non-linear**). You can read values from the graph that are not in your table — this is called **interpolation** (between known points) or **extrapolation** (beyond them). *Quick check:* What is the difference between interpolation and extrapolation?

## Victorian and cultural context

- **Victorian anchor.** The Australian Mathematical Sciences Institute (AMSI) in Melbourne provides curriculum resources on functions and graphing. Melbourne's rectangular grid layout — Hoddle Grid — is itself a Cartesian structure: intersections are described by two coordinates (street and cross-street). The MCG's seating map uses row-and-seat numbering that mirrors ordered pairs.
- **Aboriginal and Torres Strait Islander perspective.** First Nations string-figure traditions across many Nations encode geometric patterns and sequences passed through generations. Wurundjeri Woi Wurrung seasonal calendars track environmental cycles that follow repeating patterns — the flowering of certain plants signals when fish are running, a practical function linking observation to action. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Melbourne's diverse markets — Queen Victoria Market, Footscray Market — use pattern-based pricing (per kilogram, per bunch). Students from many cultural backgrounds bring number-pattern games and counting traditions that connect to algebraic thinking.

## Try these scenarios

1. **Everyday.** You notice a café loyalty card: buy 1 coffee and get 1 stamp; every 8th coffee is free. Build a table showing coffees bought vs. total cost (at $5 each) for 1 to 16 coffees, accounting for the free ones. Plot it on a Cartesian plane. Is the relationship linear?
2. **Civic.** The City of Greater Bendigo plants 15 new trees each year in a revegetation corridor. Write the rule for total trees after n years (starting from 40 existing trees). Plot the first 10 years and predict the total at year 20.
3. **Vocational.** A tiler in Geelong charges $50 call-out plus $35 per square metre. Write the cost function, build a table for 1–8 m² and plot it. Use your graph to estimate the cost for 6.5 m².
4. **Ethical.** A student claims that because the dots on their graph line up, the pattern will continue forever. Identify two reasons this assumption might be wrong in the real world.
5. **Cross-cultural.** A school collaborates with a Wurundjeri educator to record seasonal flowering times over 12 months. Represent the data as ordered pairs (month number, number of species flowering) and describe the shape of the graph.

## Memorable takeaways
- A pattern becomes a rule; a rule fills a table; a table draws a graph.
- A function gives exactly one output for each input.
- The Cartesian plane turns algebra into geometry you can see.
- Straight lines mean constant growth; curves mean changing growth.
- Graphs let you predict values you have not calculated.

## Stretch yourself
A community garden in Darebin allocates plots in a pattern: Row 1 has 2 plots, Row 2 has 5, Row 3 has 8, Row 4 has 11. Find the rule linking row number (n) to number of plots (p). Build a table for rows 1–10 and plot the ordered pairs. The garden committee wants at least 50 plots in a single row. Which is the first row that meets this? Explain whether it is realistic to keep extending the pattern and identify one real-world constraint that could break it. Show all working. 250–300 words.

## Watch out for these traps
- **Confusing the axes.** The x-value is always horizontal (across first), the y-value always vertical (up second). Plot (3, 5) not (5, 3).
- **Assuming every pattern is linear.** Check whether the difference between consecutive y-values is constant. If not, the relationship is non-linear.
- **Forgetting that graphs can mislead.** A pattern observed over 5 values does not guarantee the 50th value follows the same rule in real life.
- **Mixing up interpolation and extrapolation.** Interpolation reads between known points (safer); extrapolation predicts beyond them (riskier).

## Model responses

Use these to check your own thinking after you have had a go.

**Quick checks (Core content)**

1. *Matches for 10 triangles.* 2(10) + 1 = 21 matches.
2. *Why "exactly one" matters.* If an input could give two different outputs, you would not have a reliable rule — you could not predict or graph consistently.
3. *Table row for x = 6.* y = 2(6) + 1 = 13. The ordered pair is (6, 13).
4. *Which quadrant for (−3, 2)?* The second quadrant (x negative, y positive).
5. *Straight-line dots.* The rule is linear — the output increases by the same amount for each unit increase in the input.
6. *Interpolation vs extrapolation.* Interpolation estimates between data points you already have; extrapolation estimates beyond them, which is less certain.

**Try these scenarios**

1. *Café loyalty card.* The cost is $5 per coffee, but every 8th is free, so in 16 coffees you pay for 14. The graph shows a mostly linear pattern with a flat step at coffees 8 and 16. It is close to linear but not perfectly so.
2. *Bendigo trees.* Rule: T = 40 + 15n. At year 10: T = 190. At year 20: T = 340. Graph is a straight line starting at (0, 40) with gradient 15.
3. *Geelong tiler.* C = 50 + 35m. For 6.5 m²: C = 50 + 35(6.5) = $277.50. Read from the graph by finding 6.5 on the x-axis and tracing up to the line.
4. *Pattern-forever assumption.* (a) Real-world constraints (cost, space, materials) may stop the pattern. (b) The data may be too small a sample — a pattern in five values does not guarantee the hundredth.
5. *Seasonal flowering data.* The graph likely shows a curve rising in spring, peaking in early summer, and falling in winter — a seasonal cycle, non-linear.

**Stretch task — example shape of a strong answer.** Rule: p = 3n − 1. Row 1: 2, Row 2: 5, …, Row 10: 29. For p ≥ 50: 3n − 1 ≥ 50, so n ≥ 17. Row 17 has 50 plots. Real-world constraint: physical space — at some point rows exceed the garden's width. The graph is a straight line with gradient 3, starting at (1, 2).
