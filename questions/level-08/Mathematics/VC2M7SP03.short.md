# VC2M7SP03 — Mathematics (Short)

## Snapshot
- **Descriptor:** Describe the effect of transformations of a set of points using coordinates in the Cartesian plane, including translations, reflections in an axis, and rotations about the origin.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** A transformation moves a shape according to a precise coordinate rule. Translations slide, reflections flip, rotations turn. All three preserve shape and size.

## What you are learning
- You are learning to **describe transformations** using **coordinates** in the Cartesian plane.
- You should be able to apply the coordinate rules for translations, reflections and rotations and state the new coordinates.

## Core content

The **Cartesian plane** has a horizontal x-axis and vertical y-axis meeting at the origin (0, 0). Every point is an ordered pair *(x, y)*.

**Translation** slides every point by *(a, b)*: *(x, y) → (x + a, y + b)*. Shape, size and orientation are preserved.

**Reflection in the x-axis** flips vertically: *(x, y) → (x, −y)*. **Reflection in the y-axis** flips horizontally: *(x, y) → (−x, y)*.

**Rotation about the origin.** 90° anticlockwise: *(x, y) → (−y, x)*. 180°: *(x, y) → (−x, −y)*. 90° clockwise: *(x, y) → (y, −x)*.

All three transformations are **isometries** — they preserve side lengths and angles. Only position and/or orientation change.

**Worked example — Hosier Lane mural.** A rectangle has corners A(1, 1), B(4, 1), C(4, 3), D(1, 3). Reflect in the y-axis: A′(−1, 1), B′(−4, 1), C′(−4, 3), D′(−1, 3). Translate the reflection down by (0, −5): A″(−1, −4), B″(−4, −4), C″(−4, −2), D″(−1, −2). *Follow the thinking:* apply the rule to each vertex → plot → check shape is preserved.

**Cultural context.** Aboriginal art across south-eastern Australia uses reflection and rotational symmetry in shield carvings and possum-skin cloak designs. Hosier Lane street art, Flinders Street Station's symmetrical facade and Melbourne game studios all use coordinate transformations in design and animation.

## Memorable takeaways
- Translation: *(x, y) → (x + a, y + b)* — slide.
- x-axis reflection: *(x, y) → (x, −y)* — flip y.
- y-axis reflection: *(x, y) → (−x, y)* — flip x.
- 90° anticlockwise rotation: *(x, y) → (−y, x)*.

## Watch out for these traps
- "x-axis reflection changes the x-coordinate." No — it changes the y-coordinate.
- "Rotation changes size." Rotation preserves shape and size.
- "90° clockwise equals 90° anticlockwise." They give different images.

- *Reflect (4, 7) in the x-axis.* (4, −7).
- *Reflect (−3, 2) in the y-axis.* (3, 2).
- *Rotate (3, 1) by 90° anticlockwise.* (−1, 3).
