By the end of this you should be able to:

## Core content

**1. What is a conjecture?** A **conjecture** is a statement you believe to be true based on evidence, but have not yet proved. "I think all lines with a positive gradient slope upward to the right" is a conjecture. You test it by trying more examples or by reasoning logically. *Quick check:* Is a conjecture the same as a proof? Why not?

**2. Digital tools for experimentation.** **Desmos** and **GeoGebra** let you type a linear rule, adjust parameters with sliders and see the graph change instantly. **Spreadsheets** let you generate tables of values for many rules at once. These tools make it easy to test dozens of examples in minutes. *Quick check:* What advantage does a slider give you when exploring gradients?

**3. Experimenting with gradient.** Graph *y = x*, *y = 2x*, *y = 3x*, *y = 0.5x*, *y = −x*, *y = −2x*. Observation: as the number in front of *x* (the gradient) increases, the line gets steeper. When the gradient is negative, the line slopes downward. When the gradient is zero, the line is horizontal. *Quick check:* What do you notice about all lines with gradient 0?

**4. Experimenting with y-intercept.** Graph *y = 2x*, *y = 2x + 3*, *y = 2x − 4*. Observation: changing the constant shifts the line up or down without changing its slope. The constant is the y-intercept. *Quick check:* If you change only the y-intercept, what stays the same about the line?

**5. Parallel and intersecting lines.** Lines with the **same gradient but different y-intercepts** are parallel — they never meet. Lines with **different gradients** will intersect at exactly one point. *Quick check:* Are *y = 3x + 1* and *y = 3x − 5* parallel? How do you know?

**6. Worked example — investigating number patterns with GeoGebra.** A student explores the "family" of lines *y = mx + 2* by using a slider for *m*. Observations: all lines pass through (0, 2). As *m* increases from 0, lines fan out steeper. As *m* becomes negative, lines slope down but still pass through (0, 2). Conjecture: "All lines of the form *y = mx + 2* pass through (0, 2) regardless of *m*." Test: substitute *x = 0* into *y = mx + 2*: *y = m(0) + 2 = 2*. Confirmed for all *m*. Generalisation: in *y = mx + c*, the line always passes through (0, *c*). *Follow the thinking:* experiment → observe → conjecture → test → generalise.

**7. The conjecture–test–generalise cycle.** This is how mathematicians work: notice a pattern, state it clearly, test it with new cases, and either generalise it into a rule or find a counter-example that disproves it. A single counter-example is enough to disprove a conjecture. *Quick check:* What disproves a conjecture — one counter-example or many supporting examples?

## Try these scenarios

1. **Everyday.** Use Desmos to graph *y = x + 1*, *y = x + 3* and *y = x − 2*. State a conjecture about lines with gradient 1 but different y-intercepts. Test with one more example.
2. **Civic.** Darebin City Council models three different rates-increase options as linear functions. Graph them on the same axes using a spreadsheet. Make a conjecture about which option grows fastest and justify with evidence from the gradient.
3. **Vocational.** An apprentice electrician uses GeoGebra to explore Ohm's law (*V = IR*) by fixing *R* and varying *I*. Describe the pattern and state a generalisation about the graph's gradient.
4. **Ethical.** A student conjectures "doubling the gradient doubles the steepness." Test this with Desmos by graphing *y = 2x*, *y = 4x* and *y = 8x*. Does the visual impression match the mathematics? Discuss whether "steepness" has a precise mathematical meaning.
5. **Cross-cultural.** Aboriginal seasonal calendars predict resource availability based on observed patterns. If eel migration in the Birrarung correlates approximately with water temperature rising past 15°C, how is this similar to making and testing a conjecture?

## Memorable takeaways
- A conjecture is an observed pattern stated as a testable claim.
- Digital tools let you test many cases quickly — use sliders, tables and graphs.
- Changing the gradient changes the steepness; changing the y-intercept shifts the line up or down.
- Parallel lines have the same gradient.
- One counter-example disproves a conjecture; many examples support but do not prove it.

## Stretch yourself
Use Desmos or GeoGebra to explore the family of lines *y = mx − m* for different values of *m*. Graph at least five members of the family (e.g., *m = 1, 2, −1, 0.5, −3*). Observe where all the lines appear to pass through. State a conjecture. Then prove your conjecture algebraically by finding the point that satisfies *y = mx − m* for all values of *m* (hint: factor out *m*). Finally, generalise: what does the expression *y = m(x − 1)* tell you about the family? Write up your investigation clearly, showing each stage of the conjecture–test–generalise cycle. 250–300 words.

## Watch out for these traps
- "Five examples prove my conjecture." Examples support a conjecture but do not prove it — you need logical reasoning or algebraic proof.
- "Parallel lines eventually meet." Parallel lines (same gradient, different y-intercept) never meet by definition.
- "The y-intercept affects steepness." It only shifts the line up or down; the gradient determines steepness.
- "Digital tools replace thinking." They generate data for you to interpret — you still need to observe, conjecture and reason.

## Model responses

Use these to check your own thinking after you have had a go.

**Quick checks (Core content)**

1. *Conjecture vs proof.* A conjecture is a testable claim based on pattern; a proof establishes it as always true through logical reasoning. A conjecture can be wrong.
2. *Slider advantage.* It lets you change the gradient (or y-intercept) smoothly and see the graph update in real time, making patterns visible instantly.
3. *Lines with gradient 0.* They are all horizontal — flat lines at different heights (their y-intercept value).
4. *Same gradient, different intercept.* The steepness (slope) stays the same; only the vertical position changes.
5. *Are y = 3x + 1 and y = 3x − 5 parallel?* Yes — same gradient (3), different y-intercepts (1 and −5).
6. *One counter-example.* One counter-example disproves a conjecture completely. Many supporting examples can never prove it.

**Try these scenarios**

1. *Gradient-1 lines.* All slope at the same angle (45° to horizontal). Conjecture: "Lines with the same gradient are parallel." Test with *y = x + 10* — it is parallel to the others. Confirmed.
2. *Council rates.* The line with the largest gradient grows fastest. Compare slopes numerically to confirm.
3. *Ohm's law.* For fixed *R*, the graph of *V* vs *I* is a straight line through the origin with gradient *R*. Generalisation: gradient = resistance.
4. *Doubling gradient.* Visually, *y = 4x* appears "twice as steep" as *y = 2x*. Mathematically, steepness is defined by gradient, so doubling the gradient exactly doubles the rate of rise per unit run. The conjecture holds if "steepness" = gradient.
5. *Eel migration.* The observation is a pattern (temperature threshold → eel movement). Stating it as a rule and checking each year mirrors the conjecture–test cycle. Refinement over generations mirrors generalisation.

**Stretch task — example shape of a strong answer.** Family: *y = mx − m = m(x − 1)*. For any *m*, when *x = 1*: *y = m(1 − 1) = 0*. Conjecture: all lines pass through (1, 0). Tested with *m = 1, 2, −1, 0.5, −3* — all pass through (1, 0). Proof: *y = m(x − 1)* equals 0 when *x = 1* regardless of *m*. Generalisation: factoring out *m* reveals the common point. The expression *y = m(x − 1)* means the entire family rotates around the fixed point (1, 0).
