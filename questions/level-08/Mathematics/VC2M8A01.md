# VC2M8A01 — Mathematics

## Snapshot
- **Descriptor:** VC2M8A01. Create, expand, factorise, rearrange and simplify linear expressions, applying the associative, commutative, identity, distributive and inverse properties.
- **Year level / Learning area:** Years 7–8, Mathematics (Algebra).
- **Big ideas:**
  - Algebra is a language for expressing general relationships — letters stand for numbers that can vary.
  - The associative, commutative, identity, distributive and inverse properties are the rules that make algebraic manipulation reliable.
  - Expanding and factorising are reverse operations — mastering both gives you flexibility.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking.

## What you are learning
- You are learning to **create, expand, factorise, rearrange and simplify linear expressions** using the fundamental properties of operations.
- You are learning to move confidently between different forms of the same expression.

By the end of this you should be able to:
- Identify and apply the commutative, associative, identity, distributive and inverse properties.
- Expand expressions such as 3(2x + 5).
- Factorise by finding the highest common factor.
- Collect like terms to simplify.
- Rearrange expressions into equivalent forms.

## Core content

**1. What is a linear expression?** A **linear expression** contains variables raised to the power of 1 (no squares, cubes or higher). Examples: 3x + 2, 4a − 7b + 1, 2(m + 5). The word "linear" means the graph of the expression is a straight line. *Quick check:* Is 5x² + 3 a linear expression? Why or why not?

**2. The five key properties.** These rules work for all real numbers and are the foundation of algebraic manipulation.
- **Commutative:** a + b = b + a and a × b = b × a (order does not matter for addition or multiplication).
- **Associative:** (a + b) + c = a + (b + c) and (a × b) × c = a × (b × c) (grouping does not matter).
- **Identity:** a + 0 = a (additive identity) and a × 1 = a (multiplicative identity).
- **Inverse:** a + (−a) = 0 (additive inverse) and a × (1/a) = 1 for a ≠ 0 (multiplicative inverse).
- **Distributive:** a(b + c) = ab + ac (multiplication distributes over addition).

*Quick check:* Which property tells you that 3 × 7 = 7 × 3?

**3. Expanding.** **Expanding** means using the distributive property to remove brackets. Multiply the term outside the bracket by every term inside.
- 3(2x + 5) = 3 × 2x + 3 × 5 = 6x + 15.
- −2(4a − 3) = −2 × 4a + (−2) × (−3) = −8a + 6.

Watch the signs — a negative outside the bracket changes the sign of every term inside. *Quick check:* Expand 5(3m − 4).

**4. Collecting like terms.** **Like terms** have the same variable part (e.g. 3x and 7x are like terms; 3x and 3y are not). Add or subtract the coefficients: 3x + 7x = 10x. Combine expanding with collecting: 2(3x + 1) + 4(x − 2) = 6x + 2 + 4x − 8 = 10x − 6. *Quick check:* Simplify 5a + 3b − 2a + b.

**5. Factorising.** **Factorising** is the reverse of expanding — you find the **highest common factor** (HCF) and write it outside brackets.
- 6x + 15 → HCF is 3 → 3(2x + 5).
- 12m − 8 → HCF is 4 → 4(3m − 2).

Check by expanding: 4(3m − 2) = 12m − 8. ✓ *Quick check:* Factorise 10y + 25.

**6. Worked example — simplifying an expression for a fencing problem.**
A farmer needs fencing for a rectangular paddock with length (2x + 3) m and width (x + 1) m. Write a simplified expression for the perimeter.

*Follow the thinking:*
- Perimeter = 2 × length + 2 × width = 2(2x + 3) + 2(x + 1).
- Expand: 4x + 6 + 2x + 2.
- Collect like terms: 6x + 8.
- Factorise (optional, to check): 2(3x + 4).
- The perimeter is (6x + 8) metres, or equivalently 2(3x + 4) metres.

**7. Rearranging expressions.** Rearranging means writing an expression in a different but equivalent form — often to isolate a variable or to make a pattern clearer. Use the inverse properties: undo addition with subtraction, undo multiplication with division. For example, from 6x + 8 you can write 2(3x + 4) (factorised form) or 6x + 8 (expanded form). Both represent the same quantity. *Quick check:* Rearrange 4x + 12 into factorised form.

## Victorian and cultural context

- **Victorian anchor.** Algebraic modelling is used across Victorian industries: engineers at AMSI and the Australian Synchrotron in Clayton write expressions for physical quantities; architects use algebraic formulas when designing structures like the Melbourne Rectangular Stadium roof. Linear expressions underpin spreadsheet formulas used in every Victorian business.
- **Aboriginal and Torres Strait Islander perspective.** Pattern and relationship thinking is embedded in First Nations cultural practice — kinship systems, for example, encode complex relational rules. While these systems are not "algebra" in the Western sense, they demonstrate sophisticated systematic reasoning about relationships. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Algebra has a rich multicultural history — the word "algebra" comes from the Arabic "al-jabr," from the work of the 9th-century mathematician al-Khwārizmī. Students can explore how algebraic thinking developed across cultures, including Indian, Chinese and Islamic mathematical traditions.

## Try these scenarios

1. **Everyday.** You buy x notebooks at $3 each and y pens at $2 each, plus a $5 bag. Write an expression for the total cost. If x = 4 and y = 6, calculate the total.
2. **Civic.** The City of Wyndham is fencing two sides of a rectangular park. One side is (3x + 2) m and the adjacent side is (2x − 1) m. Write and simplify an expression for the total fencing needed (two sides only).
3. **Vocational.** An electrician charges a $60 call-out fee plus $45 per hour. Write a linear expression for the total cost of h hours of work. Expand and simplify if the customer also pays 10% GST on the total.
4. **Ethical.** A classmate simplifies 3(x + 2) as 3x + 2. Identify the error, explain what went wrong, and show the correct expansion.
5. **Cross-cultural.** Research al-Khwārizmī and write two sentences about how his work laid the foundations for modern algebra. Then expand and simplify: 2(3x + 4) + 5(x − 1).

## Memorable takeaways
- Expanding uses the distributive property: a(b + c) = ab + ac.
- Factorising reverses expanding: find the HCF and write it outside brackets.
- Like terms share the same variable part — collect them by adding coefficients.
- The five properties (commutative, associative, identity, distributive, inverse) justify every step.
- Always check by expanding what you factorised (or vice versa).

## Stretch yourself
A community garden has three rectangular plots. Plot A is x m by (x + 2) m. Plot B is 2x m by 3 m. Plot C is (x + 1) m by 4 m. Write an expression for the total area of all three plots. Note: x × (x + 2) = x² + 2x is technically quadratic, but treat it as part of the exercise. Expand, collect like terms and simplify to a single expression. Then factorise as far as possible. If x = 5, calculate the total area in square metres. Finally, write the perimeter of each plot as a linear expression, find the total perimeter of all three plots, and simplify. Show all working and name the property you use at each step. 250–300 words.

## Watch out for these traps
- **Forgetting to multiply every term inside the bracket.** 3(x + 2) = 3x + 6, not 3x + 2. The distributive property applies to all terms.
- **Sign errors with negatives.** −2(4a − 3) = −8a + 6, not −8a − 6. A negative times a negative gives a positive.
- **Combining unlike terms.** 3x + 2y cannot be simplified further — x and y are different variables.
- **Incomplete factorising.** Always check you have found the highest common factor. 6x + 12 = 6(x + 2), not 2(3x + 6) — the second form can be factorised further.

A note on certainty. The properties described here (commutative, associative, distributive, identity, inverse) are axioms of real-number arithmetic — they are assumed true and everything else follows from them. Algebraic manipulation is exact: if you apply the rules correctly, the result is guaranteed equivalent.

## Model responses

Use these to check your own thinking after you have had a go.

**Quick checks (Core content)**
1. *Is 5x² + 3 linear?* No — x² means the variable is squared (degree 2), not linear (degree 1).
2. *Which property?* The commutative property of multiplication.
3. *Expand 5(3m − 4).* 15m − 20.
4. *Simplify 5a + 3b − 2a + b.* 3a + 4b.
5. *Factorise 10y + 25.* HCF = 5. Answer: 5(2y + 5).
6. *Fencing perimeter.* 2(2x + 3) + 2(x + 1) = 4x + 6 + 2x + 2 = 6x + 8 = 2(3x + 4).
7. *Factorise 4x + 12.* HCF = 4. Answer: 4(x + 3).

**Try these scenarios**
1. *Notebook and pen cost.* Total = 3x + 2y + 5. When x = 4, y = 6: 3(4) + 2(6) + 5 = 12 + 12 + 5 = $29.
2. *Wyndham fencing.* (3x + 2) + (2x − 1) = 5x + 1 metres.
3. *Electrician.* Cost = 60 + 45h. With 10% GST: 1.1(60 + 45h) = 66 + 49.5h.
4. *Error identification.* The student only multiplied x by 3, not the 2. Correct: 3(x + 2) = 3x + 6. The distributive property requires multiplying every term inside the bracket.
5. *al-Khwārizmī and simplification.* 2(3x + 4) + 5(x − 1) = 6x + 8 + 5x − 5 = 11x + 3.

**Stretch task — example shape of a strong answer.** Plot A area = x(x + 2) = x² + 2x. Plot B area = 2x × 3 = 6x. Plot C area = (x + 1) × 4 = 4x + 4. Total perimeter = 4x + 4 + 4x + 6 + 2x + 10 = 10x + 20 = 10(x + 2). Properties named at each step (distributive for expanding, commutative for reordering terms, associative for grouping).
