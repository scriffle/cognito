# VC2M8A01 — Mathematics (Short)

## Snapshot
- **Descriptor:** Create, expand, factorise, rearrange and simplify linear expressions, applying the associative, commutative, identity, distributive and inverse properties.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** Algebra expresses general relationships using letters for numbers. The five key properties (commutative, associative, identity, distributive, inverse) make manipulation reliable. Expanding and factorising are reverse operations.

## What you are learning
- You are learning to **create, expand, factorise, rearrange and simplify linear expressions** using the fundamental properties of operations.
- You should be able to move confidently between different forms of the same expression.

## Core content

A **linear expression** has variables to the power of 1 only (e.g. 3x + 2, not 5x²). The five properties that justify every algebraic step: **commutative** (order does not matter), **associative** (grouping does not matter), **identity** (adding 0 or multiplying by 1 changes nothing), **inverse** (undo with the opposite operation), **distributive** (a(b + c) = ab + ac).

**Expanding** removes brackets using the distributive property: 3(2x + 5) = 6x + 15. Watch signs: −2(4a − 3) = −8a + 6.

**Collecting like terms** simplifies: 6x + 2 + 4x − 8 = 10x − 6. Like terms share the same variable part.

**Factorising** reverses expanding — find the **highest common factor** (HCF): 6x + 15 → HCF = 3 → 3(2x + 5). Always check by expanding back.

**Worked example.** A paddock has length (2x + 3) m and width (x + 1) m. Perimeter = 2(2x + 3) + 2(x + 1) = 4x + 6 + 2x + 2 = 6x + 8 = 2(3x + 4).

**Victorian context.** The word "algebra" comes from the Arabic "al-jabr," from al-Khwārizmī's 9th-century work. Engineers at AMSI and the Australian Synchrotron use algebraic expressions daily. Linear expressions underpin every spreadsheet formula in Victorian business.

## Memorable takeaways
- Expanding: a(b + c) = ab + ac.
- Factorising: find the HCF, write it outside brackets.
- Like terms share the same variable — collect by adding coefficients.
- The five properties justify every step.
- Check by reversing: expand what you factorised.

## Watch out for these traps
- Forgetting to multiply every term inside the bracket: 3(x + 2) = 3x + 6, not 3x + 2.
- Sign errors with negatives: −2(4a − 3) = −8a + 6, not −8a − 6.
- Combining unlike terms: 3x + 2y cannot be simplified further.

## Model responses

Use these to check your thinking after you have had a go.

- *Is 5x² + 3 linear?* No — x² is degree 2, not degree 1.
- *Expand 5(3m − 4).* 15m − 20.
- *Simplify 5a + 3b − 2a + b.* 3a + 4b.
- *Factorise 10y + 25.* 5(2y + 5).
- *Factorise 4x + 12.* 4(x + 3).
