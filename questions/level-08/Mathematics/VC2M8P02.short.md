# VC2M8P02 — Mathematics (Short)

## Snapshot
- **Descriptor:** Determine all possible outcome combinations for 2 events, using two-way tables, tree diagrams and Venn diagrams, and use these to determine probabilities of specific events in practical situations.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** Two events combine to produce outcome pairs. Two-way tables, tree diagrams and Venn diagrams each display outcomes differently. Choose the display that fits your question.

## What you are learning
- You are learning to **list all outcome combinations** for two events and use **tables, trees and Venn diagrams** to calculate probabilities.
- You should be able to construct each display and read probabilities from it.

## Core content

When two events combine, total combinations = outcomes of event 1 × outcomes of event 2. A die and a coin: 6 × 2 = 12.

**Two-way tables** list one event across the top, the other down the side. Each cell is one combination. Count favourable cells ÷ total = probability.

**Tree diagrams** branch sequentially: first event splits, then each branch splits again for the second event. Each root-to-tip path is one outcome. Multiply along branches for path probability; add matching paths for event probability.

**Venn diagrams** show overlapping circles in a rectangle (sample space). Best for "and," "or" and "neither" questions. P(A or B) = P(A) + P(B) − P(A and B).

**Worked example — school canteen.** 2 mains × 3 drinks = 6 combinations. Two-way table shows all six. Tree has 6 paths. P(pasta and juice) = 1/6. P(wrap and not water) = 2/6 = 1/3. *Follow the thinking:* list systematically → count favourable → divide by total.

**Choosing a display.** Tables: few outcomes, equal probabilities. Trees: sequential events, unequal probabilities. Venn: overlapping categories, "or"/"and" questions.

**Cultural context.** Aboriginal seasonal decision-making combines multiple factors — wind direction AND temperature AND moon phase inform harvest timing. This is compound-event reasoning applied to Country. Melbourne restaurant menus, PTV multimodal journeys and AFL team selections all involve systematic outcome listing.

## Memorable takeaways
- Total combinations = event 1 outcomes × event 2 outcomes.
- Two-way tables: grid of all pairs.
- Tree diagrams: multiply along branches for path probability.
- Venn diagrams: overlap shows "and"; circles together show "or."

## Watch out for these traps
- "Multiply outcomes to get probability." That gives total combinations; probability is favourable ÷ total.
- "'Or' means one but not both." In probability, "or" usually means "one or both" (inclusive).
- "Venn circles must overlap." If nothing is shared, they do not overlap — that is valid.
