# VC2M8SP03 — Mathematics

## Snapshot
- **Descriptor:** VC2M8SP03. Describe in different ways the position and location of three-dimensional objects in 3 dimensions, including using a three-dimensional Cartesian coordinate system with the use of dynamic geometry software or other digital tools.

- **Big ideas:**

## What you are learning
- You are learning to **describe position and location of 3D objects** using a three-dimensional Cartesian coordinate system and digital tools.
- You are learning that adding a z-axis (height/depth) extends familiar 2D coordinates into the space around you.

By the end of this you should be able to:
- Plot and read coordinates in a 3D Cartesian system (x, y, z).
- Describe the position of a point using multiple methods (coordinates, directions, distances).
- Use dynamic geometry software (e.g. GeoGebra 3D) to visualise objects in space.
- Calculate distances between 3D points using the extension of Pythagoras.

## Core content

**1. From 2D to 3D.** A 2D coordinate system uses two axes (x, y) to locate points on a flat plane. Adding a third axis (**z**, usually representing height or depth) extends this into three dimensions. A point in 3D is written as (x, y, z). *Quick check:* What does the point (3, 4, 5) mean in terms of position?

**2. The three-dimensional Cartesian system.** The three axes are mutually perpendicular (at right angles to each other). The **origin** is (0, 0, 0). The x-axis often runs left–right, y-axis forward–back, and z-axis up–down, though conventions vary. *Quick check:* In which direction would you move from the origin to reach (0, 0, 7)?

**3. Plotting points in 3D.** To plot (2, 5, 3): move 2 along x, then 5 along y, then 3 up the z-axis. On paper, use isometric grids or oblique projection. In software (GeoGebra 3D, Desmos 3D), you enter coordinates directly and rotate the view. *Quick check:* Plot the eight corners of a unit cube. What are their coordinates?

**4. Describing position in different ways.** The same point can be described as:
- Coordinates: (4, 3, 6).
- Directions: "4 metres east, 3 metres north, 6 metres up."
- Distance and bearing: "7.81 m from the origin, bearing N36.9°E, elevation 50.2°."
Different descriptions suit different contexts (navigation, architecture, gaming). *Quick check:* Describe (0, 5, 12) using words ("how far in each direction from the origin").

**5. Distance between two 3D points.** The 3D distance formula extends Pythagoras: d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]. Between (1, 2, 3) and (4, 6, 3): d = √(9 + 16 + 0) = √25 = 5 units. *Quick check:* Find the distance from (0, 0, 0) to (3, 4, 12).

**6. Worked example: locating objects in a building.**

A school building has its front-left ground-floor corner as the origin (0, 0, 0). Each unit = 1 metre. The library entrance is at (15, 8, 0) (ground floor, 15 m along, 8 m in). The music room is at (15, 8, 4) (directly above on the first floor, 4 m up).

*Follow the thinking:*
- Library and music room share x and y coordinates — one is directly above the other.
- Vertical distance between them = |4 − 0| = 4 m.
- Distance from origin to music room = √(15² + 8² + 4²) = √(225 + 64 + 16) = √305 ≈ 17.5 m.
- In GeoGebra 3D, plot both points and draw the line segment to visualise the diagonal path through the building.

**7. Using dynamic geometry software.** Tools like GeoGebra 3D, Desmos, or SketchUp let you: enter coordinates, rotate the view, measure distances and angles, and create 3D shapes. They make abstract 3D thinking concrete by letting you see objects from multiple perspectives. *Quick check:* Name one advantage of using 3D software over a paper drawing.

## Victorian and cultural context

- **Victorian anchor.** Melbourne's Hoddle Grid uses coordinate-like grid references (e.g. "corner of Swanston and Lonsdale"). City planning uses 3D models with coordinates for building heights, underground infrastructure (tunnels, pipes) and airspace above. The Melbourne Metro Tunnel project used 3D coordinate systems to align boring machines underground. Surveyors across Victoria use GPS (latitude, longitude, altitude) — three coordinates for 3D position.
- **Aboriginal and Torres Strait Islander perspective.** Songlines and navigational knowledge across First Nations traditions locate places using landmark relationships, star positions and topographic features — a relational coordinate system embedded in Country. The concept of "above, below, and across" Country includes vertical knowledge (underground water, sky knowledge, surface features). Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** GPS navigation (used globally) relies on three coordinates. Video games played by Victorian students (Minecraft, CAD tools) use 3D coordinate systems explicitly — students often encounter (x, y, z) in gaming before mathematics class.

## Try these scenarios

1. **Everyday.** Your bedroom is at position (5, 3, 6) in a building coordinate system (units = metres). The front door is at (0, 0, 0). How far is the straight-line distance from the front door to your bedroom (through walls and floors)?
2. **Civic.** A drone operator at the City of Hobsons Bay needs to fly from position (0, 0, 50) to (100, 80, 50) — both at 50 m altitude. Calculate the horizontal distance the drone travels. If it then descends to (100, 80, 0), what is the total path length?
3. **Vocational.** A warehouse manager uses a 3D coordinate system to locate stock. Shelf A is at (2, 10, 3) and Shelf B is at (8, 4, 5). Calculate the straight-line distance between them. Which shelf is closer to the loading dock at (0, 0, 0)?
4. **Ethical.** A GPS tracking app records a person's 3D position every minute. Discuss the benefits (safety, navigation) and privacy concerns of such continuous 3D tracking.
5. **Cross-cultural.** In Minecraft (a game using explicit x, y, z coordinates), your base is at (100, 64, −200) and a village is at (350, 72, −50). Calculate the straight-line distance. How does the game's coordinate system compare to mathematical convention?

## Memorable takeaways
- 3D coordinates: (x, y, z) — three numbers locate any point in space.
- The z-axis adds height/depth to the familiar x-y plane.
- 3D distance: d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²].
- Same position, many descriptions: coordinates, directions, distance + bearing.
- Digital tools (GeoGebra, Desmos) make 3D thinking visible and interactive.

## Watch out for these traps
- "I only need two coordinates." 2D locates a point on a flat surface. To specify height or depth, you need the third coordinate (z).
- "The axes always mean the same thing." Convention varies: in maths z is usually up; in some games y is up. Always check the system you are working in.
- "I can use the 2D distance formula." In 3D you must include the third term: (z₂−z₁)².
- "3D is too hard to visualise." Use digital tools — rotate the view, build objects, measure interactively. That is what they are for.
