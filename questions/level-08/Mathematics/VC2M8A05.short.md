# VC2M8A05 — Mathematics (Short)

## Snapshot
- **Descriptor:** Experiment with linear functions and relations using digital tools, making and testing conjectures and generalising emerging patterns.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** Digital tools let you test many examples quickly. A conjecture is a testable claim based on observed patterns. Generalising means writing a rule that covers all cases.

## What you are learning
- You are learning to **experiment with linear functions** using digital tools, making **conjectures** and **generalising patterns**.
- You should be able to notice a pattern, state it clearly, test it and write a general rule.

## Core content

A **conjecture** is a statement you believe to be true based on evidence but have not yet proved. The cycle: **notice → conjecture → test → generalise** (or disprove with a counter-example).

**Digital tools** (Desmos, GeoGebra, spreadsheets) let you graph many linear functions quickly. Sliders change parameters in real time, making patterns visible instantly.

**Gradient experiments.** Graph *y = x*, *y = 2x*, *y = 3x*, *y = −x*. Pattern: larger positive gradients make steeper upward lines; negative gradients slope down; gradient 0 gives a horizontal line.

**Y-intercept experiments.** Graph *y = 2x*, *y = 2x + 3*, *y = 2x − 4*. Pattern: changing the constant shifts the line up or down without changing the slope. Lines with the **same gradient** are parallel.

**Worked example — family of lines y = mx + 2.** Use a slider for *m*. All lines pass through (0, 2). Conjecture: "All lines *y = mx + 2* pass through (0, 2) regardless of *m*." Test algebraically: at *x = 0*, *y = m(0) + 2 = 2*. Confirmed. Generalisation: *y = mx + c* always passes through (0, *c*). *Follow the thinking:* experiment → observe → conjecture → test → generalise.

**One counter-example** disproves a conjecture completely. Many supporting examples increase confidence but never constitute proof.

**Cultural context.** Aboriginal knowledge systems build understanding through systematic observation — star movements, tidal rhythms, plant-flowering sequences are conjectures tested against generations of evidence. Desmos and GeoGebra are freely available to all Victorian government-school students; the MAV promotes digital exploration in classrooms.

## Memorable takeaways
- A conjecture is an observed pattern stated as a testable claim.
- Digital tools let you test rapidly — use sliders, tables, graphs.
- Same gradient = parallel lines; changing y-intercept shifts vertically.
- One counter-example disproves; many examples support but do not prove.

## Watch out for these traps
- "Five examples prove my conjecture." Examples support, not prove — use reasoning.
- "Parallel lines eventually meet." Same gradient, different intercept → never meet.
- "Y-intercept affects steepness." Only the gradient determines steepness.

## Model responses

Use these to check your thinking after you have had a go.

- *Conjecture vs proof.* A conjecture is testable; a proof establishes truth through logic.
- *Slider advantage.* See the graph change in real time as you adjust parameters.
- *Lines with gradient 0.* All horizontal — flat lines at different y-intercept heights.
- *y = 3x + 1 and y = 3x − 5 parallel?* Yes — same gradient (3).
- *Family y = m(x − 1).* All pass through (1, 0) because m(1 − 1) = 0 for any m.
