# VC2M7A05 — Mathematics (Short)

## Snapshot
- **Descriptor:** Generate tables of values from visually changing patterns or the rule of a function; describe and plot these relationships on the Cartesian plane.
- **Year / Area:** Years 7–8, Mathematics (Algebra).
- **Big ideas:** Patterns become rules; rules fill tables; tables draw graphs on the Cartesian plane.

## What you are learning
- You are learning to **spot a pattern, write its rule, build a table and plot the result on the Cartesian plane**.
- You should be able to predict values using the rule and the graph.

## Core content

A **pattern** is anything that grows or repeats in a predictable way. A matchstick triangle pattern — 3, 5, 7, 9 — follows the rule y = 2n + 1. The rule is a **function**: put a number in, get exactly one number out.

To build a **table of values**, choose input values for x (0, 1, 2, 3 …), apply the rule and record each (x, y) pair. For y = 2x + 1: (0, 1), (1, 3), (2, 5), (3, 7).

The **Cartesian plane** has a horizontal x-axis and a vertical y-axis crossing at the **origin** (0, 0). To plot (2, 5): move 2 right, 5 up, mark the dot. When all your dots line up in a straight line, the function is **linear**. When the dots curve, it is **non-linear**.

**Worked example — growing tile pattern.** Tiles grow 1, 4, 9, 16 … Rule: y = n². Table: (1, 1), (2, 4), (3, 9), (4, 16), (5, 25). The plotted dots curve upward — a non-linear relationship because the variable is squared.

Once plotted, a graph lets you read values you did not calculate. Reading between known points is **interpolation**; predicting beyond them is **extrapolation**.

## Memorable takeaways
- A pattern becomes a rule; a rule fills a table; a table draws a graph.
- A function gives exactly one output for each input.
- Straight-line graphs mean constant growth; curves mean changing growth.
- Graphs let you predict values you have not calculated.

## Watch out for these traps
- Plotting (x, y) the wrong way round — x is always horizontal first.
- Assuming every pattern is linear — check the differences between y-values.
- Thinking a pattern in five values guarantees the hundredth — real-world constraints can break it.

- *Why "exactly one output" matters.* Without it the rule is unreliable and you cannot graph consistently.
- *Table row for x = 6 in y = 2x + 1.* y = 13.
- *Straight-line dots.* The rule is linear — constant increase per step.
- *Interpolation vs extrapolation.* Interpolation reads between known points (safer); extrapolation predicts beyond them (riskier).
