# VC2M8SP02 — Mathematics (Short)

## Snapshot
- **Descriptor:** Establish properties of quadrilaterals using congruent triangles and angle properties, and solve related problems explaining reasoning.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** A diagonal splits a quadrilateral into two triangles — proving them congruent reveals properties. Angle sum = 360°. The hierarchy (square ⊂ rectangle ⊂ parallelogram) sharpens reasoning.

## What you are learning
- You are learning to **establish quadrilateral properties using congruent triangles and angle properties** and to solve problems with logical reasoning.
- You should prove why properties hold, not just list them.

## Core content

**Angle sum:** a diagonal creates two triangles → 2 × 180° = 360°.

**Parallelogram via congruent triangles.** Diagonal AC in ABCD creates △ABC ≅ △CDA (ASA, using alternate angles from parallel sides). Consequences: opposite sides equal, opposite angles equal, diagonals bisect each other.

**Rectangle:** parallelogram + all angles 90°. Diagonals are equal (RHS proof).

**Rhombus:** parallelogram + all sides equal. Diagonals are perpendicular bisectors (SSS proof). Diagonals bisect vertex angles.

**Square:** rectangle + rhombus. All properties of both.

**Worked example.** Parallelogram PQRS: ∠P = 3x+10°, ∠Q = 2x+40°. Co-interior: ∠P + ∠Q = 180°. Solve: 5x + 50 = 180, x = 26. ∠P = 88°, ∠Q = 92°. Opposite angles: ∠R = 88°, ∠S = 92°. Check: sum = 360° ✓.

**Hierarchy:** every square is a rectangle and a rhombus; every rectangle and rhombus is a parallelogram; not every parallelogram is either.

**Victorian and cultural context.** Melbourne's Hoddle Grid uses angle properties to ensure perpendicular blocks. First Nations weaving produces parallelogram and rhombus patterns through consistent crossing angles. Islamic tile patterns at the NGV exploit quadrilateral symmetry via reflections and rotations.

## Memorable takeaways
- Quadrilateral angles sum to 360°.
- Diagonal → two congruent triangles → prove properties.
- Parallelogram: opposite sides/angles equal, diagonals bisect each other.
- Rectangle adds equal diagonals; rhombus adds perpendicular diagonals.

## Watch out for these traps
- "Angles add to 180°." That is triangles. Quadrilaterals = 360°.
- "Parallelogram diagonals are always equal." Only in rectangles.
- "A square is not a rectangle." A square meets the rectangle definition (four right angles).

## Model responses

Use these to check your thinking after you have had a go.

- *Three angles 95°, 80°, 110° — fourth?* 75°.
- *Parallelogram, one angle 70°.* Angles: 70°, 110°, 70°, 110°.
- *Rhombus diagonals 12 and 16 — side?* Half-diagonals 6, 8. Side = √(36+64) = 10 cm.
- *Square side 8 — diagonal?* 8√2 ≈ 11.3 cm.
- *Is every rectangle a rhombus?* No — only if all sides equal (i.e. a square).
