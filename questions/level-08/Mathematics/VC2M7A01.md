# VC2M7A01 — Mathematics

## Snapshot
- **Descriptor:** VC2M7A01. Recognise and use variables to represent everyday formulas algebraically and substitute values into formulas to determine an unknown.
- **Year level / Learning area:** Years 7–8, Mathematics (Algebra).
- **Big ideas:**
  - A variable is a letter standing in for a number that can change.
  - Everyday formulas turn real-world rules into short algebraic statements.
  - Substitution means swapping a variable for a known value to find the unknown.
- **Curriculum hooks:** Numeracy; Critical and Creative Thinking; Sustainability.

## What you are learning
- You are learning to **recognise variables** in everyday formulas and **use algebra** to write those formulas in shorthand.
- You are learning to **substitute known values** into a formula to calculate an unknown.

By the end of this you should be able to:
- Identify variables, constants and operations inside a formula.
- Translate a word rule into an algebraic formula.
- Substitute values into a formula and evaluate the result.
- Check your answer by working backwards.

## Core content

**1. What is a variable?** A **variable** is a letter (such as *n*, *t*, *d*) that represents a quantity that can change. A **constant** is a number that stays fixed. In the formula *d = 60t*, the letter *d* (distance in km) and *t* (time in hours) are variables; 60 (speed in km/h) is a constant. *Quick check:* In the formula *C = 12n + 5*, which symbols are variables and which are constants?

**2. Everyday formulas.** Many real-life rules can be written as formulas. Cost of entry: *C = 12n* where *n* is the number of people. Perimeter of a rectangle: *P = 2(l + w)*. Average speed: *s = d / t*. Converting Celsius to Fahrenheit: *F = 1.8C + 32*. *Quick check:* Write a formula for the total cost of buying *n* books at $15 each with a $10 delivery fee.

**3. Translating words into algebra.** Read the rule carefully: "Triple the number and add seven" becomes *y = 3x + 7*. Key words — "sum" means +, "difference" means −, "product" means ×, "quotient" means ÷, "triple" means × 3. *Quick check:* Translate "halve the distance and subtract four" into a formula.

**4. Substitution.** To **substitute** means to replace a variable with a given number and then evaluate. If *A = lw* and *l = 8*, *w = 3*, then *A = 8 × 3 = 24*. Always follow order of operations (BODMAS). *Quick check:* If *y = 2x + 5* and *x = 4*, what is *y*?

**5. Finding an unknown.** Sometimes you know the output and need to find an input. If *C = 12n + 5* and *C = 41*, you solve *12n + 5 = 41* → *12n = 36* → *n = 3*. *Quick check:* If *P = 4s* and *P = 52*, what is *s*?

**6. Worked example — Melbourne Cricket Ground perimeter fence.** A temporary fence runs around a rectangular section of the MCG outer area. The section is *l* metres long and *w* metres wide. Fencing costs $18 per metre. **Total cost = 18 × 2(l + w).** If *l = 45* and *w = 30*, total cost = 18 × 2(45 + 30) = 18 × 150 = $2 700. *Follow the thinking:* write the formula → substitute → evaluate inside brackets first → multiply.

**7. Checking by substitution.** After solving for an unknown, substitute your answer back into the original formula to verify. If you found *n = 3* from *12n + 5 = 41*, check: 12(3) + 5 = 36 + 5 = 41. It matches. *Quick check:* Why is checking by substitution a reliable strategy?

## Victorian and cultural context

- **Victorian anchor.** The MCG, Melbourne tram network fare formulas, VicRoads speed-distance calculations and Melbourne Water usage billing all use everyday formulas that students encounter in daily life.
- **Aboriginal and Torres Strait Islander perspective.** Wurundjeri Woi Wurrung and other Kulin Nations used systematic counting, measurement and seasonal calendars that encoded quantitative relationships — for example, Gunditjmara fish-trap engineering at Budj Bim required precise water-flow calculations across channels. The Australian Institute of Aboriginal and Torres Strait Islander Studies (AIATSIS) publishes material on Indigenous mathematical knowledge. Specific cultural knowledge should only be read through published, community-approved material.
- **Multicultural Australian perspective.** Melbourne's multicultural communities bring diverse numeral systems and mathematical traditions. Market traders at Queen Victoria Market use mental formulas for pricing, discount and currency conversion daily.

## Try these scenarios

1. **Everyday.** You buy *n* dim sims at South Melbourne Market for $2.50 each plus a $1 sauce charge. Write a formula for total cost and find *C* when *n = 6*.
2. **Civic.** Yarra City Council charges community groups a hall-hire fee: *C = 35h + 50*, where *h* is hours. A netball club pays $190. How many hours did they book?
3. **Vocational.** An apprentice electrician uses the formula *V = IR* (voltage = current × resistance). If *V = 240* volts and *R = 60* ohms, find *I*.
4. **Ethical.** A phone plan advertises "$10 per month plus 5 cents per text." Write the formula. Discuss whether the ad is clear enough for consumers.
5. **Cross-cultural.** A Wurundjeri-led maths trail at the Royal Botanic Gardens uses tree spacing to estimate the number of trees in a row: *T = (d / s) + 1*. If *d = 80* m and *s = 4* m, find *T*.

## Memorable takeaways
- A variable is a letter that stands for a changeable quantity.
- Formulas turn everyday rules into compact algebra.
- Substitution means replacing the letter with a number, then evaluating.
- Always follow BODMAS when evaluating.
- Check your answer by substituting back.

## Stretch yourself
A community garden in Footscray charges a seasonal membership fee using the formula *C = 25p + 40*, where *p* is the number of plots rented. The garden also offers a discount for groups of five or more: the constant drops from 40 to 20. Write both formulas. Calculate the cost for a family renting 3 plots under each formula. Then find how many plots a group can rent for exactly $270 under the discounted formula. Show all substitution steps and verify each answer. 250–300 words.

## Watch out for these traps
- "A variable can only be *x*." Any letter can be a variable — *n*, *t*, *d*, *C* are all common.
- "Multiply before brackets." BODMAS says brackets first, then orders, then multiplication and division left to right.
- "Substitution is guessing." It is a precise replacement followed by evaluation — not trial and error.
- "The formula changes when you substitute." The formula stays the same; you are just evaluating it for specific values.

## Model responses

Use these to check your own thinking after you have had a go.

**Quick checks (Core content)**

1. *Variables and constants in C = 12n + 5.* Variables: *C* and *n*. Constants: 12 and 5.
2. *Formula for n books at $15 plus $10 delivery.* *C = 15n + 10*.
3. *"Halve the distance and subtract four."* *y = d/2 − 4* (or equivalent).
4. *y = 2x + 5 when x = 4.* *y = 2(4) + 5 = 8 + 5 = 13*.
5. *P = 4s when P = 52.* *4s = 52*, so *s = 13*.
6. *Why checking by substitution works.* If the substituted answer satisfies the original equation, the solution is correct.

**Try these scenarios**

1. *Dim sims.* *C = 2.50n + 1*. When *n = 6*: *C = 2.50(6) + 1 = 15 + 1 = $16*.
2. *Hall hire.* *35h + 50 = 190 → 35h = 140 → h = 4* hours.
3. *Electrician.* *I = V/R = 240/60 = 4* amps.
4. *Phone plan.* *C = 10 + 0.05t*. Discussion: the ad should state units clearly and show the formula so consumers can estimate costs.
5. *Tree spacing.* *T = (80/4) + 1 = 20 + 1 = 21* trees.

**Stretch task — example shape of a strong answer.** Standard formula: *C = 25(3) + 40 = 75 + 40 = $115*. Discounted: *C = 25(3) + 20 = 75 + 20 = $95*. For $270 discounted: *25p + 20 = 270 → 25p = 250 → p = 10* plots. Check: *25(10) + 20 = 270*. Verified.
