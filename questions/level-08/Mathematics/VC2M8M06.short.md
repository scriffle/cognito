# VC2M8M06 — Mathematics (Short)

## Snapshot
- **Descriptor:** Use Pythagoras' theorem to solve problems involving the side lengths of right-angled triangles.
- **Year / Area:** Years 7–8, Mathematics.
- **Big ideas:** In any right-angled triangle, a² + b² = c² (c is the hypotenuse). The theorem lets you find an unknown side from the other two. It connects geometry to algebra and appears across construction, navigation and design.

## What you are learning
- You are learning to use **Pythagoras' theorem** to find unknown side lengths in **right-angled triangles**.
- You should be able to identify the hypotenuse, apply the theorem, and interpret results in context.

## Core content

A **right-angled triangle** has one 90° angle. The **hypotenuse** (c) is the longest side, opposite the right angle. The theorem states: **a² + b² = c²**.

**Finding the hypotenuse:** add the squares of the legs, then square root. Example: a = 5, b = 12. c² = 25 + 144 = 169. c = 13.

**Finding a leg:** rearrange. a² = c² − b². Example: c = 10, b = 6. a² = 100 − 36 = 64. a = 8.

**Pythagorean triples** are integer solutions: (3, 4, 5), (5, 12, 13), (8, 15, 17). Multiples work too: (6, 8, 10) = 2 × (3, 4, 5).

**Worked example.** A wheelchair ramp rises 1.2 m over 5 m horizontal. Ramp length = √(1.2² + 5²) = √(1.44 + 25) = √26.44 ≈ 5.14 m.

**When to use it.** Whenever you have a right angle and two known sides: ladders against walls, diagonals of rectangles, distance problems, roof pitches, surveying.

**Victorian context.** Builders use the "3-4-5 rule" to set right angles on site. The West Gate Bridge, MCG floodlight towers and Federation Square all rely on right-angle geometry. The theorem was known independently in Babylonian, Chinese, Indian and Greek traditions — Plimpton 322 (c. 1800 BCE) predates Pythagoras by over a millennium.

## Memorable takeaways
- a² + b² = c² — c is always the hypotenuse.
- Hypotenuse: add squares, then root. Leg: subtract squares, then root.
- The hypotenuse must be longer than either leg (sanity check).
- Pythagorean triples save time: (3,4,5), (5,12,13), (8,15,17).

## Watch out for these traps
- Squaring the hypotenuse instead of the legs — c is alone on one side of the equation.
- Forgetting the square root — c² = 169 means c = 13, not 169.
- Using the theorem when there is no right angle — it only works for right-angled triangles.

## Model responses

- *c when a = 6, b = 8.* c² = 36 + 64 = 100, c = 10.
